# freeAudio (Свободное радио)

freeAudio — это полнофункциональное дополнение для интернет-радио, подкастов, аудиокниг и локального джукбокса для экранного диктора NVDA. То, что начиналось как простой способ слушать интернет-радиостанции, выросло в полноценный, полностью доступный центр прослушивания — каждый экран, диалог и элемент управления с самого начала спроектирован для работы с клавиатуры и экранного диктора, без необходимости использовать мышь на любом этапе.

## Что умеет freeAudio

- **Интернет-радио** — Просматривайте и ищите среди более чем 50 000 станций в каталоге [Radio Browser](https://www.radio-browser.info/), результаты которого дополнены данными TuneIn и iHeartRadio. Сохраняйте избранное, меняйте порядок станций и переходите к любой из них напрямую с помощью глобального сочетания клавиш из любого места в Windows — см. [Каталог Radio Browser](#каталог-radio-browser) и [Избранное](#избранное).
- **Подкасты** — Подписывайтесь на любую RSS/Atom-ленту или ищите в каталоге подкастов Apple и прослушивайте эпизоды перед подпиской. Позиция воспроизведения сохраняется автоматически и возобновляется с того места, где вы остановились — см. [Подкасты](#подкасты).
- **Аудиокниги** — Ищите, транслируйте или скачивайте книги из трёх источников: [GETEM](https://getem.boun.edu.tr/), цифровой библиотеки Университета Богазичи для людей с нарушениями зрения, [LibriVox](https://librivox.org/), проекта аудиокниг общественного достояния, начитанных добровольцами, и коллекции открытых аудиокниг Project Gutenberg — последние два не требуют учётной записи — с автоматическим продолжением между частями многочастных произведений — см. [Аудиокниги (GETEM, LibriVox и Project Gutenberg)](#аудиокниги-getem-librivox-и-project-gutenberg).
- **Локальный джукбокс** — Ищите аудиофайлы, хранящиеся на любом подключённом диске, по имени файла, или создайте личную библиотеку файлов и папок, и воспроизводите их с теми же инструментами возобновления, перемотки, скорости и транспонирования, которые используют подкасты и аудиокниги — см. [Локальный джукбокс](#локальный-джукбокс).
- **Запись** — Записывайте то, что сейчас играет, мгновенно, автоматически захватывайте отдельную песню при её начале и окончании, или планируйте разовые и повторяющиеся записи — всё это без прерывания воспроизведения — см. [Запись](#запись).
- **Тайм-шифт (перемотка живого радио)** — Ставьте на паузу и перематывайте живую станцию, как DVR, а затем возвращайтесь к прямому эфиру в любой момент — см. [Тайм-шифт (перемотка живого радио)](#тайм-шифт-перемотка-живого-радио).
- **Распознавание музыки и понравившиеся треки** — Определяйте треки без метаданных с помощью распознавания на основе Shazam, сохраняйте понравившиеся треки в текстовый файл и находите их тексты песен — см. [Распознавание музыки](#распознавание-музыки) и [Понравившиеся треки](#понравившиеся-треки).
- **Аудиопрофили и эффекты** — Сохраняйте отдельные настройки громкости, эффектов, эквалайзера и скорости воспроизведения для каждой станции, подкаста, аудиокниги или трека джукбокса, и применяйте эффекты в реальном времени (Chorus, Reverb, усиление эквалайзера и другие) через движок BASS — см. [Аудиопрофиль станции](#аудиопрофиль-станции).
- **Транспонирование (сдвиг высоты тона)** — Сдвигайте высоту тона подкастов, аудиокниг и треков джукбокса вверх или вниз без изменения их скорости, используя входящий в комплект компонент `bass_fx` — см. [Транспонирование (сдвиг высоты тона)](#транспонирование-сдвиг-высоты-тона).
- **Аудиозеркало** — Отправляйте один и тот же поток одновременно на два устройства вывода звука, например на колонки и наушники одновременно — см. [Аудиозеркало](#аудиозеркало).
- **Режим Obligato (фоновая музыка)** — Зацикленно воспроизводите выбранную избранную станцию тихо в фоне, на собственном устройстве вывода и с собственной громкостью, независимо от того, что (или ничего) играет в качестве основного медиа — см. [Режим фоновой музыки (Obligato)](#режим-фоновой-музыки-obligato).
- **Таймеры** — Планируйте запуск воспроизведения избранной станции или остановку воспроизведения в определённое время — см. [Таймер](#таймер).
- **Полный доступ с клавиатуры и через брайль** — Каждая функция полностью доступна с клавиатуры, с глобальными сочетаниями клавиш, работающими из любого места в Windows, прямыми горячими клавишами для отдельных избранных станций и опциональным выводом на брайлевский дисплей для всех голосовых уведомлений freeAudio.

## Каталог Radio Browser

freeAudio использует открытую базу данных [Radio Browser](https://www.radio-browser.info/) для своего каталога станций. Radio Browser — это общедоступный бесплатный каталог, содержащий более 50 000 интернет-радиостанций со всего мира. Регистрация или учётная запись не требуются, а его API открыт для всех. Каждая станция включает адрес, страну, жанр, язык и информацию о битрейте; станции ранжируются по голосам пользователей. freeAudio подключается к этому API через зеркальные серверы, расположенные в Германии, Нидерландах и Австрии; если один сервер недоступен, дополнение автоматически переключается на следующий.

Чтобы обозреватель оставался отзывчивым и не нагружал API при каждом поиске или смене страны, freeAudio хранит на диске локальный кэш каталога станций. Этот кэш автоматически обновляется в фоновом режиме по периодическому расписанию, поэтому отображаемый список обычно уже актуален без каких-либо действий с вашей стороны. Вы также можете в любой момент принудительно запустить немедленную повторную синхронизацию кнопкой **Обновить список станций** — см. раздел «Обозреватель станций» ниже.

## Добавление станции в Radio Browser

Если станция, которую вы ищете, отсутствует в каталоге Radio Browser, вы можете добавить её самостоятельно по адресу [https://www.radio-browser.info/add](https://www.radio-browser.info/add). Учётная запись или регистрация не требуются.

Заполните форму на этой странице:

- **Stream URL** *(обязательно)* — прямой URL-адрес аудиопотока, заканчивающийся на `.mp3`, `.aac`, `.ogg` или подобное. Это не адрес сайта станции; это «сырой» адрес потока, который вы вставили бы в медиаплеер. Большинство станций публикуют свой URL-адрес потока на своём веб-сайте или в разделе «Слушать онлайн».
- **Station name** *(обязательно)* — название станции, как оно должно отображаться в каталоге.
- **Homepage** — адрес веб-сайта станции.
- **Country and language** — выберите страну и язык вещания из раскрывающихся списков.
- **Tags** — ключевые слова жанра или темы, разделённые запятыми, например `news`, `jazz`, `classical`. Они используются для поиска и фильтрации.
- **Logo URL** — прямая ссылка на логотип станции, если доступен.

После отправки станция проверяется и добавляется в общедоступный каталог. После принятия она автоматически появится в результатах поиска и списках стран freeAudio, поскольку каталог обновляется из живого API.

## Требования

- NVDA 2025.1	 или новее
- Windows 10 или новее
- Интернет-соединение

## Установка

Скачайте `.nvda-addon` файл, нажмите на нём Enter и перезапустите NVDA при появлении запроса.

## Горячие клавиши

Все сочетания клавиш можно переназначить в меню NVDA → Параметры → Жесты ввода → freeAudio. Эти сочетания работают отовсюду, независимо от того, какое окно находится в фокусе.

Некоторые из этих сочетаний совпадают с сочетаниями, которые использует сама Windows. Если вы предпочитаете сохранить собственное сочетание Windows без переназначения сочетания freeAudio, нажмите `NVDA+F2` (Передать следующую клавишу) непосредственно перед комбинацией клавиш — NVDA отправит эту одну комбинацию напрямую в Windows, а не будет перехватывать её для freeAudio.

| Сочетание | Функция | Описание |
|---|---|---|
| `Ctrl+Win+R` | Открыть обозреватель станций | Открывает окно обозревателя, если оно закрыто, или выводит его на передний план, если уже открыто. |
| `Ctrl+Win+O` | Открыть вкладку «Подкасты» | Открывает обозреватель станций (если закрыт) или выводит его на передний план и переключается непосредственно на вкладку **Подкасты**. |
| `Ctrl+Win+L` | Открыть вкладку «Аудиокниги» | Открывает обозреватель станций (если закрыт) или выводит его на передний план и переключается непосредственно на вкладку **Аудиокниги**. |
| `Ctrl+Win+U` | Открыть вкладку «Джукбокс» | Открывает обозреватель станций (если закрыт) или выводит его на передний план и переключается непосредственно на вкладку **Джукбокс**, с фокусом на поле поиска на диске. |
| `Ctrl+Win+P` | Пауза / возобновление | Ставит текущую станцию на паузу, если играет; возобновляет, если на паузе. Если ничего не играет, запускает последнюю станцию или открывает список избранного в зависимости от вашей настройки. Двойное нажатие переключает на вкладку по вашему выбору. Тройное нажатие может вызвать отдельное действие в зависимости от вашей настройки. |
| `Ctrl+Win+S` | Остановить | Полностью останавливает текущую станцию и сбрасывает плеер. |
| `Ctrl+Win+→` | Следующая в избранном | Переходит к следующей станции в списке избранного. В конце списка переходит к началу. |
| `Ctrl+Win+←` | Предыдущая в избранном | Переходит к предыдущей станции в списке избранного. В начале списка переходит в конец. |
| `Ctrl+Win+↑` | Увеличить громкость | Увеличивает громкость на 5; максимум 200. |
| `Ctrl+Win+↓` | Уменьшить громкость | Уменьшает громкость на 5; минимум 0. |
| `Ctrl+Win+V` | Добавить в избранное / Скачать медиа | Добавляет текущую играющую станцию в список избранного или скачивает текущий эпизод подкаста или аудиокнигу. Сообщает, если станция уже в списке или если медиа уже было скачано. Не применяется, когда играет трек джукбокса: freeAudio сообщает, что сочетание предназначено только для станций, подкастов или аудиокниг. |
| `Ctrl+Win+Shift+K` | Увеличить скорость воспроизведения | Увеличивает скорость воспроизведения эпизода подкаста, аудиокниги или трека джукбокса на 0,1× (с сохранением высоты тона). Диапазон: 0,5× до 2,0×. |
| `Ctrl+Win+Shift+J` | Уменьшить скорость воспроизведения | Уменьшает скорость воспроизведения эпизода подкаста, аудиокниги или трека джукбокса на 0,1×. |
| `Shift+Win+K` | Транспонировать вверх | Повышает высоту тона эпизода подкаста, аудиокниги или трека джукбокса шагами по 1/8 целого тона (0,25 полутона), не изменяя скорость. Диапазон: −12,00 до +12,00 полутонов. См. [Транспонирование (сдвиг высоты тона)](#транспонирование-сдвиг-высоты-тона). |
| `Shift+Win+J` | Транспонировать вниз | Понижает высоту тона шагами по 1/8 целого тона, не изменяя скорость. |
| `Ctrl+Win+I` | Информация о станции | Объявляет название текущей играющей станции, эпизода подкаста, аудиокниги или трека джукбокса. Нажмите дважды, чтобы показать подробности, такие как страна, жанр и битрейт, в диалоговом окне. Нажмите трижды, чтобы скопировать текущую информацию о треке (ICY-метаданные) в буфер обмена, если доступно; если метаданные отсутствуют, запускает распознавание музыки Shazam. Нажмите четыре раза, чтобы принудительно запустить распознавание музыки в случае неверных ICY-метаданных. |
| `Ctrl+Win+M` | Аудиозеркало | Зеркально отражает текущий поток или медиа на дополнительное устройство вывода звука одновременно. Нажмите снова, чтобы остановить зеркалирование. |
| `Ctrl+Win+Shift+M` | Режим Obligato (фоновая музыка) | Зацикленно воспроизводит выбранную избранную станцию тихо в фоне, на собственном устройстве вывода и с собственной громкостью, независимо от того, что играет в основном плеере. При первом нажатии открывается диалог для выбора станции, устройства вывода и относительной громкости. Нажмите снова, чтобы остановить. |
| `Ctrl+Win+E` | Мгновенная запись | Нажмите один раз, чтобы начать запись текущей станции; нажмите снова, чтобы остановить. Нажмите **дважды**, чтобы начать **запись песни** — файл будет назван по текущему треку, и запись автоматически остановится при смене трека. Нажмите дважды снова, пока активна запись песни, чтобы остановить её досрочно. Воспроизведение продолжается без прерываний во всех режимах записи. Доступно только для станций, которые передают ICY-метаданные. |
| `Ctrl+Win+W` | Открыть папку записей | Открывает папку с сохранёнными файлами записей в Проводнике. |
| `Ctrl+Win+J` | Тайм-шифт назад / перемотка назад в подкасте, аудиокниге и джукбоксе | Для живого радио: перематывает на 15 секунд назад. Первое нажатие активирует режим тайм-шифта; каждое следующее нажатие перематывает ещё на 15 секунд назад, до предела буфера, установленного в настройках freeAudio. Требует включённого буфера тайм-шифта в Настройках. Для эпизода подкаста, аудиокниги или трека джукбокса эта клавиша выполняет перемотку внутри файла и масштабируется в зависимости от способа нажатия: **удержание** перематывает на 5 секунд за повтор; **одно осознанное нажатие** перематывает на 12 секунд назад; **два нажатия** подряд перематывают на 1 минуту; **три и более нажатий** перематывают на 5 минут. На одну серию нажатий происходит только одна перемотка, размер которой соответствует итоговому числу нажатий — нажатия не суммируются. Работает независимо от настройки тайм-шифта. |
| `Ctrl+Win+K` | Тайм-шифт вперёд / перемотка вперёд в подкасте, аудиокниге и джукбоксе | Для живого радио: перематывает на 15 секунд вперёд в режиме тайм-шифта. Достигнув края прямого эфира, воспроизведение автоматически возвращается в прямой эфир, и команда не имеет эффекта до следующей перемотки назад. Для эпизода подкаста, аудиокниги или трека джукбокса эта клавиша выполняет перемотку вперёд внутри файла с тем же масштабированием нажатия/удержания, что и `Ctrl+Win+J` выше (удержание = 5 секунд за повтор; 1 нажатие = 12 секунд; 2 нажатия = 1 минута; 3+ нажатия = 5 минут). Работает независимо от настройки тайм-шифта. |
| `Ctrl+Win+T` | Включить/выключить буфер тайм-шифта | Мгновенно включает или выключает буфер тайм-шифта, отражая состояние флажка в Настройках. При выключении немедленно возвращает в прямой эфир (если активен тайм-шифт) и останавливает фоновую запись. Не влияет на воспроизведение подкастов, аудиокниг или джукбокса. |
| *(не назначено)* | Переключить отключение уведомлений | Переключает параметр «Отключить уведомления» на лету. Назначьте сочетание клавиш через меню NVDA → Параметры → Жесты ввода → freeAudio. |
| *(не назначено)* | Воспроизвести избранную станцию напрямую | Каждая станция из списка избранного отображается как отдельный элемент в меню NVDA → Параметры → Жесты ввода → **freeAudio Stations**. Назначьте сочетание клавиш любой станции и запускайте её мгновенно из любого места, не открывая обозреватель. |

Сочетания «следующий / предыдущий» работают только со списком избранного; они не работают со списком всех станций. Когда в окне обозревателя фокус находится на списке, клавиши со стрелками влево и вправо служат той же цели — см. «Горячие клавиши внутри диалога».

## Обозреватель станций

freeAudio также добавляет подменю **freeAudio** в меню NVDA «Сервис». Оттуда вы можете напрямую открыть Обозреватель станций и Настройки freeAudio.

Окно, открываемое с помощью `Ctrl+Win+R`, содержит восемь вкладок: Все станции, Избранное, Запись, Таймер, Понравившиеся треки, Подкасты, Аудиокниги и Джукбокс. Вы можете перемещаться между вкладками с помощью `Ctrl+Tab` или используя `Alt+1` до `Alt+8`.

Когда открывается вкладка «Все станции», из Radio Browser автоматически загружаются 1000 самых популярных станций (по голосам). Выбор страны из раскрывающегося списка обновляет список, показывая станции этой страны. Ввод текста в поле поиска мгновенно выполняет полноценный поиск по всей базе данных Radio Browser одновременно по названию, стране и жанру.

При поиске результаты Radio Browser дополняются станциями из TuneIn и iHeartRadio (когда доступны). Эти внешние источники ищутся в фоновом режиме, и их результаты автоматически объединяются в список, давая вам доступ к ещё большему числу станций без каких-либо дополнительных действий.

Раскрывающийся список **Устройство вывода** в нижней части окна обозревателя (за пределами вкладок) содержит все распознаваемые BASS устройства вывода звука. Выбор устройства немедленно перенаправляет на него аудиовыход и сохраняет выбор навсегда; то же устройство будет использоваться автоматически в следующем сеансе. Если выбранное устройство не подключено, дополнение автоматически переключается на системное устройство по умолчанию. Нажмите `F11`, чтобы открыть более простой выбор устройства по запросу из любого места в Обозревателе станций. Выбор не отображается автоматически и открывается только тогда, когда BASS обнаруживает более одного физического устройства вывода. Когда доступно только одно, выбор не требуется, и freeAudio использует системный вывод по умолчанию.

Элементы управления **Громкость** (0–200) и **Эффекты** в той же области можно регулировать в любое время, пока окно открыто. Из списка Эффектов можно одновременно включить Chorus, Compressor, Distortion, Echo, Flanger, Gargle, Reverb, EQ: Bass Boost, EQ: Treble Boost и EQ: Vocal Boost; изменения применяются к активному потоку мгновенно. Каждый эффект также можно мгновенно включить или выключить сочетаниями от `Ctrl+1` до `Ctrl+0`, не отрывая рук от клавиатуры — см. раздел «Горячие клавиши эффектов» ниже.

При активации одного или нескольких эффектов эквалайзера автоматически появляется **элемент управления усилением** для каждого активного диапазона. Усиление можно настроить в диапазоне от −15 дБ до +15 дБ; значения по умолчанию: НЧ +9 дБ, ВЧ +9 дБ, вокал +6 дБ. Элементы управления отображаются только для отмеченных диапазонов EQ и автоматически скрываются при снятии отметки с эффекта. Значения сохраняются постоянно и восстанавливаются в следующем сеансе.

Кнопка **Воспроизведение/Пауза** также находится в нижней части окна. Если ни одна станция не играет, она запускает выбранную станцию; если станция уже играет, она ставит воспроизведение на паузу.

Кнопка **Обновить список станций** немедленно повторно синхронизирует локальный каталог станций с API Radio Browser, не дожидаясь периодического фонового обновления. Пока обновление выполняется, кнопка недоступна, а NVDA сообщает, что обновление выполняется; если нажать её снова до завершения текущего обновления, NVDA сообщит, что обновление уже выполняется. По завершении обновления NVDA сообщает, что список станций обновлён, а текущие результаты поиска или список по стране автоматически обновляются, отражая новые данные.

Когда станция выбрана в списке, кнопка **Сведения о станции** отображает такую информацию, как страна, язык, жанр, формат, битрейт, веб-сайт и URL-адрес потока в отдельном диалоговом окне. Каждое поле отображается в отдельном текстовом поле только для чтения; вы можете перемещаться между полями с помощью Tab и скопировать всю информацию в буфер обмена сразу с помощью кнопки **Копировать всё в буфер обмена**. Эта кнопка доступна как на вкладке «Все станции», так и на вкладке «Избранное».

### Контекстное меню станции

Щёлкните правой кнопкой мыши по станции в списке «Все станции» или «Избранное», либо выделите её и нажмите клавишу «Контекстное меню» или `Shift+F10`, чтобы открыть контекстное меню с быстрыми действиями:

- **Информация о станции** — то же самое, что и описанная выше кнопка «Информация о станции».
- **Добавить в избранное** *(вкладка «Все станции»)* / **Удалить станцию** *(вкладка «Избранное»)*.
- **Переименовать станцию** *(вкладка «Избранное»)* — то же самое, что и `F9`.
- **Сохранить аудиопрофиль для этой станции** / **Очистить аудиопрофиль** *(вкладка «Избранное»)* — см. Аудиопрофиль станции.
- **Проверить URL** — проверяет, доступен ли поток выбранной станции в данный момент, не начиная воспроизведение, и объявляет результат (доступен, либо причину сбоя, например ошибку HTTP или тайм-аут сети).

Отображаются только пункты, относящиеся к текущей вкладке и выбору.

## Избранное

Список избранного — это персональная коллекция станций, которая хранится постоянно. Чтобы добавить станцию, выберите её в списке и нажмите кнопку «Добавить в избранное» или используйте сочетание `Alt+V`. То же сочетание удаляет станцию, которая уже есть в списке, когда она выбрана.

Избранными станциями можно управлять с помощью `Ctrl+Win+→` и `Ctrl+Win+←`; эти сочетания работают, даже когда окно обозревателя закрыто.

Чтобы удалить станцию из списка избранного, выберите её и нажмите кнопку **Удалить станцию** или клавишу `Delete`. После удаления фокус и выделение автоматически перемещаются на следующую станцию в списке. Если удалённая станция была последней, фокус перемещается на предыдущую станцию. Если список становится пустым, фокус перемещается на кнопку «Воспроизвести».

### Пометка и удаление нескольких элементов

Избранное, Понравившиеся треки, библиотека аудиокниг и список джукбокса поддерживают пометку нескольких элементов и их удаление за один шаг:

- Нажмите **`.`** (точку) на выделенном элементе, чтобы пометить или снять пометку. NVDA объявляет изменение, а строка помеченного элемента получает метку "(помечено)", чтобы её статус оставался понятным при перемещении по списку.
- Нажмите **`Shift+Home`**, чтобы пометить или снять пометку со всех элементов от текущего до первого в списке, или **`Shift+End`**, чтобы сделать то же самое до последнего. Будет ли диапазон помечен или снят, решается по текущему состоянию самого элемента, поэтому весь диапазон всегда перемещается в одном направлении за одно действие. Затем фокус перемещается на дальний конец диапазона, и NVDA сообщает, сколько элементов изменилось.
- Нажмите **`Delete`**, чтобы удалить все помеченные элементы сразу. Если ничего не помечено, `Delete` по-прежнему удаляет только текущий выбранный элемент, как и раньше.
- Контекстное меню правой кнопки мыши (клавиша «Приложения» / `Shift+F10`) каждого списка включает команду **Удалить выбранные**, доступную только когда помечен хотя бы один элемент, которая делает то же самое.
- Перед удалением открывается одно диалоговое окно подтверждения, в котором указано, сколько элементов будет удалено.

Пометки ведутся отдельно для каждого списка и очищаются после удаления элементов (или снятия пометки по отдельности); они не сохраняются между сеансами.

### Экспорт и импорт избранного

Вкладка «Избранное» содержит две кнопки для резервного копирования и восстановления списка станций:

**Экспортировать избранное…** — сохраняет весь список избранного в файл. В диалоге сохранения можно выбрать один из двух форматов:
- **JSON** (`.json`) — полная резервная копия, сохраняющая названия станций, URL-адреса потоков и все метаданные. Рекомендуется для последующего восстановления списка или переноса его на другой компьютер.
- **Плейлист M3U** (`.m3u`) — стандартный формат плейлиста, совместимый с большинством медиаплееров и радиоприложений. Обратите внимание, что M3U не хранит все метаданные станций, поэтому восстановление из M3U может дать меньше деталей, чем резервная копия JSON.

**Импортировать избранное…** — загружает станции из ранее экспортированного файла JSON или M3U. После выбора файла предлагается выбрать способ добавления станций:
- **Да (Объединить)** — добавляет импортируемые станции к существующему списку, не удаляя текущие элементы избранного. Дубликаты не добавляются повторно.
- **Нет (Заменить)** — полностью очищает текущий список избранного и заменяет его содержимым импортируемого файла.
- **Отмена** — возвращает в браузер без внесения каких-либо изменений.

После успешного импорта список избранного, список станций для запланированных записей и список станций таймера обновляются автоматически.

### Организация избранного в группы

Элементы избранного могут принадлежать папке/группе, что отображается суффиксом «— Группа» после названия станции в списке (например, «NPR Newscast — NPR»).

- **Импорт из M3U** — если файл использует тег `group-title` (соглашение, используемое DVBViewer и большинством других редакторов и плееров M3U) для организации станций по папкам, freeAudio считывает его и сохраняет группу каждой станции при импорте. Экспорт избранного обратно в M3U записывает тот же тег, поэтому структура папок сохраняется при круговом прохождении через freeAudio.
- **Назначение или удаление группы вручную** — пометьте одну или несколько станций из избранного с помощью `.` (см. [Пометка и удаление нескольких элементов](#пометка-и-удаление-нескольких-элементов) выше), затем выберите **Назначить группу…** в контекстном меню (клавиша «Приложения» / `Shift+F10`) и введите имя группы. Оставьте поле пустым, чтобы удалить помеченные станции из их группы. Если ничего не помечено, команда применяется к текущей выбранной станции из избранного.
- **Фильтрация по группе** — поле Фильтр над списком избранного также сопоставляется с именами групп и принимает несколько слов, каждое из которых может совпадать с разным полем. Например, ввод `Houston Classical` находит «Houston Public Media Classical», даже если эта точная фраза нигде не встречается — «Houston» совпадает с группой, а «Classical» совпадает с названием станции.

### Изменение порядка в избранном

Когда станция выбрана на вкладке «Избранное», нажмите `запятую`, чтобы войти в режим перемещения — вы услышите звуковой сигнал. Переместитесь на нужную позицию с помощью клавиш со стрелками, затем снова нажмите `запятую`. Станция будет помещена на выбранную позицию, и новый порядок будет немедленно сохранён. Повторное нажатие `запятой` на той же позиции отменяет перемещение.

### Прямые горячие клавиши для станций из избранного

Каждая станция из списка избранного зарегистрирована как отдельный скрипт в диалоге «Жесты ввода» NVDA, в категории **freeAudio Stations**. Вы можете назначить любое сочетание клавиш любой станции и нажимать его из любого места — без необходимости открывать окно обозревателя.

Чтобы назначить сочетание:

1. Откройте меню NVDA → Параметры → Жесты ввода.
2. Разверните категорию **freeAudio Stations**.
3. Найдите станцию по названию, выберите её и нажмите **Добавить**.
4. Нажмите нужное сочетание клавиш и подтвердите.

Сочетание запускает станцию немедленно. Если станция будет удалена из избранного, её запись исчезнет из категории, а назначенное сочетание будет автоматически удалено NVDA. При добавлении новой станции в избранное она сразу появляется в категории — повторно открывать диалог «Жесты ввода» не нужно.

### Добавление пользовательской станции

Чтобы добавить станцию, которой нет в Radio Browser, используйте кнопку «Добавить пользовательскую станцию». В появившемся диалоговом окне введите название станции и URL-адрес потока, чтобы добавить её прямо в избранное. Пользовательские станции можно воспроизводить и изменять их порядок так же, как и любую другую станцию из избранного.

В этом диалоговом окне доступны две дополнительные кнопки:

- **Проверить URL** — проверяет введённый URL-адрес потока перед добавлением станции и объявляет, доступен ли он. Полезно, чтобы обнаружить опечатку или неработающую ссылку прежде, чем она окажется в вашем списке избранного.
- **Добавить в каталог Radio Browser…** — открывает [страницу подачи заявки Radio Browser](https://www.radio-browser.info/add) в браузере по умолчанию, чтобы вы могли поделиться станцией с более широким сообществом Radio Browser, как только убедитесь, что она работает. Что ожидается в форме подачи заявки, см. в разделе «Добавление станции в Radio Browser» выше.

### Аудиопрофиль станции

Вкладка «Избранное» содержит две кнопки для управления настройками звука для каждой станции:

**Сохранить аудиопрофиль для этой станции** — сохраняет текущий уровень громкости, активные эффекты и значения усиления эквалайзера как профиль, привязанный к этой конкретной станции. Всякий раз, когда эта станция начинает играть, её сохранённые громкость, эффекты и усиление автоматически применяются, переопределяя глобальные настройки по умолчанию.

**Очистить аудиопрофиль** — удаляет сохранённый аудиопрофиль для выбранной станции. После очистки станция возвращается к глобальным настройкам громкости, эффектов и усиления эквалайзера. Эта кнопка активна, только если для выбранной станции уже сохранён профиль.

Обе кнопки расположены под списком избранного и активны, только когда станция в списке выбрана.

## Распознавание музыки

Тройное нажатие `Ctrl+Win+I` запускает распознавание музыки на основе Shazam для текущего потока. Распознавание запускается только тогда, когда нет доступных ICY-метаданных (информация о треке, передаваемая станцией); если метаданные присутствуют, они копируются в буфер обмена.

Распознавание работает следующим образом: из потока захватывается короткий аудиообразец с помощью ffmpeg, применяется алгоритм создания отпечатков Shazam, и результат отправляется на серверы Shazam. Если распознавание успешно, название трека, исполнитель, альбом и год выпуска объявляются NVDA и автоматически копируются в буфер обмена. Если включена опция **Сохранять понравившиеся треки в текстовый файл**, результат распознавания также добавляется в `likedSongs.txt`.

**Аудиообратная связь:** Два повышающихся звуковых сигнала означают начало распознавания, и два понижающихся — его окончание. Короткий звуковой сигнал воспроизводится каждые 2 секунды во время выполнения процесса.

**Требование:** Требуется ffmpeg.exe. FFmpeg.exe, помещённый в папку дополнения, используется автоматически; если он находится в другом месте, путь можно указать в настройках. Скачайте ffmpeg с [ffmpeg.org](https://ffmpeg.org/download.html).

**Примечание о станциях, вставляющих рекламу:** некоторые станции проигрывают короткую рекламу при каждом новом подключении к своему потоку, отдельно от эфира, который вы уже слушаете. Распознавание избегает сэмплирования этой рекламы, повторно используя уже существующее фоновое соединение с потоком freeAudio (то же самое, что используется для тайм-шифта), вместо того чтобы открывать новое, поэтому оно распознаёт то, что реально играет, а не рекламу. Это работает автоматически и не требует настройки.

## Аудиозеркало

Сочетание `Ctrl+Win+M` зеркально отражает текущий поток на второе устройство вывода звука одновременно. Это полезно для одновременного прослушивания на двух разных устройствах, например, на колонках и наушниках.

При первом нажатии появляется диалог выбора с перечислением доступных устройств вывода. Как только устройство выбрано, начинается зеркалирование, а основное воспроизведение продолжается без прерываний. Повторное нажатие сочетания останавливает зеркалирование.

**Варианты использования:**
- **Колонки + наушники** — Гость может слушать ту же трансляцию в наушниках, пока вы слушаете через колонки компьютера.
- **Настройка записи** — Направьте основной выход на колонки, а второй выход на внешний рекордер или аудиоинтерфейс для внешней записи.
- **Мультирум** — Воспроизводите через Bluetooth-колонку и встроенные динамики одновременно; не требуется дополнительного программного обеспечения для передачи звука в другую комнату.
- **Удалённый мониторинг** — В сеансе демонстрации экрана или удалённого рабочего стола и локальная, и удалённая стороны могут слышать один и тот же поток одновременно.

## Режим фоновой музыки (Obligato)

Сочетание `Ctrl+Win+Shift+M` тихо воспроизводит избранную станцию в фоновом режиме на полностью отдельном звуковом движке, независимом от основного плеера — как мягкий музыкальный фон, звучащий под тем, чем вы фактически занимаетесь.

При первом нажатии открывается диалог с тремя элементами управления:

- **Фоновая станция** — список ваших избранных станций, из которого выбирается та, что будет зациклена в фоне. Требуется как минимум одна избранная станция; если список избранного пуст, freeAudio предложит сначала добавить станцию (`Ctrl+Win+V` во время воспроизведения станции).
- **Аудиовыход** — устройство, через которое воспроизводится фоновая станция: **Такое же, как основной выход** (по умолчанию), **Устройство по умолчанию**, или любое конкретное устройство, которое видит freeAudio.
- **Громкость фона** — насколько громко играет фоновая станция, в процентах от текущей громкости основного плеера (25%, 50%, 75%, 100%, 125% или 150%). Ваш выбор запоминается на следующий раз.

После запуска фоновая станция продолжает играть независимо от основного плеера — переключение станции, подкаста или аудиокниги в основном плеере, или его полная остановка, никогда не прерывают режим Obligato. При этом две вещи автоматически остаются связанными с основным плеером:

- **Громкость** — громкость фона постоянно поддерживается на выбранном проценте от текущей громкости основного плеера, поэтому увеличение или уменьшение основной громкости (`Ctrl+Win+↑`/`↓`) изменяет фоновую музыку в той же пропорции.
- **Пауза** — постановка основного плеера на паузу (`Ctrl+Win+P`) также ставит на паузу фоновую станцию, а возобновление основного плеера возобновляет и её. Полная остановка основного плеера не считается паузой, поэтому фоновая станция продолжает играть.

Нажмите `Ctrl+Win+Shift+M` ещё раз в любой момент, чтобы остановить режим Obligato.

## Запись

Записи сохраняются в `Documents\freeAudio Recordings\` по умолчанию. Имя файла включает название станции (или название песни в режиме записи песни) и время начала записи. Папку записей можно изменить в любое время через меню NVDA → Параметры → Настройки → freeAudio → **Папка записей**.

Настройка **Формат вывода записей** определяет, как сохраняются завершённые записи:
- **Исходный формат потока** записывает поток точно так, как он был получен. Вещание HLS может поэтому создать файл `.ts`.
- **Только аудио, исходный кодек** удаляет слой видео/контейнера без перекодирования аудио. Например, аудио AAC из записи HLS `.ts` обычно сохраняется как `.m4a` с сохранением качества вещания.
- **MP3** преобразует аудио после записи с использованием выбранного битрейта. Преобразование использует `ffmpeg.exe`, поставляемый с freeAudio, и выполняется в фоновом режиме, чтобы NVDA оставался отзывчивым. Если преобразование не удалось, исходная запись сохраняется.

**Мгновенная запись:** Пока станция играет, нажмите `Ctrl+Win+E` один раз. Нажмите снова, чтобы остановить. Воспроизведение продолжается без прерываний на протяжении всего процесса.

**Запись песни:** Нажмите `Ctrl+Win+E` **дважды** подряд, пока играет станция, которая передаёт ICY-метаданные. Запись начинается немедленно и называется по текущему названию трека. Когда трек меняется, запись автоматически останавливается, и NVDA объявляет сохранённое имя файла. Если вы хотите закончить запись досрочно, до окончания трека, снова нажмите `Ctrl+Win+E` дважды. Если текущая станция не передаёт ICY-метаданные, запись песни недоступна, и NVDA сообщит вам об этом.

**Запланированная запись:** Откройте вкладку «Запись» в обозревателе станций. Выберите станцию из вашего избранного, введите время начала в формате ЧЧ:ММ и продолжительность в минутах, выберите один или несколько активных дней, затем задайте режим повтора и режим записи:

Поле **Фильтр** над списком станций позволяет сузить список избранного в реальном времени, чтобы быстро найти станцию, которую хотите запланировать.

**Активные дни:** Отметьте один или несколько дней недели. В режиме однократной записи для каждого выбранного дня создаётся отдельная запись, установленная на ближайшее наступление этого дня. В режиме повтора запись выполняется только в отмеченные дни. Если дни не выбраны, запись не ограничивается конкретными днями.

**Режим повтора:**
- **Записать один раз** — создаёт однократную запись для каждого выбранного дня. Каждая запись устанавливается на ближайшее наступление этого дня; если сегодняшнее время уже прошло, запись автоматически переносится на следующую неделю.
- **Повторять еженедельно** — повторяется каждую неделю в выбранные активные дни до удаления из списка расписания.

**Сохранить запись в:** Для каждой запланированной записи вы можете выбрать сохранение в папку записей по умолчанию или в пользовательскую папку. Используйте кнопку **Обзор...**, чтобы выбрать папку интерактивно. Если выбранная папка становится недоступной, запись сохраняется в папку по умолчанию, и вы уведомляетесь об этом.

**Режим записи:**
- **Записывать во время прослушивания** — воспроизводит и записывает одновременно через движок BASS.
- **Только запись** — записывает в фоновом режиме без вывода звука; механизм записи подключается непосредственно к потоку.

После добавления расписания оно появляется в списке ниже. Используйте кнопку **Удалить выбранное** для удаления расписания или **Изменить выбранное** для изменения его времени, продолжительности, повтора, активных дней, режима записи или папки вывода.

NVDA объявляет, когда запись начинается и когда заканчивается. Если NVDA перезапускается во время активной запланированной записи, запись автоматически возобновляется при запуске.

Как и распознавание музыки, мгновенная запись и запись трека повторно используют уже существующее фоновое соединение с потоком freeAudio, когда оно доступно, вместо того чтобы открывать новое, — благодаря этому запись фиксирует то, что реально звучит в эфире, даже на станциях, которые иначе проиграли бы свежую рекламу новому подключению. Это не относится к запланированным записям в режиме **«Только запись»**, поскольку в момент их начала ни одна станция ещё не воспроизводится.

## Тайм-шифт (перемотка живого радио)

Тайм-шифт позволяет перематывать слушаемую станцию, как DVR или кассета — поставьте на паузу, вернитесь на несколько минут назад и догоните прямой эфир, когда захотите. Воспроизведение при этом не останавливается: перемотка назад и вперёд происходит мгновенно на том же аудиопотоке.

Функция **отключена по умолчанию**. Включите её в меню NVDA → Параметры → Настройки → freeAudio → **Включить буфер тайм-шифта (перемотка прямого радио)**, или мгновенно переключайте в любой момент с помощью `Ctrl+Win+T`.

> **Примечание:** теперь freeAudio всегда поддерживает небольшой фоновый захват текущей воспроизводимой станции — не только когда эта настройка включена — потому что и Распознавание музыки, и Запись полагаются на него для избегания рекламы, описанного в этих разделах. Когда эта настройка **отключена**, фоновый захват ограничен примерно последними 45 секундами, а `Ctrl+Win+J`/`Ctrl+Win+K` остаются недоступны — меняется только размер буфера, а не то, работает ли он. Включение настройки увеличивает тот же захват до полного буфера перемотки, описанного ниже.

### Как это работает

После включения freeAudio непрерывно записывает воспроизводимую станцию в скользящий локальный буфер в фоне. Буфер хранит примерно **последние 10 минут** звука; старый звук автоматически вытесняется с начала по мере поступления нового, поэтому буфер всегда представляет «ближайшее прошлое» относительно края прямого эфира. Время буфера определяется в настройках.

- **`Ctrl+Win+J`** — Перемотать на 15 секунд назад. Первое нажатие переключает вас с прямого воспроизведения в режим тайм-шифта, начиная с 15 секунд позади края прямого эфира. Каждое следующее нажатие перематывает ещё на 15 секунд назад, до предела буфера.
- **`Ctrl+Win+K`** — Перемотать на 15 секунд вперёд в режиме тайм-шифта. Достигнув края прямого эфира, воспроизведение автоматически переключается обратно на прямой поток, и NVDA объявляет «Вернуться к прямому эфиру».
- **`Ctrl+Win+T`** — Включает или выключает всю функцию. Выключение в режиме тайм-шифта немедленно возвращает в прямой эфир и останавливает фоновую запись для текущей станции.

Фоновая запись продолжается всё время, пока активен тайм-шифт, поэтому край прямого эфира продолжает двигаться вперёд, даже когда вы слушаете что-то из нескольких минут назад — точно как настоящий DVR.

### Включение и прогрев буфера

Буфер начинает заполняться, как только станция начинает играть (при включённой функции) или в момент, когда вы включаете функцию во время прослушивания станции. Поэтому перемотка возможна только после того, как реально накоплено несколько секунд звука — если нажать `Ctrl+Win+J` сразу после переключения станций, NVDA сообщит, что в буфере пока недостаточно звука. Просто подождите несколько секунд и попробуйте снова.

Переключение на другую станцию всегда перезапускает буфер для новой станции; буферизованный звук предыдущей станции удаляется.

### Поддерживаемые потоки

Тайм-шифт работает с тем же диапазоном потоков, которые уже поддерживает freeAudio:

- Обычные HTTP/HTTPS-потоки (MP3, AAC, OGG и др.), включая серверы в стиле Shoutcast/Icecast.
- **HLS-потоки (`.m3u8`)** — freeAudio разрешает основной плейлист станции, следит за медиаплейлистом и загружает сегменты в фоне, чтобы буфер оставался заполненным.

В редком случае, когда плейлист станции невозможно прочитать вообще (например, повреждённый или недоступный манифест `.m3u8`), NVDA сообщит, что перемотка недоступна для данной конкретной станции.

### Требования и ограничения

- **Требует бэкенд BASS**, который freeAudio всегда использует для воспроизведения (см. [Воспроизведение](#воспроизведение)).
- Время буфера определяется в настройках.
- Буфер привязан к станции: смена станции, остановка воспроизведения или перезапуск NVDA очищают его и начинают заново.
- Воспроизведение с тайм-шифтом использует собственный локальный файл буфера и не создаёт сохранённой записи — если хотите сохранить звук навсегда, используйте также Мгновенную запись (`Ctrl+Win+E`).

## Таймер

Откройте вкладку «Таймер» в обозревателе станций (`Alt+4`). Можно добавить два типа таймеров:

При выборе станции для таймера будильника поле **Фильтр** над списком станций позволяет сузить список избранного в реальном времени.

**Будильник — включить радио:** Автоматически начинает воспроизводить выбранную станцию из избранного в указанное время. Выберите станцию и введите время в формате ЧЧ:ММ.

**Сон — выключить радио:** Останавливает воспроизведение в указанное время. Когда таймер срабатывает, громкость постепенно уменьшается в течение 60 секунд перед остановкой воспроизведения. Выбирать станцию не нужно; просто введите время.

Для обоих типов, если введённое время уже прошло, действие планируется на следующий день. Если в то же время уже существует таймер (независимо от типа), добавление нового заблокировано; пользователь получает уведомление о конфликте и предложение сначала удалить существующую запись. Ожидающие таймеры перечислены на вкладке; выберите один и нажмите кнопку «Удалить выбранный таймер», чтобы отменить его.

**Повторяющиеся таймеры:** В разделе **Повтор** выберите **Повторять еженедельно** вместо стандартного однократного варианта, чтобы таймер срабатывал каждую неделю, а не один раз. Список флажков **Активные дни** затем позволяет выбрать, в какие дни недели он повторяется; если оставить все дни неотмеченными, он повторяется каждый день. Повторяющийся таймер продолжает срабатывать по расписанию, пока вы не удалите его из списка ожидающих таймеров — это не однократная запись, исчезающая после срабатывания.

## Подкасты

freeAudio включает полнофункциональный плеер подкастов. Вы можете подписываться на любую RSS- или Atom-ленту подкаста, просматривать эпизоды, воспроизводить их, скачивать и возобновлять воспроизведение с того места, где остановились — всё это полностью доступно.

### Доступ к вкладке «Подкасты»

Откройте обозреватель станций с помощью `Ctrl+Win+R` и переключитесь на вкладку **Подкасты** с помощью `Ctrl+Tab` или `Alt+6`. Вкладка организована в три основные области:

1. **Поиск и добавление** — верхняя секция для поиска новых подкастов, включая список предпросмотра, показывающий эпизоды выбранного в данный момент результата поиска.
2. **Подписки** — список ваших подписанных лент.
3. **Эпизоды** — список эпизодов выбранной ленты с элементами управления воспроизведением.

### Добавление ленты подкаста

Вы можете добавить ленту подкаста двумя способами:

**По URL:**
- В поле **Поиск** вставьте полный URL RSS- или Atom-ленты (например, `https://example.com/feed.xml`).
- Нажмите Enter.
- freeAudio получает ленту, проверяет её и добавляет в ваши подписки. Если лента действительна, вы услышите подтверждение с названием ленты. Если это не удастся, сообщение об ошибке объяснит причину.

**Через поиск:**
- В поле **Поиск** введите ключевое слово (название подкаста, тему или имя ведущего) и нажмите Enter.
- freeAudio ищет в каталоге подкастов iTunes и отображает подходящие подкасты в списке **Результаты поиска**.
- Выбор результата загружает эту ленту в фоновом режиме и перечисляет её эпизоды в списке **Эпизоды выбранного результата** прямо под ним, чтобы вы могли ознакомиться с тем, что на самом деле содержит передача, прежде чем решить подписаться.
- Как только вас устроит увиденное, выберите результат и либо нажмите `Enter`, либо откройте его контекстное меню (клавиша «Приложения» / `Shift+F10`, или щелчок правой кнопкой мыши) и выберите **Подписаться**, чтобы добавить его в подписки. Лента добавляется немедленно и появляется в списке подписок. Отдельной кнопки «Добавить выбранное из поиска» нет — `Enter` или контекстное меню являются единственным способом подписаться на результаты поиска.

> **Совет:** Вы также можете ввести URL ленты прямо в поле поиска — если он выглядит как действительный URL, дополнение попытается добавить его как ленту без поиска.

**Контекстное меню для результатов поиска:** Щёлкните правой кнопкой мыши по результату поиска, или выберите его и нажмите клавишу «Приложения» / `Shift+F10`, чтобы открыть меню с единственным действием **Подписаться**, идентичным нажатию `Enter` на результате.

### Прослушивание эпизодов перед подпиской

Прежде чем подписываться, вы можете прослушать эпизоды подкаста прямо из результатов поиска. Всякий раз, когда вы выбираете подкаст в списке **Результаты поиска**, freeAudio загружает эту ленту и показывает её эпизоды — название и дату публикации — в списке **Эпизоды выбранного результата** ниже.

- Выберите эпизод в этом списке предпросмотра и нажмите `Enter`, или откройте его контекстное меню (клавиша «Приложения» / `Shift+F10`, или щелчок правой кнопкой мыши) и выберите **Прослушать**, чтобы начать воспроизведение через обычный плеер. Все обычные элементы управления воспроизведением (пауза, громкость, тайм-шифт и т. д.) работают на нём точно так же, как на любой другой станции или эпизоде.
- Пока эпизод прослушивается, то же контекстное меню показывает **Остановить прослушивание** вместо **Прослушать** — выберите его, или снова нажмите `Enter` на этом эпизоде, чтобы остановить.
- Прослушивание не подписывает вас ни на что; оно предназначено исключительно для прослушивания перед принятием решения. Сам список предпросмотра временный — он заменяется, как только вы выбираете другой результат поиска, и не сохраняется нигде так, как сохраняются ваши реальные подписки.

### Управление подписками

После добавления нескольких лент они появляются в списке **Подписки**. Каждая запись показывает название ленты и количество доступных эпизодов.

- **Выберите ленту**, чтобы увидеть её эпизоды в нижнем списке. Текстовое поле только для чтения **Сведения о ленте** под списком подписок показывает название ленты, автора, описание, количество эпизодов и URL.
- **Обновить ленту** — выберите её и нажмите кнопку **Обновить ленту** (доступна также через контекстное меню, см. ниже), чтобы получить последние эпизоды. Все ленты также автоматически обновляются в фоновом режиме при открытии вкладки «Подкасты», поэтому вы обычно видите самые свежие эпизоды без ручного вмешательства.
- **Удалить ленту** — выберите её и нажмите `Delete` или используйте контекстное меню, чтобы удалить её из подписок. Перед удалением у вас запросят подтверждение.

**Контекстное меню для лент:** Щёлкните правой кнопкой мыши по ленте, или выберите её и нажмите клавишу «Приложения» / `Shift+F10`, чтобы открыть меню с пунктами:
- **Обновить ленту** — получить новые эпизоды сейчас.
- **Сохранить аудиопрофиль для этого подкаста** / **Очистить аудиопрофиль** — см. [Аудиопрофиль подкаста](#аудиопрофиль-подкаста).
- **Удалить ленту** — удалить подписку.
- **Копировать URL ленты** — скопировать URL ленты в буфер обмена.

### Просмотр и воспроизведение эпизодов

Выберите ленту в списке подписок; её эпизоды появятся в списке **Эпизоды** ниже. Каждый эпизод показывает:
- Свой номер эпизода (1 = самый старый эпизод в ленте, с возрастанием до самого нового).
- Дату публикации (если доступна).
- Своё название.
- Префикс **«Прослушано»**, если эпизод был полностью воспроизведён.
- Суффикс продолжительности — либо общую продолжительность (если никогда не воспроизводился), либо прошедший/общий прогресс (если воспроизведён частично).

**Воспроизведение:**
- Выберите эпизод и нажмите `Enter` или `Пробел`, чтобы начать воспроизведение. Если эпизод ранее был воспроизведён частично, он возобновляется с того места, где вы остановились.
- Строка *не* обновляется во время воспроизведения эпизода — это сделано намеренно, чтобы NVDA не объявлял строку повторно, пока вы на ней находитесь. Её флаг «Прослушано» и продолжительность обновляются немедленно в момент, когда вы ставите эпизод на паузу или он заканчивается, поэтому отображение всегда точное именно тогда, когда это важно; оно просто не растёт секунда за секундой во время воспроизведения.
- Используйте `F3` / `F4` на вкладке «Подкасты», чтобы перейти к предыдущему / следующему эпизоду и сразу воспроизвести его. Вы также можете использовать `←` / `→`, когда в фокусе находится список эпизодов, или `Ctrl+←` / `Ctrl+→` в любом месте вкладки «Подкасты» — оба варианта работают одинаково.
- Используйте `Shift+F3` / `Shift+F4` для перехода между лентами без воспроизведения эпизодов.
- Нажмите `Пробел` во время воспроизведения эпизода, чтобы поставить на паузу или возобновить воспроизведение.

**Возобновление воспроизведения:** freeAudio автоматически сохраняет вашу позицию в каждом эпизоде подкаста — немедленно при паузе или завершении эпизода, а также каждые 15 секунд в фоновом режиме, пока вы продолжаете слушать, поэтому сбой или неожиданный перезапуск не приведут к значительной потере прогресса. Если вы останавливаете или ставите воспроизведение на паузу и возвращаетесь позже, эпизод возобновляется с сохранённой позиции. Если вы дослушаете эпизод до самого конца (в пределах последних 3 секунд), он помечается как «Прослушано» и не будет возобновляться — в следующий раз он начнётся с начала, и в списке появится префикс «Прослушано».

**Контекстное меню для эпизодов:** Щёлкните правой кнопкой мыши по эпизоду, или выберите его и нажмите клавишу «Приложения» / `Shift+F10`, чтобы открыть меню с пунктами:
- **Воспроизвести эпизод** — начать воспроизведение.
- **Скачать эпизод** — скачать файл эпизода в вашу папку записей.
- **Сохранить аудиопрофиль для этого подкаста** / **Очистить аудиопрофиль** — те же команды, что и в собственном контекстном меню ленты, включённые здесь для удобства, чтобы не приходилось возвращаться к списку подписок. Они по-прежнему сохраняют один профиль для всего подкаста, а не отдельный для этого эпизода — см. [Аудиопрофиль подкаста](#аудиопрофиль-подкаста).
- **Копировать URL эпизода** — скопировать прямой URL аудио в буфер обмена.

### Скачивание эпизодов

Выберите эпизод и нажмите кнопку **Скачать эпизод** (или используйте контекстное меню). Эпизод скачивается в вашу папку записей (`Документы\freeAudio Recordings\` по умолчанию). Имя файла основано на названии эпизода и определённом расширении файла (`.mp3`, `.m4a`, `.ogg` и т. д.). NVDA объявляет о начале и завершении загрузки. Если файл уже существует, вы получаете уведомление, и загрузка пропускается.

### Фильтрация эпизодов

Над списком эпизодов находится поле **Фильтр**. По мере ввода список эпизодов фильтруется в реальном времени, показывая эпизоды, название которых содержит введённый текст, или номер которых точно ему соответствует — так что ввод `47` сразу переходит к эпизоду 47, даже если «47» нигде не встречается в его названии. NVDA объявляет количество совпадающих эпизодов после каждого изменения. Нажмите стрелку `Вниз` из поля фильтра, чтобы переместить фокус непосредственно в отфильтрованный список.

### Подробности воспроизведения подкастов

Эпизоды подкастов воспроизводятся с помощью **движка BASS** (того же движка, что используется для радиопотоков, и, начиная с этой версии, единственного движка воспроизведения, который использует freeAudio). Поскольку эпизоды скачиваются постепенно и допускают перемотку, вы можете использовать сочетания клавиш перемотки назад/вперёд тайм-шифта (`Ctrl+Win+J`/`Ctrl+Win+K`) во время воспроизведения подкаста для перемотки внутри эпизода. Позиция сохраняется автоматически, чтобы вы могли возобновить воспроизведение позже.

**Ступенчатая перемотка:** В отличие от фиксированной 15-секундной перемотки живого радио, перемотка внутри подкаста, аудиокниги или трека джукбокса масштабируется в зависимости от того, как вы нажимаете клавишу, что позволяет сделать небольшую коррекцию или перепрыгнуть на большое расстояние без повторных нажатий:

- **Удержание клавиши** (автоповтор) перематывает на **5 секунд** за повтор — то же небольшое значение, которое это сочетание клавиш всегда использовало для файлов.
- **Одно осознанное нажатие** перематывает на **12 секунд**.
- **Два нажатия** подряд быстро перематывают на **1 минуту**.
- **Три и более нажатий** перематывают на **5 минут**; дальнейшие нажатия в той же серии больше не увеличивают значение.

Осознанное нажатие удерживается краткий момент, прежде чем действительно произойдёт перемотка, на случай, если последует ещё одно нажатие — на каждую серию нажатий приходится только одна перемотка, размер которой соответствует тому, сколько нажатий в итоге было сделано, а не сумме значений каждого нажатия. После перемотки NVDA объявляет итоговую прошедшую/оставшуюся позицию в эпизоде, а не просто «X секунд вперёд/назад».

**Скорость воспроизведения:** Вы можете регулировать скорость воспроизведения эпизодов подкастов, аудиокниг и треков джукбокса с помощью `Ctrl+Win+Shift+K` (быстрее) и `Ctrl+Win+Shift+J` (медленнее). Скорость изменяется с шагом 0,1×, в диапазоне от 0,5× до 2,0×, с сохранением высоты тона.

**Транспонирование (сдвиг высоты тона):** Независимо от скорости воспроизведения, вы можете сдвинуть высоту тона эпизода подкаста, аудиокниги или трека джукбокса вверх или вниз с помощью `Shift+Win+K` / `Shift+Win+J` — см. [Транспонирование (сдвиг высоты тона)](#транспонирование-сдвиг-высоты-тона).

**Звуковой эффект возобновления:** Всякий раз, когда эпизод возобновляется с сохранённой позиции, freeAudio кратко проигрывает мягкий звуковой эффект загрузки кассеты на отдельном канале, пока перематывает к вашей сохранённой точке, вместо того чтобы позволить звуку самого эпизода слышимо звучать с 0:00 в это время. Это не зависит от настройки **Переход при смене станции** — эта настройка влияет только на переключение между живыми радиостанциями, а не на возобновление подкастов или аудиокниг.

### Аудиопрофиль подкаста

Щёлкните правой кнопкой мыши по подкасту в списке подписок, или щёлкните правой кнопкой мыши по любому из его эпизодов, и выберите **Сохранить аудиопрофиль для этого подкаста**, чтобы сохранить текущую громкость, эффекты, усиление эквалайзера и/или скорость воспроизведения как профиль, привязанный к этому подкасту. Всякий раз, когда воспроизводится любой эпизод этого подкаста, сохранённые настройки применяются автоматически, переопределяя глобальные значения по умолчанию. Поскольку команда доступна как из контекстного меню ленты, так и из контекстного меню эпизода, вы можете получить к ней доступ, не возвращаясь к списку подписок — в любом случае всегда сохраняется один профиль для всего подкаста, а не отдельный для каждого эпизода.

Диалоговое окно с 15 вариантами позволяет вам выбрать, что именно сохранить:
- **Только громкость**
- **Только эффекты**
- **Громкость и эффекты**
- **Громкость и скорость воспроизведения**
- **Эффекты и скорость воспроизведения**
- **Только скорость воспроизведения**
- **Громкость, эффекты и скорость воспроизведения**
- **Только транспонирование**
- **Громкость и транспонирование**
- **Эффекты и транспонирование**
- **Скорость воспроизведения и транспонирование**
- **Громкость, эффекты и транспонирование**
- **Громкость, скорость воспроизведения и транспонирование**
- **Эффекты, скорость воспроизведения и транспонирование**
- **Громкость, эффекты, скорость воспроизведения и транспонирование**

В профиль записываются только выбранные вами части; всё, что не выбрано, сохраняет то, что уже было сохранено ранее. Например, выбор **Только скорость воспроизведения** для подкаста, у которого уже есть сохранённый профиль громкости/эффектов, обновляет только скорость, оставляя остальное без изменений.

**Очистить аудиопрофиль** удаляет сохранённый профиль подкаста из любого из двух меню. Опция активна только тогда, когда у подкаста в данный момент есть сохранённый профиль.

### Хранение данных подкастов

Ваши подписки хранятся в `freeAudio_podcasts.json` в папке пользовательской конфигурации NVDA. Позиции эпизодов хранятся отдельно в `podcast_positions.json` в том же месте. Оба файла представляют собой обычный JSON и могут быть скопированы для резервного копирования или перенесены на другой компьютер.

## Аудиокниги (GETEM, LibriVox и Project Gutenberg)

freeAudio включает плеер аудиокниг, который ищет, воспроизводит и скачивает книги из трёх источников:

- **[GETEM](https://getem.boun.edu.tr/)** — цифровая библиотека, управляемая Центром для людей с нарушениями зрения Университета Богазичи. Для трансляции или скачивания аудио книги требуется бесплатное членство (просмотр — нет) — см. [Вход в систему](#вход-в-систему) ниже.
- **[LibriVox](https://librivox.org/)** — проект аудиокниг общественного достояния, начитанных добровольцами. Не требуется никакой учётной записи или входа в систему какого-либо рода; весь его каталог, включая сами аудиофайлы, является общественным достоянием и открыто доступен.
- **Коллекция открытых аудиокниг Project Gutenberg** — аудиокниги общественного достояния, начитанные людьми и сгенерированные компьютером, размещённые на [archive.org](https://archive.org/), дополнение к текстовой библиотеке Project Gutenberg. Как и LibriVox, не требует учётной записи или входа в систему.

Результаты из всех трёх источников появляются вместе в едином объединённом списке **Результаты поиска** и едином объединённом списке **Библиотека** — отдельной вкладки или выпадающего списка для переключения между ними нет. Источник каждой книги (GETEM, LibriVox или Project Gutenberg) отображается в виде метки рядом с её названием и в её сведениях, поэтому вы всегда можете определить, на что смотрите. Вы можете искать, прослушивать, добавлять, воспроизводить и скачивать книги из любого источника совершенно одинаковым образом; воспроизводить многочастные произведения с автоматическим продолжением между частями; и скачивать книги для прослушивания в автономном режиме — всё это полностью доступно.

Любой из источников можно отключить отдельно в **Меню NVDA → Настройки → Параметры → freeAudio** с помощью списка флажков **Источники аудиокниг**, если вы хотите искать только в некоторых из них. По умолчанию все три включены.

> **Примечание:** Для прослушивания книги с GETEM требуется бесплатное членство в GETEM. Для просмотра каталога GETEM учётная запись не требуется, но для получения и воспроизведения аудио книги с GETEM она нужна — см. [Вход в систему](#вход-в-систему) ниже. Книги LibriVox и Project Gutenberg никогда не требуют учётной записи.

### Доступ к вкладке «Аудиокниги»

Откройте обозреватель станций с помощью `Ctrl+Win+R` и переключитесь на вкладку **Аудиокниги** с помощью `Ctrl+Tab` или `Alt+7`. Вкладка имеет три основные области:

1. **Поиск** — текстовое поле для поиска сразу по всем включённым каталогам, со списком результатов, который появляется после выполнения поиска.
2. **Библиотека** — список книг, которые вы добавили из любого источника, где вы их воспроизводите, скачиваете и управляете ими.
3. **Сведения** — поле только для чтения, показывающее источник, название, автора, чтеца, издателя, формат, количество частей, описание и URL каталога выбранной книги в любом из списков.

### Вход в систему

GETEM требует быть зарегистрированным участником для трансляции или скачивания реального аудио книги, хотя сам каталог можно свободно просматривать. Введите своё имя пользователя и пароль GETEM один раз в **Меню NVDA → Настройки → Параметры → freeAudio**; они хранятся в зашифрованном виде на диске (через Windows Data Protection API, привязанный к вашей учётной записи пользователя Windows) и впоследствии используются автоматически. Если вы попытаетесь воспроизвести или скачать книгу с GETEM до ввода учётных данных, freeAudio предложит вам сначала добавить их в настройках.

LibriVox и Project Gutenberg вообще не требуют какого-либо входа в систему — их результаты и аудио можно искать, прослушивать, воспроизводить и скачивать немедленно, без ввода каких-либо учётных данных.

### Поиск аудиокниг

Введите поисковый запрос в поле поиска и нажмите `Enter`. freeAudio ищет по источникам, включённым в настройках, и объединяет результаты в один список:

- **GETEM** ищется одновременно по названию, автору, чтецу, теме и издателю, поскольку собственная форма поиска GETEM поддерживает сужение по всем этим полям вместе, а не отдельный поиск по любому из них. Показываются только произведения, действительно доступные в аудиоформате (человеческая или компьютерная озвучка, аудиоописание, радиопостановка, говорящие книги DAISY и т. д.); брайль, крупный шрифт и другие неаудио форматы автоматически отфильтровываются.
- **LibriVox** ищется по названию или автору/чтецу в своём каталоге общественного достояния.
- **Project Gutenberg** ищется по названию или автору в коллекции открытых аудиокниг на archive.org.

Вставка URL страницы каталога/сведений книги прямо в поле поиска (страница каталога GETEM или страница «details» archive.org для книги LibriVox или Project Gutenberg) разрешает эту конкретную книгу напрямую вместо выполнения поиска по ключевым словам.

NVDA объявляет, сколько аудиокниг было найдено всего.

Выбор результата показывает его сведения — автора, чтеца, издателя, формат и количество частей — в поле сведений ниже.

**Прослушивание:** Выберите результат и нажмите `Пробел`, или откройте его контекстное меню (клавиша «Приложения» / `Shift+F10`, или щелчок правой кнопкой мыши) и выберите **Прослушать**, чтобы начать воспроизведение с первой части, не добавляя книгу в вашу библиотеку. Пока книга прослушивается, то же контекстное меню показывает **Остановить прослушивание** вместо неё — выберите его, или снова нажмите `Пробел`, чтобы остановить. Прослушивание не сохраняет вашу позицию, поскольку она отслеживается только для книг, уже находящихся в вашей библиотеке.

**Добавление в библиотеку:** Выберите результат и нажмите `Enter`, или используйте его контекстное меню и выберите **Добавить в библиотеку**, чтобы добавить его. freeAudio сообщит вам, если книга уже там есть.

### Ваша библиотека

Добавленные вами книги появляются в списке **Библиотека**, показывая название, автора и формат. Выбор одной из них показывает её сведения ниже.

- Нажмите `Enter` или `Пробел`, чтобы воспроизвести выбранную книгу. Если ничего не загружено, `Пробел` запускает её; если что-то уже воспроизводится, `Пробел` вместо этого ставит его на паузу, в соответствии с остальной частью плеера.
- Используйте `F3` / `F4` на вкладке «Аудиокниги», чтобы перейти к предыдущей / следующей **книге** в вашей библиотеке и начать её воспроизведение. `Ctrl+←` / `Ctrl+→` делают то же самое, когда в фокусе находится список библиотеки.
- Используйте `Shift+F3` / `Shift+F4`, чтобы вместо этого перемещаться между **частями** воспроизводимой в данный момент книги — это обратно вкладке «Подкасты», где F3/F4 перемещаются между эпизодами, а Shift+F3/F4 — между лентами. Это потому, что книга является единой записью библиотеки, даже когда у неё несколько частей, поэтому более детальная навигация «по частям» здесь размещена на клавишах с модификатором Shift.

**Контекстное меню для записей библиотеки:** Щёлкните правой кнопкой мыши по книге, или выберите её и нажмите клавишу «Приложения» / `Shift+F10`, чтобы открыть меню с пунктами:
- **Воспроизвести медиа** — начать воспроизведение, то же самое, что и `Enter`.
- **Скачать книгу** — скачать все части книги; см. [Скачивание аудиокниг](#скачивание-аудиокниг) ниже.
- **Копировать URL** — скопировать URL страницы каталога книги в буфер обмена (страницу каталога GETEM для книги с GETEM или страницу сведений archive.org для книги с LibriVox или Project Gutenberg).
- **Сохранить аудиопрофиль для этой книги** / **Очистить аудиопрофиль** — см. [Аудиопрофиль аудиокниги](#аудиопрофиль-аудиокниги) ниже.
- **Удалить из библиотеки** — удалить книгу из вашей библиотеки.

Вы также можете пометить несколько книг сразу и удалить их все вместе — см. [Пометка и удаление нескольких элементов](#пометка-и-удаление-нескольких-элементов) под Избранным.

### Воспроизведение и возобновление

Многочастное произведение рассматривается в плеере как единый элемент, а не отдельная строка для каждой части — так же, как эпизод подкаста является единым элементом независимо от того, как он доставляется. freeAudio запоминает, какую часть вы слушали последней, и автоматически возобновляет с неё в следующий раз, когда вы воспроизводите эту книгу, даже после перезапуска NVDA.

Когда одна часть заканчивается, freeAudio автоматически запускает следующую часть той же книги — вам не нужно выбирать её вручную. Это происходит, даже если окно обозревателя станций в этот момент закрыто; часть «сейчас воспроизводится», показанная в списке «Библиотека», автоматически повторно синхронизируется при следующем открытии окна.

Воспроизведение транслируется через небольшое локальное реле, а не путём скачивания всей части сначала, поэтому прослушивание начинается сразу же, как только приходят первые байты — то же поведение немедленного старта, которое используют подкасты. Все обычные элементы управления плеера (пауза, громкость, тайм-шифт, скорость воспроизведения, транспонирование, устройство вывода и т. д.) работают с аудиокнигой точно так же, как со станцией или эпизодом подкаста.

Как и с подкастами, возобновление книги с сохранённой позиции проигрывает короткий звуковой эффект загрузки кассеты, пока freeAudio перематывает к вашей сохранённой точке — см. примечание **Звуковой эффект возобновления** в [Подробностях воспроизведения подкастов](#подробности-воспроизведения-подкастов).

### Аудиопрофиль аудиокниги

Щёлкните правой кнопкой мыши по книге в списке вашей библиотеки и выберите **Сохранить аудиопрофиль для этой книги**, чтобы сохранить текущую громкость, эффекты, усиление эквалайзера и/или скорость воспроизведения как профиль, привязанный к этой книге. Всякий раз, когда книга (или любая из её частей) воспроизводится, сохранённые настройки применяются автоматически, переопределяя глобальные значения по умолчанию. Это работает точно так же, как [Аудиопрофиль подкаста](#аудиопрофиль-подкаста) выше, включая тот же набор опций сохранения (громкость, эффекты и/или скорость воспроизведения, в любой комбинации) и то же поведение частичного обновления.

**Очистить аудиопрофиль** удаляет сохранённый профиль из книги; опция активна только тогда, когда у книги в данный момент есть сохранённый профиль.

### Скачивание аудиокниг

Выберите книгу в своей библиотеке и выберите **Скачать книгу** в её контекстном меню, чтобы сохранить каждую часть в её собственную папку (названную по книге) внутри вашей папки записей (`Документы\freeAudio Recordings\` по умолчанию). Файлы нумеруются так, чтобы части всегда сортировались обратно в порядок прослушивания, независимо от того, как их называет сам GETEM. NVDA объявляет, сколько частей было сохранено по завершении загрузки; если часть не удаётся скачать, последняя ошибка сообщается вместе со счётчиком.

### Хранение данных аудиокниг

Каждый источник хранит свой собственный файл библиотеки, хотя на вкладке «Аудиокниги» они отображаются объединёнными. Ваша библиотека GETEM (добавленные книги и прогресс прослушивания) хранится в `freeAudio_getem_library.json`, ваша библиотека LibriVox хранится отдельно в `freeAudio_librivox_library.json`, а ваша библиотека Project Gutenberg хранится отдельно в `freeAudio_gutenberg_library.json` — все три в папке пользовательской конфигурации NVDA. Ваши зашифрованные учётные данные GETEM хранятся отдельно в `freeAudio_getem_credentials.bin` в том же месте и могут быть расшифрованы только той же учётной записью пользователя Windows, которая их сохранила. У LibriVox и Project Gutenberg нет файла учётных данных, поскольку ни один из них не требует учётной записи.

## Локальный джукбокс

Вкладка **Джукбокс** в freeAudio даёт вам два способа воспроизведения аудиофайлов, которые уже есть на вашем компьютере: поиск по имени файла на всех подключённых дисках или создание постоянной личной библиотеки файлов и папок. Всё, что вы воспроизводите отсюда, получает ту же обработку, что и подкаст или аудиокнига — автоматическое возобновление, ступенчатая перемотка назад/вперёд, скорость воспроизведения, транспонирование высоты тона и аудиопрофили для отдельных элементов работают точно так же.

### Доступ к вкладке «Джукбокс»

Откройте обозреватель станций с помощью `Ctrl+Win+R` и переключитесь на вкладку **Джукбокс** с помощью `Ctrl+Tab` или `Alt+8`, или откройте её напрямую из любого места с помощью глобального сочетания `Ctrl+Win+U`. Вкладка организована в три основные области:

1. **Поиск на диске** — текстовое поле, которое ищет на всех локально подключённых, готовых дисках аудиофайлы, имя которых содержит введённый текст. Нажмите `Enter`, чтобы начать поиск.
2. **Результаты поиска** — список, который появляется после запуска поиска, показывая совпадающие файлы. Скрыт до этого момента, поэтому вкладка остаётся аккуратной, когда искать нечего.
3. **Джукбокс и треки** — постоянный список добавленных вами элементов, за которым следует список треков в выбранной записи (для записи-файла — только этот файл; для записи-папки — каждый аудиофайл, найденный внутри неё).

Кнопки **Добавить файл…**, **Добавить папку…**, **Удалить**, **Экспортировать джукбокс…** и **Импортировать джукбокс…** находятся под списком треков.

### Поиск файлов на диске

Введите любую часть имени файла в поле **Поиск на диске** и нажмите `Enter`. freeAudio проходит по всем локально подключённым дискам — жёстким дискам, USB-накопителям, картам памяти, подключённым сетевым дискам — в поисках аудиофайлов (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.m4b`, `.aac`, `.wma`, `.opus` и нескольких других), имя файла которых содержит поисковый текст. Поиск выполняется в фоновом режиме, поэтому NVDA остаётся отзывчивым.

- **Пробел** на результате поиска выполняет его предпросмотр — запускает воспроизведение через обычный плеер. Нажмите **Пробел** снова на том же файле, чтобы остановить предпросмотр.
- **Enter** на результате поиска добавляет его в ваш джукбокс.
- Контекстное меню (клавиша «Приложения» / `Shift+F10`, или щелчок правой кнопкой мыши) предлагает те же два действия: **Просмотр** / **Остановить просмотр** и **Добавить в джукбокс**.
- Запуск нового поиска отменяет любой ещё выполняющийся поиск, поэтому медленный поиск на большом диске никогда не задерживает новый.

### Создание вашего джукбокса

Список джукбокса — это ваша постоянная личная библиотека. Можно добавить два типа элементов:

- **Добавить файл…** — открывает выбор файлов, позволяющий добавить один или несколько отдельных аудиофайлов. Все выбранные файлы добавляются сразу.
- **Добавить папку…** — открывает выбор папок, позволяющий выбрать несколько папок сразу. Каждый аудиофайл, найденный внутри каждой выбранной папки, включая её подпапки, рассматривается как один из **треков** этой папки. Каждая папка добавляется как отдельная запись в списке джукбокса; файлы внутри неё перечислены в списке треков, когда папка выбрана. NVDA объявляет, сколько папок было добавлено, после закрытия выбора.
- **Удалить** — удаляет текущую выбранную запись из вашего джукбокса. Удаление записи-папки не удаляет никаких файлов с диска; оно просто забывает папку. Вы также можете пометить несколько записей сразу и удалить их все вместе — см. [Пометка и удаление нескольких элементов](#пометка-и-удаление-нескольких-элементов) под Избранным.

Ваш список джукбокса сохраняется автоматически, поэтому он переживает перезапуски NVDA. Содержимое папок сканируется по запросу и кэшируется, поэтому добавление папки мгновенно даже для очень больших коллекций — полное сканирование происходит при первом выборе этой папки. Если вы добавляете файлы в папку вне freeAudio, используйте пункт **Пересканировать папку** в контекстном меню папки, чтобы их обнаружить.

### Добавление элементов из Проводника Windows

Ещё две команды, доступные только когда в списке файлов Проводника Windows (список «Подробности»/«Значки» — не адресная строка, не дерево папок, не лента и не поле поиска) находится в фокусе файл или папка, позволяют полностью пропустить диалоги «Добавить файл…»/«Добавить папку…» выше:

- **Воспроизвести файл в фокусе в freeAudio** — воспроизводит выделенный аудиофайл напрямую, без необходимости, чтобы он уже был в вашем списке джукбокса. Работает только для файлов; при использовании на папке сообщает, что нужно добавить папку в джукбокс вместо этого.
- **Добавить элемент в фокусе в джукбокс freeAudio** — добавляет выделенный файл или папку в ваш список джукбокса, точно так же, как если бы вы использовали **Добавить файл…** или **Добавить папку…** выше.

Ни у одной из команд нет назначенного сочетания клавиш по умолчанию. Назначьте его в меню NVDA → Параметры → Жесты ввода → freeAudio, **находясь в фокусе внутри окна Проводника**.

### Воспроизведение из джукбокса

- **Enter** на записи джукбокса воспроизводит её напрямую: для записи-файла — сам файл; для записи-папки — её первый трек.
- **Пробел** на записи джукбокса ставит воспроизведение на паузу, если что-то играет; в противном случае воспроизводит выбранную запись.
- **Enter** или **Пробел** в списке треков воспроизводит выбранный трек. **Пробел** сначала ставит на паузу, если что-то уже играет.
- **F3 / F4** на вкладке джукбокса перемещаются между треками внутри текущей выбранной записи и воспроизводят немедленно.
- **Shift+F3 / Shift+F4** перемещаются между записями в списке джукбокса (файлы и папки), повторяя то, как эти клавиши перемещаются между лентами на вкладке «Подкасты».
- **Ctrl+← / Ctrl+→** при фокусе на списке записей или треков делают то же, что F3/F4 в списке треков — предыдущий / следующий трек.

### Подробности воспроизведения в джукбоксе

Каждый трек, воспроизводимый из джукбокса, получает полную обработку локального медиа:

- **Возобновление:** freeAudio запоминает вашу позицию в каждом треке, сохраняет её при паузе и периодически во время воспроизведения, и возобновляет с этой точки, когда вы воспроизводите его снова — даже после перезапуска NVDA.
- **Ступенчатая перемотка:** `Ctrl+Win+J` / `Ctrl+Win+K` перематывают внутри трека с тем же масштабированием нажатия/удержания, что и подкасты и аудиокниги — удержание на 5 секунд за повтор, одно нажатие на 12 секунд, два нажатия на 1 минуту, три или более нажатий на 5 минут.
- **Скорость воспроизведения:** `Ctrl+Win+Shift+J` / `Ctrl+Win+Shift+K` регулируют скорость шагами по 0,1× от 0,5× до 2,0×, с сохранением высоты тона.
- **Транспонирование:** `Shift+Win+J` / `Shift+Win+K` изменяют высоту тона без изменения скорости — см. [Транспонирование (сдвиг высоты тона)](#транспонирование-сдвиг-высоты-тона).
- **Аудиопрофиль:** Громкость, эффекты, эквалайзер и скорость трека можно сохранить глобально, воспроизведя трек с соответствующими настройками — джукбокс в настоящее время не предоставляет меню профиля для отдельных треков, поэтому применяются текущие глобальные настройки.

> **Примечание:** Буфер тайм-шифта (используемый для перемотки живого радио) намеренно **не** запускается для треков джукбокса — они уже являются локальными файлами с возможностью перемотки, поэтому фоновый захват не имеет смысла и только потреблял бы место на диске. Перемотка назад и вперёд всё равно работает, поскольку они действуют непосредственно на воспроизводимый файл.

### Переименование элементов джукбокса

Выберите **Переименовать…** в контекстном меню элемента джукбокса (клавиша «Приложения» / `Shift+F10`), чтобы задать ему собственное отображаемое имя. Это имя заменяет имя файла или папки в списке джукбокса и записывается в строку `#EXTINF` при экспорте элемента в M3U (см. [Экспорт и импорт библиотеки джукбокса](#экспорт-и-импорт-библиотеки-джукбокса) ниже). Оставьте поле пустым, чтобы удалить собственное имя и вернуться к исходному имени файла или папки.

### Организация джукбокса в группы

Элементы джукбокса могут принадлежать группе, что отображается суффиксом «— Группа» после названия элемента в списке, точно так же, как в разделе [Организация избранного в группы](#организация-избранного-в-группы):

- Пометьте один или несколько элементов с помощью `.` (см. [Пометка и удаление нескольких элементов](#пометка-и-удаление-нескольких-элементов) выше), затем выберите **Назначить группу…** в контекстном меню и введите имя группы. Оставьте поле пустым, чтобы удалить помеченные элементы из их группы. Если ничего не помечено, команда применяется к текущему выбранному элементу.
- Поле Фильтр над списком джукбокса также сопоставляется с именами групп — так же, как и в избранном.

### Изменение порядка в джукбоксе

Когда элемент выбран в списке джукбокса, нажмите `запятую`, чтобы войти в режим перемещения — вы услышите звуковой сигнал. Переместитесь на нужную позицию с помощью клавиш со стрелками, затем снова нажмите `запятую`. Элемент будет помещён на выбранную позицию, и новый порядок будет немедленно сохранён. Повторное нажатие `запятой` на той же позиции отменяет перемещение.

### Экспорт и импорт библиотеки джукбокса

Вкладка «Джукбокс» содержит две кнопки для резервного копирования и восстановления вашей библиотеки под списком треков:

**Экспортировать джукбокс…** — сохраняет весь список джукбокса в файл. В диалоге сохранения можно выбрать один из двух форматов:
- **JSON** (`.json`) — полная резервная копия, сохраняющая путь, собственное имя, группу и сохранённый аудиопрофиль каждого элемента. Рекомендуется для последующего восстановления библиотеки или переноса её на другой компьютер.
- **Плейлист M3U** (`.m3u`) — более простой формат, совместимый с большинством медиаплееров; перечисляет путь каждого элемента, а его собственное имя (если есть) записывается в предшествующей строке `#EXTINF`. Группы и аудиопрофили в M3U не включаются, поэтому при восстановлении из M3U эти данные теряются.

**Импортировать джукбокс…** — загружает элементы из ранее экспортированного файла JSON или M3U. После выбора файла предлагается выбрать способ добавления элементов:
- **Да (Объединить)** — добавляет импортируемые элементы к существующей библиотеке, не удаляя текущие элементы. Элементы, путь которых совпадает с уже имеющимся в библиотеке, повторно не добавляются.
- **Нет (Заменить)** — полностью очищает текущий список джукбокса и заменяет его содержимым импортируемого файла.
- **Отмена** — возвращает в браузер без внесения каких-либо изменений.

### Прямые горячие клавиши для элементов джукбокса

Каждый элемент вашего списка джукбокса зарегистрирован как отдельный скрипт в диалоге «Жесты ввода» NVDA, в категории **freeAudio Jukebox**, точно так же, как в разделе [Прямые горячие клавиши для станций из избранного](#прямые-горячие-клавиши-для-станций-из-избранного). Вы можете назначить любое сочетание клавиш любому элементу и нажимать его из любого места — без необходимости сначала открывать окно обозревателя.

Чтобы назначить сочетание:

1. Откройте меню NVDA → Параметры → Жесты ввода.
2. Разверните категорию **freeAudio Jukebox**.
3. Найдите элемент по названию, выберите его и нажмите **Добавить**.
4. Нажмите нужное сочетание клавиш и подтвердите.

Сочетание немедленно воспроизводит элемент — для файла сам файл, для папки её первый трек. Если элемент позже будет удалён из джукбокса, его запись исчезнет из категории, а назначенное сочетание будет автоматически удалено NVDA. При добавлении нового элемента он сразу появляется в категории — повторно открывать диалог «Жесты ввода» не нужно.

## Транспонирование (сдвиг высоты тона)

Транспонирование сдвигает **высоту тона** воспроизводимого содержимого вверх или вниз без изменения его **скорости** — противоположность «эффекту бурундука», который вы получили бы, просто ускорив трек. Это полезно для соответствия естественному диапазону конкретного чтеца, транспонирования музыки в более удобную тональность или просто настройки записи, чтобы она звучала комфортнее для ваших ушей.

Транспонирование доступно для **подкастов**, **аудиокниг** и **треков джукбокса** — тех же «локальных, перематываемых медиа с поддержкой темпа», к которым уже применяются сочетания клавиш скорости воспроизведения. Оно недоступно для живых радиостанций, у которых нет фиксированной высоты тона для сдвига.

- **`Shift+Win+K`** — Повышает высоту тона на один шаг.
- **`Shift+Win+J`** — Понижает высоту тона на один шаг.

Каждый шаг — **одна восьмая целого тона** — то есть **0,25 полутона** (целый тон — это 2 полутона, поэтому 8 шагов составляют целый тон, а 48 шагов — октаву). Диапазон — **−12,00 до +12,00 полутонов**, то есть одна полная октава вверх или вниз. NVDA объявляет новое значение после каждого шага, например «**+1,25 полутона**»; возврат к 0,0 объявляет «**Обычная высота тона**».

Транспонирование запоминается между треками, так же как и скорость воспроизведения: установив его один раз во время воспроизведения трека, следующий трек с поддержкой темпа, который вы воспроизведёте, начнётся с тем же сдвигом, если только его собственный сохранённый аудиопрофиль не переопределит это. Воспроизведение трека без сохранённого значения транспонирования сбрасывает сдвиг обратно на 0,0 (Обычная высота тона), как то же правило уже применяется к скорости.

## Понравившиеся треки

Когда включена опция **Сохранять понравившиеся треки в текстовый файл**, информация о треке, скопированная в буфер обмена троекратным нажатием `Ctrl+Win+I`, также добавляется построчно в `Documents\freeAudio Recordings\likedSongs.txt`.

На станциях, передающих ICY-метаданные, название трека и исполнитель сохраняются напрямую. На станциях без ICY-метаданных результат распознавания Shazam сохраняется в тот же файл — оба источника используют один общий список. Файл создаётся автоматически, если его не существует; каждая запись добавляется в конец файла, предыдущие записи никогда не удаляются.

## Вкладка «Понравившиеся треки»

Вкладка **«Понравившиеся треки»** в браузере станций отображает все треки, сохранённые в `likedSongs.txt`. Список автоматически перезагружается из файла каждый раз при открытии вкладки. Щёлкните правой кнопкой мыши по песне, или выберите её и нажмите клавишу «Приложения» / `Shift+F10`, чтобы открыть контекстное меню с теми же действиями, что описаны ниже.

Поле **Фильтр** над списком позволяет сужать отображаемые треки в реальном времени. Введите любую часть названия песни или имени исполнителя — список мгновенно обновляется после каждого нажатия клавиши. NVDA объявляет количество совпадающих результатов после каждого изменения. Нажмите стрелку `Вниз` в поле фильтра, чтобы переместить фокус непосредственно в список.

При выборе трека из списка становятся доступны следующие действия:

- **Воспроизвести в Spotify:** Пытается напрямую открыть настольное приложение Spotify. Если приложение не установлено, переходит на сайт Spotify и автоматически начинает воспроизводить первый результат.
- **Воспроизвести на YouTube (`Alt+O`):** Выполняет поиск выбранного трека на YouTube и открывает результаты в браузере по умолчанию.
- **Показать текст песни:** Загружает и отображает текст выбранного трека. Текст песни загружается с [lrclib.net](https://lrclib.net) (бесплатно, без регистрации). Пока поиск выполняется в фоновом режиме, объявляется короткое сообщение «Загрузка текста…». Если текст найден, он открывается в диалоговом окне только для чтения, где его можно читать с помощью NVDA и копировать в буфер обмена. Если текст не найден, NVDA сообщает об этом. Кнопка временно отключается во время выполнения загрузки, чтобы предотвратить дублирующие запросы.
- **Удалить (`Alt+M`):** Удаляет выбранный трек из `likedSongs.txt` и обновляет список. Клавиша `Delete` также активирует эту кнопку, когда список находится в фокусе. Вы также можете пометить несколько песен сразу и удалить их все вместе — см. [Пометка и удаление нескольких элементов](#пометка-и-удаление-нескольких-элементов) под Избранным.
- **Обновить (`Alt+E`):** Перезагружает список из файла.

Кнопки Spotify, YouTube, «Показать текст песни» и «Удалить» активны только тогда, когда в списке выбран реальный трек.

### Служба текстов песен

freeAudio использует [lrclib.net](https://lrclib.net) для получения текстов песен — бесплатная открытая база данных, не требующая ключа API или учётной записи. Процесс поиска анализирует строку трека, хранящуюся в `likedSongs.txt`, и последовательно пробует более широкие запросы до нахождения текста:

1. Точное совпадение с полным именем исполнителя и очищенным названием (шумовые суффиксы, такие как «Remastered», «Live» или теги года, удаляются перед поиском).
2. Точное совпадение с полным именем исполнителя и оригинальным названием (если очистка его изменила).
3. Точное совпадение только с именем первого исполнителя и очищенным названием (для строк с несколькими исполнителями, например «Исполнитель A & Исполнитель B»).
4. Нечёткий поиск с именем первого исполнителя и очищенным названием.
5. Нечёткий поиск с исходной строкой трека в качестве крайнего средства.

Если доступны простые тексты, они отображаются как есть. Если доступны только синхронизированные по времени LRC-тексты, временны́е метки удаляются и отображается простой текст. Инструментальные треки сообщаются как не найденные.

## Отключение уведомлений

Когда в Настройках включен параметр **Отключить уведомления**, NVDA не озвучивает следующие автоматические объявления:

- Название станции при начале воспроизведения новой станции
- Изменения состояния воспроизведения: воспроизведение, пауза, остановка
- Режим Obligato: запущен / остановлен
- События записи: начата, остановлена, завершена (мгновенная, запись песни и запланированная)
- Объявления о смене ICY-треков, даже если также включена опция **Автоматически объявлять смену треков**

Следующие объявления намеренно **не затрагиваются**: сообщения об ошибках, обратная связь об избранном (добавлена / уже в списке), результаты распознавания музыки и уведомления об обновлениях.

Параметр можно переключить в меню NVDA → Параметры → Настройки → freeAudio или мгновенно в любое время через неназначенный жест ввода (назначьте его в меню NVDA → Параметры → Жесты ввода → freeAudio). При переключении NVDA один раз объявляет «Уведомления отключены» или «Уведомления включены» для подтверждения изменения.

## Автоматическое объявление смены треков

Когда в Настройках включена опция **Автоматически объявлять смену треков**, freeAudio проверяет поток ICY-метаданных активной станции в фоновом режиме примерно каждые 5 секунд. Когда трек меняется, новое название автоматически озвучивается NVDA — нажатие клавиш не требуется.

При переключении на новую станцию первая информация о треке объявляется сразу после установления соединения. Если вы переключитесь на станцию, которая не передаёт ICY-метаданные, система молчит, и информация о треке с предыдущей станции не повторяется.

Эта функция отключена по умолчанию и может быть включена в меню NVDA → Параметры → Настройки → freeAudio.

## Воспроизведение

freeAudio использует **BASS** в качестве единственного бэкенда воспроизведения для всего — интернет-радио, подкастов, аудиокниг и треков джукбокса. Отдельная установка не требуется; он поставляется вместе с дополнением. Поддержка VLC, PotPlayer и Windows Media Player в качестве резервных бэкендов была удалена; BASS используется всегда.

BASS отправляет аудио напрямую в аудиостек Windows и отображается в микшере громкости Windows как независимый источник звука с именем «pythonw.exe», отдельно от NVDA. Это означает, что звук freeAudio проходит по совершенно отдельному каналу, не смешиваясь с речью NVDA: радио не прерывается, не смешивается и не зависит от собственных аудионастроек NVDA, когда NVDA говорит. Пользователь может регулировать громкость радио независимо от NVDA в микшере громкости Windows. Поддерживает HTTP, HTTPS и большинство встроенных форматов потоков.

Эпизоды подкастов, главы аудиокниг и треки джукбокса воспроизводятся через BASS, потому что он может открыть поток как перематываемый файл (даже во время загрузки), что позволяет точно отслеживать позицию, выполнять ступенчатую перемотку назад/вперёд, регулировать скорость воспроизведения, транспонировать высоту тона и возобновлять воспроизведение. Аудиозеркало, тайм-шифт и перемотка/возобновление подкастов/аудиокниг/джукбокса зависят от BASS и всегда доступны.

## Проверка обновлений

freeAudio автоматически проверяет наличие новых версий через GitHub.

**Автоматическая проверка:** Выполняется в фоновом режиме через 15 секунд после запуска NVDA. Если найдена новая версия, вы получаете уведомление; если версия актуальна, сообщение не показывается.

**Ручная проверка:** Может быть запущена по запросу из меню NVDA → Сервис → freeAudio → **Проверить обновления…**. При запуске таким способом результат объявляется, даже если версия актуальна.

**Когда найдено обновление:** Открывается диалоговое окно с указанием номера версии и вашей установленной версии.

- Если на странице релиза GitHub доступен непосредственно загружаемый файл `.nvda-addon`, отображается кнопка **Загрузить и установить**. После подтверждения файл загружается в фоновом режиме, NVDA объявляет о начале загрузки, и автоматически открывается окно установки NVDA.
- Если прямая ссылка для загрузки недоступна, отображается кнопка **Открыть страницу**, и страница релиза GitHub открывается в браузере по умолчанию.

**Чтобы отключить автоматические проверки:** Выключите опцию **Проверять обновления автоматически** в меню NVDA → Параметры → Настройки → freeAudio.
