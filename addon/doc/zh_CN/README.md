# 自由之声 (freeAudio) — NVDA 插件

freeAudio 是一款专为 NVDA 屏幕阅读器设计的功能全面的网络电台、播客、有声书和本地点唱机插件。它最初只是一个用于流式传输网络电台的简单工具，如今已发展成为一个完整且完全无障碍的听觉中心——从头到尾，每一个屏幕、对话框和控件都是专门为键盘和屏幕阅读器操作而设计的，全程无需使用鼠标。

## 自由之声的功能特性

* **网络电台** — 在来自 [Radio Browser](https://www.radio-browser.info/) 目录的 50,000 多个电台中进行浏览和搜索，搜索结果还得到了 TuneIn 和 iHeartRadio 的补充。您可以保存收藏夹、调整其顺序，并通过 Windows 中任意位置的全局键盘快捷键直接跳转到其中任何一个电台——详见[Radio Browser 目录](https://www.google.com/search?q=%23radio-browser-%E7%9B%AE%E5%BD%95)和[收藏夹](https://www.google.com/search?q=%23%E6%94%B6%E8%97%8F%E5%A4%B9)。
* **播客** — 订阅任何 RSS/Atom 播客源，或者搜索 Apple 的播客目录并在订阅前预览单集。播放进度会自动保存，并在您下次收听时从中断处恢复——详见[播客](https://www.google.com/search?q=%23%E6%92%AD%E5%AE%A2)。
* **有声书** — 通过三个来源搜索并流式传输或下载书籍：[GETEM](https://getem.boun.edu.tr/)（海峡大学面向视障人士的数字图书馆）、[LibriVox](https://librivox.org/)（由志愿者朗读的公共领域有声书项目）以及古腾堡计划开源有声书合集（Project Gutenberg Open Audiobook Collection，后两项无需账号），并且支持跨多部作品的多部分自动续播——详见[有声书（GETEM、LibriVox 与古腾堡计划）](https://www.google.com/search?q=%23%E6%9C%89%E5%A3%B0%E4%B9%A6getemlibrivox-%E4%B8%8E%E5%8F%A4%E8%85%BE%E5%A0%A1%E8%AE%A1%E5%88%92)。
* **本地点唱机** — 通过文件名搜索任意已连接驱动器上存储的音频文件，或构建由文件和文件夹组成的个人音乐库，并使用与播客和有声书相同的续播、跳转、速度和音高工具进行播放——详见[本地点唱机](https://www.google.com/search?q=%23%E6%9C%AC%E5%9C%B0%E7%82%B9%E5%94%B1%E6%9C%BA)。
* **录音** — 即时录制当前播放的内容，在单曲开始和结束时自动捕获单曲，或者安排一次性录音和定时循环录音——所有操作均不会中断播放——详见[录音](https://www.google.com/search?q=%23%E5%BD%95%E9%9F%B3)。
* **时移（直播电台快退）** — 像 DVR 一样暂停和快退直播电台，随时可以追赶回直播进度——详见[时移（直播电台快退）](https://www.google.com/search?q=%23%E6%97%B6%E7%A7%BB%E7%9B%B4%E6%92%AD%E7%94%B5%E5%8F%B0%E5%BF%AB%E9%80%80)。
* **音乐识别与红心收藏歌曲** — 使用基于 Shazam 的识别技术识别没有元数据的音轨，将喜欢的歌曲保存到文本文件中，并查询它们的歌词——详见[音乐识别](https://www.google.com/search?q=%23%E9%9F%B3%E4%B9%90%E8%AF%86%E5%88%AB)和[红心收藏歌曲](https://www.google.com/search?q=%23%E7%BA%A2%E5%BF%83%E6%94%B6%E8%97%8F%E6%AD%8C%E6%9B%B2)。
* **音频配置文件与特效** — 针对单个电台、单个播客、单个有声书或单个点唱机音轨分别保存独立的音量、特效、均衡器 (EQ) 和播放速度设置，并通过 BASS 后端实时应用各种特效（合唱、混响、均衡器增益等）——详见[电台音频配置文件](https://www.google.com/search?q=%23%E7%94%B5%E5%8F%B0%E9%9F%B3%E9%A2%91%E9%85%8D%E7%BD%AE%E6%96%87%E4%BB%B6)。
* **转调（音高调节）** — 使用内置的 `bass_fx` 组件，在不改变速度的情况下向上或向下调整播客、有声书和点唱机音轨的音高——详见[转调（音高调节）](https://www.google.com/search?q=%23%E8%BD%AC%E8%B0%83%E9%9F%B3%E9%AB%98%E8%B0%83%E8%8A%82)。
* **音频镜像** — 同时将同一个音频流发送到两个音频输出设备，例如扬声器和耳机同时发声——详见[音频镜像](https://www.google.com/search?q=%23%E9%9F%B3%E9%A2%91%E9%95%9C%E5%83%8F)。
* **伴奏模式（背景音乐）** — 在后台安静地循环播放您选定的某个收藏电台，使用其专属的输出设备和音量，无论作为主媒体播放什么内容（或不播放）都不会受到影响——详见[伴奏模式（背景音乐）](https://www.google.com/search?q=%23%E4%BC%B4%E5%A5%8F%E6%A8%A1%E5%BC%8F%E8%83%8C%E6%99%AF%E9%9F%B3%E4%B9%90)。
* **定时器** — 设定在特定时间自动开始播放某个收藏电台，或设定在指定时间停止播放——详见[定时器](https://www.google.com/search?q=%23%E5%AE%9A%E6%97%B6%E5%99%A8)。
* **深度的键盘与盲文访问支持** — 每一个功能都可以完全通过键盘访问，拥有在 Windows 任何地方都能生效的全局快捷键、针对单个收藏电台的直接热键，以及针对自由之声所有语音提示的可选盲文输出。

## Radio Browser 目录

freeAudio 使用 [Radio Browser](https://www.radio-browser.info/) 开放数据库作为其电台目录。Radio Browser 是一个由社区管理的免费目录，托管了来自世界各地的 50,000 多个网络电台。无需注册或创建账号，其 API 对所有人开放。每个电台都包含地址、国家/地区、曲风、语言和比特率信息；电台根据用户投票进行排名。freeAudio 通过位于德国、荷兰和奥地利的镜像服务器连接到此 API；如果某台服务器无法访问，它会自动切换到下一台。

为了保持浏览器的响应速度并避免在每次搜索或切换国家时频繁请求 API，freeAudio 会在磁盘上保留一份电台目录的本地缓存。此缓存会在后台按定期计划自动刷新，因此您看到的列表通常在您不需要做任何操作时就已经是最新的了。您也可以随时通过**更新电台列表**按钮强制立即重新同步——详见下方的[电台浏览器](https://www.google.com/search?q=%23%E7%94%B5%E5%8F%B0%E6%B5%8F%E8%A7%88%E5%99%A8)。

## 在 Radio Browser 中添加电台

如果您要找的电台不在 Radio Browser 目录中，您可以自行前往 [https://www.radio-browser.info/add](https://www.radio-browser.info/add) 进行提交。无需账号或注册。

填写该页面上的表单：

* **流 URL (Stream URL)** *（必填）* — 音频流的直接 URL，以 `.mp3`、`.aac`、`.ogg` 或类似格式结尾。这不是电台的网站地址；而是您可以粘贴到媒体播放器中的原始音频流地址。大多数电台在其网站上或“在线收听”部分都会公布其流 URL。
* **电台名称 (Station name)** *（必填）* — 电台在目录中显示的名称。
* **主页 (Homepage)** — 电台的网站地址。
* **国家和语言 (Country and language)** — 从下拉列表中选择国家/地区和广播语言。
* **标签 (Tags)** — 用逗号分隔的曲风或主题关键词，例如 `news`、`jazz`、`classical`。这些关键词用于搜索和筛选。
* **Logo URL** — 电台 Logo 图片的直接链接（如果可用）。

提交后，该电台将经过审核并添加到公共目录中。一旦被接受，它将自动出现在 freeAudio 的搜索和国家列表中，因为该目录会从实时 API 中定期刷新。

## 系统要求

* NVDA 2025.1 或更高版本
* Windows 10 或更高版本
* 互联网连接

## 安装

下载 `.nvda-addon` 文件，对其按回车键并在提示时重启 NVDA。

## 键盘快捷键

所有快捷键均可在 NVDA 菜单 → 偏好设置 → 输入手势 → freeAudio 中重新分配。这些快捷键在任何地方都可以生效，无论当前哪个窗口拥有焦点。

其中一些快捷键与 Windows 自身的快捷键重合。如果您想保留 Windows 自身的快捷键而不重新分配 freeAudio 的快捷键，请在组合键按下之前立即按 `NVDA+F2`（透传下一个按键）——NVDA 会将该按键组合直接发送给 Windows，而不会拦截它用于 freeAudio。

| `Ctrl+Win+W` | 打开录音文件夹 | 在文件资源管理器中打开包含录音文件的文件夹。 |

| `Ctrl+Win+K` | 时移快进 / 播客、有声书与点唱机向前跳转 | 对于直播电台：在时移状态下向前移动 15 秒。一旦到达直播边缘，播放将自动返回直播，此后在该按键再次快退之前它将不执行任何操作。对于播客、有声书或点唱机音轨，此按键使用与上述 `Ctrl+Win+J` 相同的点击/按住缩放比例在文件中向前跳转（按住 = 每次重复 5 秒；单击 1 次 = 12 秒；点击 2 次 = 1 分钟；点击 3 次以上 = 5 分钟）。无论时移设置如何，均可正常工作。 |
| `Ctrl+Win+T` | 切换时移缓冲区 | 动态启用或禁用时移缓冲区，与“设置”中的复选框相对应。如果处于时移状态，禁用时将立即返回直播播放并停止后台捕获。对播客、有声书或点唱机播放没有影响。 |
| *(未分配)* | 选择输出设备 | 打开可用主输出设备的按需列表。仅当 BASS 检测到多个物理输出设备时才会显示该列表。通过 NVDA 菜单 → 偏好设置 → 输入手势 → freeAudio 分配组合键。 |
| *(未分配)* | 切换静音通知 | 动态切换“静音通知”设置。通过 NVDA 菜单 → 偏好设置 → 输入手势 → freeAudio 分配组合键。 |
| *(未分配)* | 直接播放收藏电台 | 收藏夹列表中的每个电台都会作为独立条目出现在 NVDA 菜单 → 偏好设置 → 输入手势 → **freeAudio 电台**中。为某个电台分配任意键盘快捷键，即可随时随地直接开始播放，而无需先打开浏览器。 |

“下一个/上一个”快捷键仅用于导航收藏夹列表；它们对“所有电台”列表无效。当浏览器窗口中的某个列表获得焦点时，左右方向键具有相同的功能——详见“对话框内快捷键”。

## 电台浏览器

freeAudio 还会在 NVDA 的“工具”菜单中添加一个 **freeAudio** 子菜单。从那里您可以直接打开电台浏览器和 freeAudio 设置。

通过 `Ctrl+Win+R` 打开的窗口包含八个选项卡：所有电台、收藏夹、录音、定时器、红心收藏歌曲、播客、有声书和点唱机。您可以使用 `Ctrl+Tab` 或通过 `Alt+1` 到 `Alt+8` 在各个选项卡之间导航。

当“所有电台”选项卡打开时，投票数最高的前 1,000 个电台会自动从 Radio Browser 加载。从下拉列表中选择一个国家/地区会更新列表以显示该国的电台。在搜索框中键入内容会立即同时按名称、国家和曲风对整个 Radio Browser 数据库进行完整搜索。

在搜索时，Radio Browser 的结果会辅以来自 TuneIn 和 iHeartRadio 的电台（如果可用）。这些外部来源会在后台进行搜索，其结果会自动合并到列表中，让您无需额外操作即可访问更多电台。

浏览器窗口底部（选项卡区域外）的**输出设备 (Output Device)** 下拉列表列出了所有被 BASS 识别的音频输出设备。选择某个设备会立即将音频输出重定向到该设备并永久保存该选择；下次会话中将自动使用同一设备。如果所选设备未连接，插件将自动回退到系统默认设备。按 `F11` 可从电台浏览器中的任意位置打开一个更简单的按需设备选择器。当 BASS 仅检测到一个物理输出设备时，选择器不会自动显示，仅在检测到多个物理输出设备时才会打开。当只有一个设备可用时，无需进行选择，freeAudio 将使用系统默认输出。此功能仅在 BASS 后端处于活动状态时才有效。

同一区域中的**音量 (Volume)**（0–200）和**特效 (Effects)** 控件可以在窗口打开时的任何时候进行调整。从特效列表中，可以同时启用合唱 (Chorus)、压缩器 (Compressor)、失真 (Distortion)、回声 (Echo)、弗兰杰 (Flanger)、Gargle、混响 (Reverb)、均衡器：低音增强 (EQ: Bass Boost)、均衡器：高音增强 (EQ: Treble Boost) 和均衡器：人声增强 (EQ: Vocal Boost)；更改会立即应用到当前活动的音频流。通过 `Ctrl+1` 到 `Ctrl+0` 也可以无需离开键盘直接切换每个特效——详见[特效快捷键](https://www.google.com/search?q=%23%E7%89%B9%E6%95%88%E5%BF%AB%E6%8D%B7%E9%94%AE)。这些控件仅在 BASS 后端处于活动状态时才完全有效。

当启用一个或多个均衡器 (EQ) 特效时，每个处于活动状态的频段都会出现一个**增益控制 (gain control)**。增益可以在 −15 dB 到 +15 dB 之间进行设置；默认值为：低音 +9 dB、高音 +9 dB、人声 +6 dB。增益控件仅针对当前勾选的 EQ 频段显示，当取消勾选某个 EQ 特效时会自动隐藏。增益值会全局保存并在下次会话中恢复。

**播放/暂停 (Play/Pause)** 按钮也位于窗口底部。如果当前没有电台在播放，它会开始播放所选电台；如果电台已经在播放，则会暂停播放。

**更新电台列表**按钮会立即从 Radio Browser API 重新同步本地电台目录，而无需等待定期的后台刷新。在刷新运行期间，该按钮处于禁用状态，并且 NVDA 会播报刷新正在进行中；如果在当前刷新完成之前再次按下，NVDA 会告知您刷新已经在进行中。刷新完成后，NVDA 会播报电台列表已更新，并且当前显示的搜索结果或国家列表会自动刷新以反映最新数据。

在列表中选中某个电台时，**电台详情**按钮会在单独的对话框中显示国家/地区、语言、曲风、格式、比特率、网站和流 URL 等信息。每个字段都显示在自己的只读文本框中；您可以使用 Tab 键在字段之间移动，并使用**全部复制到剪贴板**按钮将所有信息一次性复制到剪贴板。此按钮在“所有电台”和“收藏夹”选项卡中均可用。

## 收藏夹

收藏夹列表是永久存储的个人电台收藏。要添加电台，请在列表中选中它并按“添加到收藏夹”按钮或使用 `Alt+V` 快捷键。当已在列表中的电台被选中时，使用相同的快捷键可将其移除。

可以使用 `Ctrl+Win+→` 和 `Ctrl+Win+←` 播放收藏夹；即使在浏览器窗口未打开时，这些快捷键也依然有效。

要从收藏夹列表中删除电台，请选中它并按**删除电台**按钮或 `Delete` 键。删除后，焦点和选中项会自动移动到列表中的下一个电台。如果被删除的电台是最后一个，焦点会移动到上一个电台。如果列表变为空，焦点会移动到“播放”按钮。

### 标记和移除多个项目

收藏夹、“红心收藏歌曲”、有声书库和点唱机列表均支持标记多个项目并通过一个步骤将它们一并移除：

* 在高亮显示的项目上按 **`.`**（句点键）可进行标记或取消标记。NVDA 会播报更改，并且被标记项目的行会带有 `"(marked)"` 标签，以便在您继续在列表中上下浏览时保持状态清晰。
* 按 **`Shift+Home`** 可标记或取消标记从当前项目到列表中第一项之间的所有项目，或者按 **`Shift+End`** 对向下直到最后一项的项目执行相同操作。该范围是被标记还是取消标记由当前项目自身的状态决定，因此整个范围在一次操作中始终朝同一个方向变化。操作完成后，焦点移动到该范围的远端，NVDA 会播报更改了多少个项目。
* 按 **`Delete`** 可一次性移除所有被标记的项目。如果没有任何标记，`Delete` 仍然像以前一样只移除当前选中的项目。
* 每个列表的右键上下文菜单（应用程序键 / `Shift+F10`）包含一个**移除所选项目 (Remove Selected)** 命令（仅在至少有一个项目被标记时启用），其作用相同。

标记是按列表区分的，一旦您移除这些项目（或逐个取消标记）就会被清除；它们不会在不同会话之间保存。

### 导出和导入收藏夹

“收藏夹”选项卡包含两个用于备份和恢复电台列表的按钮：

**导出收藏夹… (Export Favourites…)** — 将您的整个收藏夹列表保存到文件。保存对话框允许您在两种格式之间进行选择：

* **JSON** (`.json`) — 完整的备份，保留电台名称、流 URL 和所有元数据。建议用于稍后恢复您的列表或将其移动到另一台计算机。
* **M3U 播放列表** (`.m3u`) — 与大多数媒体播放器和电台应用兼容的标准播放列表格式。请注意，M3U 不存储所有电台元数据，因此从 M3U 恢复可能会导致比 JSON 备份更少的详细信息。

**导入收藏夹… (Import Favourites…)** — 从先前导出的 JSON 或 M3U 文件中加载电台。选择文件后，系统会询问您如何添加电台：

* **是 (合并) (Yes (Merge))** — 将导入的电台添加到您现有的列表中，而不删除任何当前的收藏夹。重复的电台不会被重复添加。
* **否 (替换) (No (Replace))** — 完全清除您当前的收藏夹列表，并将其替换为导入文件的内容。
* **取消 (Cancel)** — 返回浏览器而不做任何更改。

导入成功后，收藏夹列表、定时录音电台列表和定时器电台列表都会自动刷新。

### 将收藏夹整理到分组中

收藏夹可以属于某个文件夹/分组，在列表中的电台名称后显示为“— 分组”后缀（例如，“NPR Newscast — NPR”）。

* **从 M3U 导入** — 如果文件使用 `group-title` 标签（DVBViewer 以及大多数其他 M3U 编辑器和播放器使用的惯例）将电台组织到文件夹中，freeAudio 会在导入时读取并保留每个电台的分组。将收藏夹导出回 M3U 会写入相同的标签，因此文件夹结构在通过 freeAudio 进行往返时得以保留。
* **手动分配或移除分组** — 用 `.` 标记一个或多个收藏夹（见上文[标记和移除多个项目](https://www.google.com/search?q=%23%E6%A0%87%E8%AE%B0%E5%92%8C%E7%A7%BB%E9%99%A4%E5%A4%9A%E4%B8%AA%E9%A1%B9%E7%9B%AE)），然后从上下文菜单（应用程序键 / `Shift+F10`）中选择**分配到分组… (Assign to Group…)** 并键入分组名称。将字段留空则可将已标记的收藏夹从其分组中移除。如果没有任何标记，则该命令应用于当前选中的收藏夹。
* **按分组筛选** — 收藏夹列表上方的“筛选”字段也匹配分组名称，并接受可以各自匹配不同字段的多个词。例如，键入 `Houston Classical` 可以找到 "Houston Public Media Classical"，即使该确切短语从未整体出现过——“Houston”匹配分组，“Classical”匹配电台名称。

### 重新排序收藏夹

在“收藏夹”选项卡中选中某个电台后，按 `逗号 (comma)` 进入移动模式——您会听到一声蜂鸣。使用方向键导航到目标位置，然后再次按 `逗号`。电台将被放置在所选位置，并且新顺序会立即保存。在同一位置再次按 `逗号` 会取消移动。

### 收藏电台的直接键盘快捷键

收藏夹列表中的每个电台都作为独立脚本注册在 NVDA 的“输入手势”对话框中的 **freeAudio 电台 (freeAudio Stations)** 类别下。您可以为任何电台分配任何键盘快捷键，并从任何地方按下它——无需先打开浏览器窗口。

要分配快捷键：

1. 打开 NVDA 菜单 → 偏好设置 → 输入手势。
2. 展开 **freeAudio 电台** 类别。
3. 按名称找到电台，选中它，然后按**添加 (Add)**。
4. 按下所需的按键组合并确认。

该快捷键会立即激活电台。如果该电台随后从您的收藏夹中移除，其条目将从该类别中消失，并且分配给它的任何快捷键都会被 NVDA 自动清除。当新电台添加到收藏夹时，它会直接出现在该类别中——无需重新打开输入手势对话框。

### 添加自定义电台

要添加一个不在 Radio Browser 中的电台，请使用“添加自定义电台”按钮。在弹出的对话框中，输入电台名称和串流网址（Stream URL），即可将其直接添加到你的收藏夹中。自定义电台可以像其他任何收藏一样进行播放和重新排序。

此对话框中还提供了两个附加按钮：

* **测试网址** — 在添加电台之前检查你输入的串流网址，并通报该网址是否可访问。这对于在死链或拼写错误进入你的收藏夹列表之前将其拦截非常有用。
* **添加至 Radio Browser 目录…** — 在你的默认浏览器中打开 [Radio Browser 提交页面](https://www.radio-browser.info/add)，以便在确认电台可用后，将其分享给更广泛的 Radio Browser 社区。有关提交表单的要求，请参阅上文的[将电台添加到 Radio Browser](https://www.google.com/search?q=%23adding-a-station-to-radio-browser)。

### 电台音频配置文件

“收藏夹”选项卡包含两个用于管理单台音频设置的按钮：

**为此电台保存音频配置文件** — 将当前的音量级别、活动效果（合唱、均衡器等）以及均衡器增效值保存为绑定到该特定电台的配置文件。每当该电台开始播放时，其保存的音量、效果和增效设置都会自动应用，并覆盖全局默认值。

**清除音频配置文件** — 从所选电台中移除保存的音频配置文件。清除后，电台将恢复为全局的音量、效果和均衡器增效设置。此按钮仅在所选电台已有保存的配置文件时处于活动状态。

这两个按钮都位于收藏夹列表下方，并且仅在选中列表中某个电台时启用。

## 音乐识别

连按三次 `Ctrl+Win+I` 快捷键可对当前正在播放的串流触发基于 Shazam 的音乐识别。只有在没有 ICY 元数据（电台广播的曲目信息）可用时，才会开始识别；如果存在元数据，则会将其复制到剪贴板。

识别过程如下：使用 ffmpeg 从串流中捕获简短的音频样本，应用 Shazam 指纹识别算法，并将结果发送到 Shazam 的服务器。如果识别成功，NVDA 会播报曲目名称、艺术家、专辑和发行年份，并自动将其复制到剪贴板。如果启用了**将喜欢的歌曲保存到文本文档**选项，识别结果还会追加到 `likedSongs.txt` 中。

**音频反馈：** 识别开始时会响起两个上升的蜂鸣声，结束时会响起两个下降的蜂鸣声。在处理过程运行期间，每隔 2 秒会播放一声短促的蜂鸣。

**要求：** 需要 `ffmpeg.exe`。放置在插件文件夹中的 `ffmpeg.exe` 会被自动使用；如果它位于其他位置，可以在“设置”中路径。从 [ffmpeg.org](https://ffmpeg.org/download.html) 下载 ffmpeg。

**关于插入广告的电台的说明：** 某些电台会对与其串流建立的每一个全新连接播送简短广告，这与你正在收听的广播是分开的。识别功能通过重用 freeAudio 现有的后台串流连接（与用于[时移（回溯直播电台）](https://www.google.com/search?q=%23time-shift-rewind-live-radio)的连接相同）来避免对该广告进行采样，而不是打开一个新连接，因此它识别的是实际正在播放的内容，而不是广告。此功能自动运行，无需任何配置。

## 音频镜像

使用 `Ctrl+Win+M` 快捷键可将当前播放的串流同时镜像到第二个音频输出设备。这对于同时在两个不同的设备（例如扬声器和耳机）上收听非常有用。

首次按下时，会出现一个列出可用输出设备的选定对话框。选择设备后，镜像即告开始，主播放将继续不间断进行。再次按下该快捷键可停止镜像。

**使用场景：**

* **扬声器 + 耳机** — 让访客通过耳机收听同一广播，而你则通过电脑扬声器收听。
* **录音设置** — 将主输出路由至扬声器，并将第二个输出路由至外部录音机或音频接口以进行外部捕获。
* **多房间** — 同时通过蓝牙扬声器和内置扬声器播放；无需额外的软件即可将音频传输到另一个房间。
* **远程监控** — 在屏幕共享或远程桌面会话中，本地和远程双方都可以同时听到相同的串流。

> **注意：** 音频镜像仅在 BASS 后端处于活动状态时可用。如果在镜像处于活动状态时更改了音量，两个输出会同时更新。

## 背景音乐模式 (Obligato Mode)

`Ctrl+Win+Shift+M` 快捷键可以在一个与主播放器完全独立的独立音频引擎上，安静地在后台播放收藏的电台——就像在你实际进行的任何操作下方运行的柔和音乐背景。

首次按下时，会打开一个包含三个控件的对话框：

* **背景电台** — 你收藏的电台列表，用于选择在后台循环播放哪一个。至少需要一个收藏；如果你的收藏夹列表为空，freeAudio 会提示你先添加电台（在播放电台时按 `Ctrl+Win+V`）。
* **音频输出** — 背景电台通过哪个设备播放：**与主输出相同**（默认）、**系统默认**或 freeAudio 可以看到的任何特定设备。
* **背景音量** — 背景电台的播放音量，作为主播放器当前音量的百分比（25%、50%、75%、100%、125% 或 150%）。你的选择会被记住以供下次使用。

启动后，背景电台会独立于主播放器继续播放——在主播放器上切换电台、播客、有声读物，或者完全停止播放，都不会中断背景音乐模式。有两项设置会自动与主播放器保持联动：

* **音量** — 背景音量会持续保持为主播放器当前音量的指定百分比，因此调高或调降主音量（`Ctrl+Win+↑`/`↓`）会按相同比例缩放背景音乐。
* **暂停** — 暂停主播放器（`Ctrl+Win+P`）也会暂停背景电台，恢复主播放器也会恢复背景电台。主播放器的完全停止不被视为暂停，因此背景电台会继续播放。

随时再次按下 `Ctrl+Win+Shift+M` 即可停止背景音乐模式。

## 录音

默认情况下，录音保存在 `Documents\freeAudio Recordings\` 中。文件名包含电台名称（或在歌曲录音模式下的歌曲标题）以及录音开始时间。可以随时从“NVDA 菜单 → 首选项 → 设置 → freeAudio → **录音文件夹**”更改录音文件夹。

**录音输出格式**设置控制已完成录音的保存方式：

* **原始串流格式**完全按接收到的方式写入串流。因此，HLS 广播可能会生成 `.ts` 文件。
* **仅音频，原始编解码器**在不重新编码音频的情况下移除视频/容器层。例如，来自 HLS `.ts` 录音的 AAC 音频通常保存为 `.m4a`，从而保留广播质量。
* **MP3** 在录音后使用选定的比特率转换音频。转换使用随 freeAudio 附带的 `ffmpeg.exe`，并在后台运行，以便 NVDA 保持响应。如果转换失败，则保留原始录音。

**即时录音：** 在播放电台时，按一次 `Ctrl+Win+E`。再次按下可停止。整个过程播放持续不断。

**歌曲录音：** 在播放广播 ICY 元数据的电台时，快速连续按**两次** `Ctrl+Win+E`。录音立即开始，并以当前曲目名称命名。曲目更改时，录音自动停止，NVDA 会播报保存的文件名。如果你想在曲目播放完之前提前结束录音，请再次快速按两次 `Ctrl+Win+E`。如果当前电台不广播 ICY 元数据，则歌曲录音不可用，NVDA 会通知你。

**定时录音：** 打开浏览器中的“录音”选项卡。从你的收藏夹中选择一个电台，以 HH:MM 格式输入开始时间和持续时间（分钟），选择一个或多个活动日，然后选择重复模式和录音模式：

电台列表上方的**筛选**字段可让你实时缩窄收藏列表，以便快速找到要计划的电台。

**活动日：** 勾选一周中的一个或多个几天。在单次录音模式下，会为每个选定的日期创建一个单独的条目，每个条目都安排在該日期的下一次临近出现时间。在循环模式下，录音仅在勾选的日期重复。如果未勾选任何日期，则录音不限于特定日期。

**重复：**

* **仅录制一次** — 在每个选定的日期仅录制一次。每个条目都安排在該日期的下一次临近出现时间；如果选定的时间今天已经过去，则条目会自动移至下周的同一天。
* **每周重复** — 在选定的活动日每周重复一次，直到从计划列表中移除。

**录音保存至：** 对于每个定时录音，你可以选择保存到默认录音文件夹或自定义文件夹。使用浏览...按钮交互式选择文件夹。如果所选文件夹不可用，录音将回退到默认文件夹并会收到通知。

**录音模式：**

* **边听边录** — 通过 BASS 后端同时播放和录音。
* **仅录音** — 在后台静默录音而不输出任何音频；录音引擎直接连接到串流。

添加计划后，它会显示在下方的列表中。使用“删除所选”按钮删除计划，或使用“编辑所选”修改其时间、持续时间、重复、活动日、录音模式或输出文件夹。

NVDA 会在录音开始和结束时进行播报。如果在定时录音处于活动状态时重新启动 NVDA，录音会在启动时自动恢复。

与音乐识别一样，即时录音和歌曲录音在可用时会重复使用 freeAudio 现有的后台串流连接，而不是打开新连接，因此录音可以捕捉实际正在播出的内容，即使是在那些本来会向全新连接提供新鲜广告的电台上也是如此。这不适用于预定的**仅录音**录音，因为在它们开始时没有电台在播放。

## 时移（回溯直播电台）

时移功能可让你像使用 DVR 或盒式磁带一样倒回当前正在收听的电台——暂停当前画面，回退几分钟，并在需要时随时追上直播。播放永远不必为此停止：倒带和快进都在同一个音频流上即时发生。

此功能**默认禁用**。请从“NVDA 菜单 → 首选项 → 设置 → freeAudio → **启用时移缓冲区（回溯直播电台）**”中启用它，或者随时使用 `Ctrl+Win+T` 立即切换。

> **Note:** freeAudio 现在会始终保持对当前播放电台的少量后台捕获——不仅在此设置启用时如此——因为[音乐识别](https://www.google.com/search?q=%23music-recognition)和[录音](https://www.google.com/search?q=%23recording)都依赖它来实现这些部分中描述的防广告行为。当此设置**关闭**时，该后台捕获量将保持在最近 45 秒左右，并且 `Ctrl+Win+J`/`Ctrl+Win+K` 保持不可用——只有缓冲区大小会发生变化，而不是它是否运行。启用该设置会将相同的捕获量扩展到下面描述的完整回溯缓冲区。

### 工作原理

一旦启用，freeAudio 就会在后台独立于正常播放，将当前播放的电台连续捕获到滚动本地缓冲区中。缓冲区大约保存**最后几分钟**的音频；随着新音频的到达，较旧的音频会自动从前端丢弃，因此缓冲区始终代表相对于直播边缘的“最近过去”。
缓冲区时间在设置中确定。

* **`Ctrl+Win+J`** — 倒回 15 秒。第一次按会使你从直播播放切换到时移播放，从落后直播边缘 15 秒开始。每次进一步按下都会再往回移动 15 秒，直至达到缓冲区限制。
* **`Ctrl+Win+K`** — 在时移状态下快进 15 秒。一旦到达直播边缘，播放就会自动切换回直播流，并且 NVDA 会播报“返回直播”——你不需要做任何额外的事情来恢复正常收听。
* **`Ctrl+Win+T`** — 打开或关闭整个功能。在时移状态下将其关闭会立即将你带回直播播放并停止当前电台的后台捕获。

在你处于时移状态的整个过程中，后台捕获会一直运行，因此即使你在收听几分钟前的音频时，直播边缘也会继续向前推进——就像真正的 DVR 一样。

### 启用与缓冲区预热

一旦电台开始播放（功能启用后）或在你已经收听电台时启用该功能的瞬间，缓冲区就会开始填充。因此，只有在实际捕获了几秒钟的音频后才能进行倒带——如果你在切换电台后立即按 `Ctrl+Win+J`，NVDA 会告诉你还没有足够缓冲的音频。只需等待几秒钟，然后重试即可。

切换到不同的电台总是会重新启动新电台的缓冲区；先前电台的缓冲音频将被丢弃。

### 支持的串流

时移支持 freeAudio 已经支持的相同范围的串流：

* 纯 HTTP/HTTPS 串流（MP3、AAC、OGG 等），包括 Shoutcast/Icecast 风格的服务器。
* **HLS (`.m3u8`) 串流** — freeAudio 解析电台的主播放列表，跟踪媒体播放列表，并在后台下载片段以保持缓冲区充满，其工作方式与纯串流相同。

在极少数情况下，完全无法读取电台的播放列表（例如，损坏或无法访问的 `.m3u8` 清单），NVDA 会告诉你该特定电台无法倒回。

### 要求和限制

* **需要 BASS 后端**，freeAudio 总是将此后端用于播放（参见[播放](https://www.google.com/search?q=%23playback)）。
* 缓冲区时间在设置中确定。
* 缓冲区是按电台划分的：切换电台、停止播放或重新启动 NVDA 会将其清除并重新开始。
* 时移播放使用其自己的本地缓冲区文件，并且不会产生保存的录音——如果你想永久保留音频，请同时使用即时录音（`Ctrl+Win+E`）。

## 定时器

打开电台浏览器中的“定时器”选项卡（`Alt+4`）。可以添加两种类型的定时器：

为闹钟定时器选择电台时，电台列表上方的**筛选**字段可让你实时缩窄收藏列表。

**闹钟 — 启动电台：** 在指定时间自动开始播放你收藏中选定的电台。选择一个电台并以 HH:MM 格式输入时间。

**睡眠 — 停止电台：** 在指定时间停止播放。当定时器触发时，音量会在 60 秒内逐渐降低，然后停止播放。无需选择电台；只需输入时间即可。

对于这两种类型，如果输入的时间已经过去，则该操作将安排在第二天。如果同一时间已经存在任何类型的其他定时器，则添加定时器将被阻止；一条消息会告知你冲突并提示你先删除现有条目。未完成的定时器列在选项卡中；选择一个并按“删除所选定时器”按钮即可将其取消。

**循环定时器：** 在**重复**下，选择**每周重复**而不是默认的单次选项，以使定时器每周触发一次而不是触发一次。然后，**活动日**检查清单可让你挑选它重复的一周中的几天；将每一天都留空不勾选则表示每天重复。循环定时器会按计划继续触发，直到你将其从待处理定时器列表中移除为止——它不是触发后消失的一次性条目。

## 播客

freeAudio 包含一个功能齐全的播客播放器。你可以订阅任何 RSS 或 Atom 播客源、浏览剧集、播放它们、下载它们，并从你离开的地方恢复播放——所有这些都完全无障碍。

### 访问“播客”选项卡

使用 `Ctrl+Win+R` 打开电台浏览器，并使用 `Ctrl+Tab` 或 `Alt+6` 切换到**播客**选项卡。该选项卡分为三个主要区域：

1. **搜索和添加** — 用于发现新播客的顶部区域，包括一个预览列表，该列表显示当前选定的搜索结果的剧集。
2. **订阅** — 你已订阅的源的列表。
3. **剧集** — 所选源的剧集列表，带有播放控件。

### 添加播客源

你可以通过两种方式添加播客源：

**通过网址：**

* 在 **“或输入播客网址”** 字段中，粘贴完整的 RSS 或 Atom 源网址（例如 `https://example.com/feed.xml`）。
* 按 Enter 键或单击**添加源**按钮。
* freeAudio 获取源、对其进行验证并将其添加到你的订阅中。如果源有效，你将听到带有源标题的确认信息。如果失败，错误消息会解释原因。

**通过搜索：**

* 在**搜索**字段中，键入关键词（播客标题、主题或主持人姓名）并按 Enter 键。
* freeAudio 搜索 iTunes 播客目录并在**搜索结果**列表中显示匹配的播客。
* 选择结果会在后台获取该源，并在正下方的**所选结果中的剧集**列表中列出其剧集，以便你在决定订阅之前预览节目实际包含的内容——请参阅下文的[订阅前预览剧集](https://www.google.com/search?q=%23previewing-episodes-before-subscribing)。
* 对看到的内容满意后，选择该结果，然后按 `Enter` 键，或者打开其上下文 menu（应用程序键 / `Shift+F10`，或右键单击）并选择**订阅**，将其添加到你的订阅中。该源会立即添加并出现在你的订阅列表中。没有单独的“从搜索中添加所选内容”按钮——`Enter` 或上下文 menu 是从搜索结果中订阅的唯一方法，这使得界面保持干净且易于访问。

> **提示：** 你也可以将源网址直接键入搜索字段中——如果它看起来像一个有效的网址，插件将尝试将其添加为源而无需搜索。

**搜索结果的上下文菜单：** 右键单击搜索结果，或选择它并按应用程序键 / `Shift+F10`，以打开一个仅包含单个**订阅**操作的菜单，这与对结果按 `Enter` 相同。

### 订阅前预览剧集

在承诺订阅之前，你可以直接从搜索结果中收听播客的剧集。每当你选择**搜索结果**列表中的播客时，freeAudio 就会获取该源并在下方的**所选结果中的剧集**列表中显示其剧集——标题和发布日期。

* 在该预览列表中选择一剧集并按 `Enter`，或打开其上下文菜单（应用程序键 / `Shift+F10`，或右键单击）并选择**预览**，以通过常规播放器开始播放它。所有常规播放控件（暂停、音量、时移等）在其上的工作方式与在任何其他电台或剧集上完全相同。
* 在预览剧集时，相同的上下文菜单会显示**停止预览**来代替**预览**——选择它，或在该剧集上再次按 `Enter` 即可停止。
* 预览不会让你订阅任何内容；它纯粹用于在决定之前进行收听。预览列表本身是临时的——只要你选择不同的搜索结果，它就会被替换，并且它不会像你的实际订阅那样持久保存在任何地方。

### 管理订阅

添加了一些源后，它们会出现在**订阅**列表中。每个条目显示源标题和可用的剧集数量。

* **选择一个源**以在下方的列表中查看其剧集。订阅列表下方的**源详情**只读文本框显示源标题、作者、描述、剧集计数和网址。
* **刷新源** — 选择它并按**刷新源**按钮（通过上下文菜单可用，见下文）以获取最新剧集。当你打开“播客”选项卡时，所有源也会在后台自动刷新，因此你通常无需人工干预即可看到最近的剧集。
* **移除源** — 选择它并按 `Delete` 或使用上下文菜单将其从你的订阅中移除。系统会要求你确认移除。

**源的上下文菜单：** 右键单击源，或选择它并按应用程序键 / `Shift+F10`，以打开包含以下内容的菜单：

* **刷新源** — 立即获取新剧集。
* **为此播客保存音频配置文件** / **清除音频配置文件** — 请参阅[播客音频配置文件](https://www.google.com/search?q=%23podcast-audio-profile)。
* **移除源** — 删除订阅。
* **复制源网址** — 将源网址复制到剪贴板。

### 浏览和播放剧集

在订阅列表中选择一个源；其剧集会出现在下方的**剧集**列表中。每个剧集显示：

* 其剧集编号（1 = 源中最旧的剧集，向上计数到最新）。
* 其发布日期（如果可用）。
* 其标题。
* 如果剧集已完整播放，则带有“已听”前缀。
* 持续时间后缀，即总持续时间（如果从未播放过）或已播放/总进度（如果部分播放过）。

**播放：**

* 选择一集并按 `Enter` 或 `Space` 开始播放。如果一集以前部分播放过，它将从你离开的地方恢复。
* 在播放剧集时，该行*不会*更新——这是有意设计的，这样当你坐在上面时，NVDA 就不会反复重新播报该行。它的“已听”标志和持续时间在你暂停剧集或播放完成的那一刻会立即刷新，因此显示总是在最重要的时候保持准确；它只是在播放过程中不会一秒一秒地倒计时。
* 在“播客”选项卡上使用 `F3` / `F4` 移动到上一集/下一集并立即播放。你也可以在剧集列表聚焦时使用 `←` / `→`，或者在“播客”选项卡的任何地方使用 `Ctrl+←` / `Ctrl+→`——两者的工作方式完全相同。
* 使用 `Shift+F3` / `Shift+F4` 在源之间移动而不播放剧集。
* 在播放剧集时按 `Space` 可暂停或恢复播放。

**恢复播放：** freeAudio 会自动保存你在每个播客剧集中的进度——无论何时你暂停或剧集完成都会立即保存，在你继续收听时在后台每 15 秒保存一次，因此崩溃或意外重启不会丢失太多进度。如果你停止或暂停播放并稍后返回，剧集将从保存的职位恢复。如果你将剧集播放到最后（最后 3 秒内），它将被标记为“已听”并且不会恢复——下次它将从头开始播放，并且“已听”前缀会出现在列表中。

**剧集的上下文菜单：** 右键单击剧集，或选择它并按应用程序键 / `Shift+F10`，以打开包含以下内容的菜单：

* **播放剧集** — 开始播放。
* **下载剧集** — 将剧集文件下载到你的录音文件夹中。
* **为此播客保存音频配置文件** / **清除音频配置文件** — 与源自身的上下文菜单相同的命令，为方便起见包含在此处，这样你就不必切换回“订阅”列表。它们仍然为整个播客保存一个配置文件，而不是为此剧集保存单独的配置文件——请参阅[播客音频配置文件](https://www.google.com/search?q=%23podcast-audio-profile)。
* **复制剧集网址** — 将直接音频网址复制到剪贴板。

### 下载单集

选中一个单集并点击**下载单集**按钮（或使用上下文菜单）。单集将被下载到你的录音文件夹中（默认在 `Documents\freeAudio Recordings\`）。文件名基于单集标题和检测到的文件扩展名（`.mp3`、`.m4a`、`.ogg` 等）。NVDA 会播报下载开始和结束的时间。如果文件已经存在，系统会通知你并跳过下载。

### 筛选单集

单集列表上方有一个**筛选**字段。当你键入时，单集列表会实时进行筛选，以显示标题包含所键入文本的单集，或者单集编号与之完全匹配的单集——因此输入 `47` 会直接跳转到第 47 集，即使“47”并未出现在其标题的任何地方。NVDA 会在每次更改后播报匹配的单集数量。从筛选字段按 `Down`（向下）箭头可将焦点直接移入筛选后的列表中。

### 播客播放详情

播客单集使用 **BASS 后端**播放（这是用于广播串流的同一引擎，并且从本版本起，是 freeAudio 使用的唯一播放后端）。由于单集是渐进式下载且可定位的，因此你可以在播放播客时使用时移倒回/快进快捷键（`Ctrl+Win+J`/`Ctrl+Win+K`）在单集中进行定位。播放位置会自动保存，以便你稍后恢复。

**分级定位：** 与直播广播固定的 15 秒倒回不同，在播客、有声读物或点唱机音轨中定位会根据你按键的方式进行缩放，因此你可以进行小幅修正或长距离跳转而无需重复按键：

* **按住按键不放**（自动重复）每次重复后退或前进 **5 秒** — 与此快捷键一直用于文件的微调量相同。
* **一次 deliberate（刻意的）轻触**定位 **12 秒**。
* **连续两次轻触**定位 **1 分钟**。
* **三次或更多次轻触**定位 **5 分钟**；同一串按键中的进一步轻触不会再进一步升级。

刻意的轻触会按住片刻才真正进行定位，以防还有其他轻触随之而来 — 每次轻触序列只发生一次定位，其大小取决于最终进行了多少次轻触，而不是每次轻触量的总和。定位后，NVDA 会播报单集中产生的已过/剩余位置，而不仅仅是“向前/向后 X 秒”。

**播放速度：** 你可以使用 `Ctrl+Win+Shift+K`（更快）和 `Ctrl+Win+Shift+J`（更慢）调整播客单集、有声读物和点唱机音轨的播放速度。速度以 0.1x 的增量变化，范围从 0.5x 到 2.0x，并且保持音高不变。这需要将可选的 `bass_fx.dll` 库放置在插件文件夹中。如果缺少该库，NVDA 会通知你该功能不可用。

**移调（音高偏移）：** 独立于播放速度，你可以使用 `Shift+Win+K` / `Shift+Win+J` 向上或向下移动播客单集、有声读物或点唱机音轨的音高 — 请参阅[移调（音高偏移）](https://www.google.com/search?q=%23transpose-pitch-shift)。移调同样需要 `bass_fx.dll`。

> **注意：** `bass_fx.dll` 默认未随 freeAudio 捆绑。你可以从 [BASS FX 页面](https://www.un4seen.com/bass-fx.html)下载它，并将其放置在插件的 `bass/x64`（适用于 64 位 NVDA）或 `bass`（适用于 32 位 NVDA）文件夹中以启用这些功能。

**恢复音效：** 每当单集从保存的位置恢复时，freeAudio 会在单独的通道上短暂播放柔和的盒式磁带加载音效，同时它会寻回到你保存的点，而不是在此期间让单集自身的音频从 0:00 开始清晰可闻地播放。每当 BASS 后端处于活动状态时，这都会自动发生，并且独立于**电台切换过渡**设置 — 该设置仅影响直播电台之间的切换，而不影响恢复播客或有声读物。

### 播客音频配置文件

右键单击“订阅”列表中的播客，或右键单击其任何单集，然后选择**为此播客保存音频配置文件**，将当前的音量、效果、EQ 增益和/或播放速度保存为绑定到该播客的配置文件。每当播放该播客的任何单集时，保存的设置都会自动应用，并覆盖全局默认值。由于该命令在源上下文菜单和单集上下文菜单中都可用，因此你无需切换回“订阅”列表即可触及它 — 无论哪种方式，它始终为整个播客保存一个配置文件，而不是每个单集保存一个单独的配置文件。

对话框可让你准确选择要保存的内容：

* **仅音量**
* **仅效果**
* **音量和效果**
* **音量和播放速度**
* **效果和播放速度**
* **仅播放速度**
* **音量、效果和播放速度**

只有你挑选的部分会被写入配置文件；任何遗漏的部分都会保留已经为其保存的任何内容。例如，在一个已经有保存的音量/效果配置文件的播客上选择**仅播放速度**，只会更新速度而保持其余部分不变。

**清除音频配置文件**从播客中移除保存的配置文件，可通过任一上下文菜单进行操作。它仅在播客当前具有保存的配置文件时才处于活动状态。

### 播客数据储存

你的订阅存储在 NVDA 用户配置文件夹中的 `freeAudio_podcasts.json` 中。单集位置单独存储在同一位置的 `podcast_positions.json` 中。这两个文件都是纯 JSON，可以进行备份或传输到另一台计算机。

## 有声读物（GETEM、LibriVox 和古腾堡计划）

freeAudio 包含一个有声读物播放器，可以从三个来源搜索、播放和下载书籍：

* **[GETEM](https://getem.boun.edu.tr/)** — 由海峡大学视障人士中心运营的数字图书馆。需要免费会员资格才能流式传输或下载书籍的音频（浏览则不需要） — 请参阅下文的[登录](https://www.google.com/search?q=%23signing-in)。
* **[LibriVox](https://librivox.org/)** — 志愿朗读的公共领域有声读物项目。完全不需要任何账户或登录；其整个目录（包括音频文件本身）都属于公共领域且完全公开可访问。
* **古腾堡计划公开有声读物合集** — 托管在 [archive.org](https://archive.org/) 上的真人朗读和计算机合成朗读的公共领域有声读物，是古腾堡计划文本图书馆的伴侣。像 LibriVox 一样，不需要账户或登录。

来自这三个来源的结果会一起显示在一个合并的**搜索结果**列表和一个合并的**图书馆**列表中 — 没有单独的选项卡或下拉菜单可以在它们之间切换。每本书的来源（GETEM、LibriVox 或古腾堡计划）作为标签显示在其标题旁边以及其详细信息中，因此你随时可以辨别出你正在查看的是哪个来源。你可以通过完全相同的方式从任何来源搜索、预览、添加、播放和下载书籍；在跨部分自动恢复的情况下播放多部分作品；以及下载书籍以供离线收听 — 所有这些都完全无障碍。

如果你只想搜索其中的一部分，可以从 **NVDA 菜单 → 首选项 → Settings → freeAudio** 中的**有声读物来源**检查清单中单独关闭任何来源。这三个来源默认均已启用。

> **注意：** 收听 GETEM 书籍需要免费的 GETEM 会员资格。浏览 GETEM 的目录不需要账户，但解析和播放 GETEM 书籍的音频则需要 — 请参阅下文的[登录](https://www.google.com/search?q=%23signing-in)。LibriVox 和古腾堡计划的书籍永远不需要账户。

### 访问“有声读物”选项卡

使用 `Ctrl+Win+R` 打开电台浏览器，并使用 `Ctrl+Tab` 或 `Alt+7` 切换到**有声读物**选项卡。该选项卡有三个主要区域：

1. **搜索** — 一个用于一次性搜索所有已启用目录的文本字段，并在运行搜索时显示结果列表。
2. **图书馆** — 你从任一来源添加的书籍列表，你可以在其中播放、下载和管理它们。
3. **详细信息** — 一个只读框，显示任一列表中当前选定书籍的来源、标题、作者、朗读人、出版商、格式、部分数量、描述和目录网址。

### 登录

GETEM 要求注册会员才能流式传输或下载书籍的实际音频，尽管目录本身可以自由搜索。在 **NVDA 菜单 → 首选项 → Settings → freeAudio** 中输入一次你的 GETEM 用户名和密码；它们会加密存储在磁盘上（通过 Windows 数据保护 API，绑定到你的 Windows 用户账户），并在之后自动重复使用。如果你在输入凭据之前尝试播放或下载 GETEM 书籍，freeAudio 会提示你先在“设置”中添加它们。

LibriVox 和古腾堡计划根本不需要登录步骤 — 它们的搜索结果和音频可以立即搜索、预览、播放和下载，无需输入任何凭据。

### 搜索有声读物

在搜索字段中键入搜索词并按 `Enter`。freeAudio 会搜索设置中启用的任何来源并将结果合并到一个列表中：

* **GETEM** 通过标题、作者、朗读人、主题和出版商同时进行搜索，因为 GETEM 自己的搜索表单仅支持将它们全部缩小范围，而不是在它们中的任何一个中进行单一搜索。仅显示实际上可作为音频获得的著作（真人或计算机合成朗读、音频描述、广播剧、DAISY 有声读物等）；盲文、大字版和其他非音频格式会被自动过滤掉。
* **LibriVox** 针对其公共领域目录按标题或作者/朗读人进行搜索。
* **古腾堡计划** 针对 archive.org 上的公开有声读物合集按标题或作者进行搜索。

将书籍的目录/详细信息页面网址（GETEM 书籍的 GETEM 目录页面，或 LibriVox 或古腾堡计划标题的 archive.org“详细信息”页面）直接粘贴到搜索字段中，会直接解析该单本书，而不是运行关键词搜索。

NVDA 会播报总共找到了多少本有声读物。

选择一个结果会在下方的详细信息框中显示其详细信息 — 作者、朗读人、出版商、格式和部分数量。

**预览：** 选择一个结果并按 `Space`，或打开其上下文菜单（应用程序键 / `Shift+F10`，或右键单击）并选择**预览**，即可从其第一部分开始播放它，而不将其添加到你的图书馆。在预览书籍时，相同的上下文菜单会在其位置显示**停止预览** — 选择它或再次按 `Space` 即可停止。预览书籍不会保存你的收听位置，因为该位置仅针对已在你的图书馆中的书籍进行跟踪。

**添加至图书馆：** 选择一个结果并按 `Enter`，或使用其上下文菜单并选择**添加至图书馆**将其添加。如果该书籍已经存在，freeAudio 会告诉你。

### 你的图书馆

你添加的书籍会出现在**图书馆**列表中，显示标题、作者和格式。选择一本会在下方显示其详细信息。

* 按 `Enter` 或 `Space` 播放所选书籍。如果未加载任何内容，`Space` 会将其启动；如果已经在播放某些内容，`Space` 会改为将其暂停，这与播放器的其余部分保持一致。
* 在“有声读物”选项卡上使用 `F3` / `F4` 移动到你图书馆中的上一本 / 下一本**书**并开始播放。当图书馆列表聚焦时，`Ctrl+←` / `Ctrl+→` 执行相同操作。
* 使用 `Shift+F3` / `Shift+F4` 在当前播放的书籍的**部分**之间移动 — 与“播客”选项卡相反，在“播客”选项卡中 F3/F4 在单集之间移动，而 Shift+F3/Shift+F4 在源之间移动。这是因为一本书即使有多个部分也只是一个单一的图书馆条目，因此这里更细粒度的“部分”导航位于 Shift 修改键上。

**图书馆条目的上下文菜单：** 右键单击一本书，或选择它并按应用程序键 / `Shift+F10`，以打开包含以下内容的菜单：

* **播放媒体** — 开始播放，与 `Enter` 相同。
* **下载书籍** — 下载书籍的每个部分；请参阅下文的[下载有声读物](https://www.google.com/search?q=%23downloading-audio-books)。
* **复制网址** — 将书籍的目录页面网址复制到剪贴板（GETEM 书籍的 GETEM 目录页面，或 LibriVox 或古腾堡计划书籍的 archive.org 详细信息页面）。
* **为此书保存音频配置文件** / **清除音频配置文件** — 请参阅下文的[有声读物音频配置文件](https://www.google.com/search?q=%23audio-book-audio-profile)。
* **从图书馆移除** — 从你的图书馆中删除该书籍。

你还可以一次标记多本书并将它们全部移除 — 请参阅“收藏夹”下的[标记和移除多个项目](https://www.google.com/search?q=%23marking-and-removing-multiple-items)。

### 播放与恢复

多部分作品在播放器中被视为单个项目，而不是每个部分一行 — 就像播客单集无论如何交付都是单个项目一样。freeAudio 会记住你上次收听的部分，并在下次播放该书时自动在该处恢复，甚至跨 NVDA 重启也是如此。

当某一部分结束时，freeAudio 会自动开始同一本书的下一部分 — 你无需手动选择它。即使当时电台浏览器窗口已关闭，也会发生这种情况；下次打开窗口时，图书馆列表中显示的“正在播放”部分会自动重新同步。

播放通过小型本地中继流式传输，而不是先下载整个部分，因此在收到前几个字节后就会开始播放 — 与播客使用的立即开始行为相同。所有常规播放器控件（暂停、音量、时移、播放速度、移调、输出设备等）在有声读物上的工作方式与在电台或播客单集上的工作方式完全相同。

像播客一样，从保存的位置恢复一本书会在 freeAudio 寻回到你保存的点时播放短暂的盒式磁带加载音效 — 请参阅[播客播放详情](https://www.google.com/search?q=%23podcast-playback-details)中的**恢复音效**说明。

### 有声读物音频配置文件

右键单击“图书馆”列表中的一本书，并选择**为此书保存音频配置文件**，将当前的音量、效果、EQ 增益和/或播放速度保存为绑定到该书的配置文件。每当播放该书（或其任何部分）时，保存的设置都会自动应用，并覆盖全局默认值。这与上面的[播客音频配置文件](https://www.google.com/search?q=%23podcast-audio-profile)完全相同，包括相同的保存选项集（音量、效果和/或播放速度，以任意组合）以及相同的局部更新行为。

**清除音频配置文件**从书中移除保存的配置文件；它仅在当前书具有保存的配置文件时才处于活动状态。

### 下载有声读物

在你的图书馆中选择一本书，并从其上下文菜单中选择**下载书籍**，将每个部分保存到其自己的文件夹中（以书名命名），该文件夹位于你的录音文件夹内（默认在 `Documents\freeAudio Recordings\` 中）。文件已编号，因此无论 GETEM 本身如何称呼它们，这些部分总是能按收听顺序重新排序。下载完成后，NVDA 会播报保存了多少部分；如果某个部分失败，则会在计数旁报告最后的错误。

### 有声读物数据储存

每个来源都保留自己的图书馆文件，尽管它们在“有声读物”选项卡中合并显示。你的 GETEM 图书馆（已添加的书籍及其收听进度）存储在 `freeAudio_getem_library.json` 中，你的 LibriVox 图书馆单独存储在 `freeAudio_librivox_library.json` 中，你的古腾堡计划图书馆单独存储在 `freeAudio_gutenberg_library.json` 中 — 这三个都位于 NVDA 用户配置文件夹中。你加密的 GETEM 凭据单独存储在同一位置的 `freeAudio_getem_credentials.bin` 中，并且只能由保存它们的同一 Windows 用户账户解密。LibriVox 和古腾堡计划没有凭据文件，因为两者都不需要账户。

## 本地点唱机

freeAudio 的**点唱机**选项卡为你提供了两种播放电脑上已有的音频文件的方法：按名称搜索每个连接的驱动器上的文件，或者建立一个持久的个人文件和文件夹图书馆。你从这里播放的任何内容都会获得与播客或有声读物相同的待遇 — 自动恢复、分级倒回/快进、播放速度、音高移调和每项音频配置文件都完全相同。

### 访问“点唱机”选项卡

使用 `Ctrl+Win+R` 打开电台浏览器，并使用 `Ctrl+Tab` 或 `Alt+8` 切换到**点唱机**选项卡，或者使用全局快捷键 `Ctrl+Win+U` 从任意位置直接打开它。该选项卡组织为三个主要区域：

1. **在设备上搜索** — 一个文本字段，用于搜索每个本地连接的就绪驱动器，查找文件名包含键入文本的音频文件。按 `Enter` 开始搜索。
2. **搜索结果** — 运行搜索后出现的一个列表，显示匹配的文件。在此之前处于隐藏状态，因此当没有什么可搜索时，选项卡保持整洁。
3. **点唱机和音轨** — 你添加的项目的持久列表，后面跟着所选条目中的音轨列表（对于文件条目，仅该一个文件；对于文件夹条目，在其中找到的每个音频文件）。

**添加文件...**、**添加文件夹...** 和**移除**按钮位于“音轨”列表下方。

### 在设备上搜索文件

将文件名的任何部分键入**在设备上搜索**字段中并按 `Enter`。freeAudio 会遍历每个本地连接的驱动器 — 固定磁盘、USB 驱动器、存储卡、映射的网络驱动器 — 寻找文件名包含搜索文本的音频文件（`.mp3`、`.wav`、`.ogg`、`.flac`、`.m4a`、`.m4b`、`.aac`、`.wma`、`.opus` 等）。搜索在后台运行，因此 NVDA 保持响应。

* 在搜索结果上按 **Space**（空格）可对其进行预览 — 通过正常播放器开始播放。在同一文件上再次按 **Space** 可停止预览。
* 在搜索结果上按 **Enter** 可将其添加到你的点唱机中。
* 上下文菜单（应用程序键 / `Shift+F10`，或右键单击）提供相同的两个操作：**预览** / **停止预览**和**添加到点唱机**。
* 开始新搜索会取消任何仍在运行的搜索，因此在大驱动器上的慢速搜索永远不会延迟新搜索。

### 构建你的点唱机

点唱机列表是你的持久个人图书馆。可以添加两种类型的产品：

* **添加文件...** — 打开一个文件选择器，允许你添加一个或单个音频文件。所有选择的文件将一次性全部添加。
* **添加文件夹...** — 打开一个文件夹选择器，允许你同时选择多个文件夹。在每个选定文件夹中找到的每个音频文件（包括在其子文件夹中）都被视为该文件夹的**音轨**之一。每个文件夹作为其自己的单个条目添加到你的点唱机列表中；选择该文件夹时，其中的文件会列在“音轨”列表中。选择器关闭后，NVDA 会播报添加了多少个文件夹。
* **移除** — 从你的点唱机中删除当前选定的条目。移除文件夹条目不会从磁盘或设备中删除任何文件；它只是忘记该文件夹。你还可以一次标记多个条目并将它们全部移除 — 请参阅“收藏夹”下的[标记和移除多个项目](https://www.google.com/search?q=%23marking-and-removing-multiple-items)。
* 你的点唱机列表会自动保存，因此它能在 NVDA 重启后存活。文件夹内容按需扫描并缓存，因此即使对于非常大的收藏，添加文件夹也是瞬间完成的 — 完整扫描在你第一次选择该文件夹时发生。如果你在 freeAudio 之外向文件夹中添加了文件，请使用文件夹上下文菜单中的**重新扫描文件夹**项目将其拾取。

### 从 Windows 资源管理器添加项目

另外两个命令仅在 Windows 资源管理器的文件列表中聚焦于文件或文件夹时可用（详细信息/图标列表——而不是地址栏、文件夹树、功能区或搜索框），它们可让你完全跳过上面的“添加文件……”/“添加文件夹……”对话框：

* **使用 freeAudio 播放聚焦的文件** — 直接播放突出显示的高亮音频文件，无需将其预先放入你的点唱机列表中。仅对文件有效；如果在文件夹上使用该命令，系统会提示你改为将该文件夹添加到点唱机中。
* **将聚焦的项目添加至 freeAudio 点唱机** — 将突出显示的文件或文件夹添加到你的点唱机列表中，就像你使用了上面的添加文件…**或**添加文件夹…一样。

两个命令都没有默认分配按键。**在文件资源管理器窗口内聚焦时**，从“NVDA 菜单 → 首选项 → 输入手势”中分配一个按键 — 它们会出现在资源管理器自己的部分中而不是“所有应用程序”下，因此你选择的按键组合仅在你于资源管理器中浏览文件时才会触发这些命令；在其他任何地方，它都会保留其原本的含义。

### 从点唱机播放

* **Enter** 在点唱机条目上可直接播放它：对于文件条目，播放文件本身；对于文件夹条目，播放其第一个音轨。
* **Space** 在点唱机条目上：如果正在播放任何内容，则暂停播放；否则播放聚焦的条目。
* **Enter** 或 **Space** 在“音轨”列表上可播放聚焦的音轨。如果已经在播放某些内容，**Space** 会首先暂停。
* **F3 / F4** 在“点唱机”选项卡上可在当前选定条目内的音轨之间移动并立即播放。
* **Shift+F3 / Shift+F4** 在点唱机列表中的条目（文件和文件夹）之间移动，呼应了这些键在“播客”选项卡上的源之间移动的方式。
* **Ctrl+← / Ctrl+→** 在条目或音轨列表聚焦时执行与音轨列表上的 F3/F4 相同的功能 — 上一首 / 下一首音轨。

### 点唱机播放详情

从点唱机播放的每一个音轨都可以获得完整的本地媒体待遇：

* **恢复：** freeAudio 会记住你在每个音轨中的位置，在暂停时以及播放期间定期保存该位置，并在你再次播放时从该点恢复 — 甚至在 NVDA 重启后也是如此。
* **分级定位：** `Ctrl+Win+J` / `Ctrl+Win+K` 使用与播客和有声读物相同的轻触/按住缩放比例在音轨内进行定位 — 每次重复按住 5 秒，轻触一次 12 秒，轻触两次 1 分钟，轻触三次或更多次 5 分钟。
* **播放速度：** `Ctrl+Win+Shift+J` / `Ctrl+Win+Shift+K` 以 0.1x 的步长从 0.5x 调整到 2.0x 调整速度，并保持音高不变。需要 `bass_fx.dll`。
* **移调：** `Shift+Win+J` / `Shift+Win+K` 在不改变速度的情况下移动音高 — 请参阅[移调（音高偏移）](https://www.google.com/search?q=%23transpose-pitch-shift)。同样需要 `bass_fx.dll`。
* **音频配置文件：** 音轨的音量、效果、EQ 和速度可以通过在设置了适当的设置时播放音轨来全局保存 — 点唱机目前不公开每个音轨的配置文件菜单，因此适用当前的全局设置。

> **注意：** 时移缓冲区（用于倒回直播电台）刻意**不**为点唱机音轨启动 — 它们已经是可定位的本地文件，因此后台捕获没有用处，只会消耗磁盘空间。倒回和快进仍然有效，因为它们直接对正在播放的文件起作用。

## 移调（音高偏移）

移调可在不改变其**速度**的情况下向上或向下移动正在播放的内容的**音高** — 这与通过简单地加快音轨速度所获得的“花栗鼠效应”相反。它对于匹配特定朗读者的自然音域、将音乐移调到更友好的调性，或者只是调整录音使其听起来更舒适非常有用。

移调适用于**播客**、**有声读物**和**点唱机音轨** — 与播放速度快捷键已经适用的“本地的、可定位的、具备速度能力的媒体”相同。它不适用于没有固定音高可移的直播广播电台。

* **`Shift+Win+K`** — 将音高提高一步。
* **`Shift+Win+J`** — 将音高降低一步。

每一步是**一个全音的八分之一** — 也就是说，**0.25 个半音**（一个全音是 2 个半音，因此 8 步构成一个全音，48 步构成一个八度）。范围是 **−12.00 到 +12.00 个半音**，即向上或向下满一个八度。NVDA 会在每一步之后播报新值，例如“**+1.25 个半音**”；返回 0.0 时会播报“**正常音高**”。

移调会在各个音轨之间被记住，就像播放速度一样：在音轨播放时设置一次意味着你播放的下一个具备速度能力的音轨将以相同的偏移开始，除非该音轨自身保存的音频配置文件覆盖了它。播放没有保存移调值的音轨会将偏移重置回 0.0（正常音高），就像同样的规则已经适用于速度一样。

**要求：** 与播放速度一样，移调需要将可选的 **`bass_fx.dll`** 库放置在插件的 `bass/x64`（64 位 NVDA）或 `bass`（32 位 NVDA）文件夹中。如果缺少该库，NVDA 会告诉你该功能不可用，并且你设置的值仍会为下一个具备速度能力的串流被记住。

## 喜欢的歌曲

当启用**将喜欢的歌曲保存到文ಂತಹ档**选项时，通过连续按三次 `Ctrl+Win+I` 复制到剪贴板的音轨信息也会逐行追加到 `Documents\freeAudio Recordings\likedSongs.txt` 中。

在广播 ICY 元数据的电台上，会直接保存音轨标题和艺术家。在没有 ICY 元数据的电台上，Shazam 识别结果会保存到同一个文件 — 两个来源共享同一个列表。如果该文件不存在，则会自动创建；每个条目都追加到文件末尾，以前的条目永不删除。

## 喜欢的歌曲选项卡

电台浏览器中的**喜欢的歌曲**选项卡显示保存在 `likedSongs.txt` 中的所有音轨。每次打开该选项卡时，列表都会从文件中自动重新加载。右键单击一首歌，或选择它并按应用程序键 / `Shift+F10`，以打开包含下面描述的相同操作的上下文菜单。

列表上方的**筛选**字段可让你实时缩窄显示的音轨范围。键入歌曲标题或艺术家名称的任意部分，列表就会在每一次按键时立即更新。NVDA 会在每次更改后播报匹配结果的数量。从筛选字段按 `Down`（向下）箭头可将焦点直接移入列表中。

从列表中选择一个音轨可启用以下操作：

* **在 Spotify 上播放：** 尝试直接打开 Spotify 桌面应用。如果未安装该应用，则回退到 Spotify 网站并自动开始播放第一个结果。
* **在 YouTube 上播放（`Alt+O`）：** 在 YouTube 上搜索所选音轨并在默认浏览器中打开结果。
* **显示歌词：** 获取并显示所选音轨的歌词。歌词检索自 [lrclib.net](https://lrclib.net)（免费，无需账户）。当搜索在后台运行时，会播报一条简短的“正在获取歌词…”消息。如果找到歌词，它们会在一个只读对话框中打开，你可以在其中用 NVDA 阅读它们并将其复制到剪贴板。如果未找到歌词，NVDA 会进行播报。为了防止重复请求，在获取正在进行时，该按钮会暂时禁用。
* **移除（`Alt+M`）：** 从 `likedSongs.txt` 中删除所选音轨并更新列表。当列表聚焦时，`Delete` 键也会触发此按钮。你还可以一次标记多首歌曲并将它们全部移除 — 请参阅“收藏夹”下的[标记和移除多个项目](https://www.google.com/search?q=%23marking-and-removing-multiple-items)。
* **刷新（`Alt+E`）：** 从文件中重新加载列表。

Spotify、YouTube、显示歌词和移除按钮仅在列表中选择了真正的音轨时才启用。

### 歌词服务

freeAudio 使用 [lrclib.net](https://lrclib.net) 来获取歌词 — 这是一个不需要 API 密钥或账户的免费开放数据库。查找过程会解析存储在 `likedSongs.txt` 中的音轨字符串，并尝试逐渐放宽的查询，直到找到歌词：

1. 使用完整的艺术家名称和清理后的标题进行精确匹配（在搜索之前会剥离诸如“Remastered”、“Live”或年份标签之类的噪声后缀）。
2. 使用完整的艺术家名称和原始标题进行精确匹配（如果清理更改了它）。
3. 仅使用第一位艺术家名称和清理后的标题进行精确匹配（对于诸如“Artist A & Artist B”的多艺术家字符串）。
4. 使用第一位艺术家名称和清理后的标题进行模糊搜索。
5. 作为最后手段，使用原始音轨字符串进行模糊搜索。

当普通歌词可用时，它们会按原样显示。当只有时间同步的 LRC 歌词可用时，时间戳会被剥离，并显示纯文本。纯音乐音轨会报告为未找到。

## 设置

可以从“NVDA 菜单 → 首选项 → 设置 → freeAudio”中配置以下选项：

| 选项 | 描述 |
| --- | --- |
| 音轨更改语音 | 选择是使用 NVDA 合成器还是选定的 SAPI5 语音朗读自动播报的音轨更改。 |
| SAPI5 语音 | 当**音轨更改语音**设置为 SAPI5 时，选择使用哪个已安装的 SAPI5 语音来播报音轨更改。该列表是在后台从系统上安装的语音中填充的。 |
| 音频输出设备（BASS 后端） | 设置广播播放的音频输出设备。该列表包括系统上所有兼容 BASS 的设备加上一个“系统默认”选项。更改在保存时立即应用；如果所选设备断开连接，插件会自动回退到系统默认并播报更改。仅在 BASS 后端使用时处于活动状态。 |
| 音频设备刷新模式（BASS 后端） | 控制 freeAudio 刷新 BASS 输出设备编号的方式。**可靠**模式（默认）实时探测设备并更准确地跟踪蓝牙/USB 更改，但可能会使设备更改稍微变慢。**快速**模式使用当前的 BASS 设备列表且速度更快，但设备编号可能会保持陈旧，直到重启 BASS 或 NVDA。 |
| 音量 | 设置插件的起始音量（0–200）。使用 `Ctrl+Win+↑` / `Ctrl+Win+↓` 在播放期间所做的更改也会反映在此处。 |

## 静音通知

当在“设置”中启用了**静音通知**时，NVDA 会使以下自动播报静音：

* 当新电台开始播放时的电台名称
* 播放状态更改：播放、暂停、停止
* 背景音乐模式：开始 / 停止
* 录音事件：开始、停止、完成（即时、歌曲和定时录音）
* ICY 音轨更改播报，即使也启用了**自动播报音轨更改**

有意**不受**影响的播报包括：错误消息、收藏夹反馈（已添加 / 已在列表中）、音乐识别结果和更新通知。

可以从“NVDA 菜单 → 首选项 → 设置 → freeAudio”中切换该设置，或者通过未分配的输入手势随时即时切换（从“NVDA 菜单 → 首选项 → 输入手势 → freeAudio”中分配一个）。切换时，NVDA 会播报一次“Notifications muted”（通知已静音）或“Notifications unmuted”（通知已取消静音）以确认更改。

## 自动播报音轨更改

当在“设置”中启用了**自动播报音轨更改**选项时，freeAudio 大约每 5 秒在后台检查一次活动电台的 ICY 元数据串流。当音轨更改时，新标题由 NVDA 自动读取 — 无需按键。

当切换到新电台时，一旦建立连接，就会播报第一个音轨信息。如果你切换到一个不广播 ICY 元数据的电台，系统将保持安静，并且不会重复前一个电台的音轨信息。

此功能默认禁用，可以从“NVDA 菜单 → 首选项 → 设置 → freeAudio”中进行切换。

## 播放

freeAudio 将 **BASS** 用作一切内容的唯一播放后端 — 网络广播、播客、有声读物和点唱机音轨。不需要单独安装；它随插件一起捆绑。对 VLC、PotPlayer 和 Windows Media Player 作为回退后端支持已被移除；始终使用 BASS。

BASS 将音频直接发送到 Windows 音频堆栈，并在 Windows 音量合成器中显示为名为“pythonw.exe”的独立音频源，与 NVDA 分开。这意味着 freeAudio 音频在与 NVDA 语音完全独立的通道上流动：当 NVDA 正在说话时，广播不会中断、混合或受 NVDA 自身音频设置的影响。用户可以在 Windows 音量合成器中独立于 NVDA 调整广播音量。支持 HTTP、HTTPS 和大多数嵌入式串流格式。

播客单集、有声读物章节和点唱机音轨通过 BASS 播放，因为它可以将串流打开为可定位的文件（即使在下载时也是如此），从而允许精确的位置跟踪、分级倒回/快进、播放速度、音高移调和恢复。音频镜像、时移以及播客/有声读物/点唱机的定位和恢复都依赖于 BASS 并且始终可用。

## 检查更新

freeAudio 通过 GitHub 自动检查新版本。

**自动检查：** 在 NVDA 启动 15 秒后在后台静默运行。如果发现新版本，你将收到通知；如果未发现，则不显示消息。

**手动检查：** 可以从“NVDA 菜单 → 工具 → freeAudio → **检查更新…**”按需触发。以这种方式启动时，即使版本是最新的，也会播报结果。

**找到更新时：** 会打开一个对话框，显示版本号和你的已安装版本。

* 如果 GitHub 发布页面上提供了可直接下载的 `.nvda-addon` 文件，则会显示**下载并安装**按钮。确认后，该文件会在后台下载，NVDA 会播报下载何时开始，并且 NVDA 自己的安装屏幕会自动打开。
* 如果没有可用的直接下载链接，则会显示**打开页面**按钮，并在默认浏览器中打开 GitHub 发布页面。

**要禁用自动检查：** 从“NVDA 菜单 → 首选项 → 设置 → freeAudio”中关闭**自动检查更新**选项。
