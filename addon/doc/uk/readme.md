# freeAudio — додаток для NVDA

freeAudio — це повнофункціональний додаток для інтернет-радіо, подкастів, аудіокниг і локальної музики для екранного зчитувача NVDA. Те, що починалося як простий спосіб трансляції інтернет-радіостанцій, перетворилося на повноцінний, повністю доступний центр прослуховування — кожен екран, діалог і елемент керування розроблені з нуля для використання з клавіатури та екранного зчитувача, без потреби в миші в будь-який момент.

## Що вміє freeAudio

- **Інтернет-радіо** — Переглядайте та шукайте понад 50 000 станцій із каталогу [Браузер радіостанцій](https://www.radio-browser.info/), результати доповнюються TuneIn та iHeartRadio. Зберігайте улюблені станції, змінюйте їхній порядок і переходьте до будь-якої з них глобальною комбінацією клавіш з будь-якого місця Windows — див. [Каталог Браузер радіостанцій](#каталог-браузер-радіостанцій) та [Улюблене](#улюблене).
- **Подкасти** — Підписуйтеся на будь-який RSS/Atom-канал, або шукайте в каталозі подкастів Apple та переглядайте епізоди перед підпискою. Позиція відтворення зберігається автоматично — див. [Подкасти](#подкасти).
- **Аудіокниги** — Шукайте, транслюйте та завантажуйте книги з трьох джерел: [GETEM](https://getem.boun.edu.tr/), цифрової бібліотеки для людей з порушеннями зору Університету Боазічі; [LibriVox](https://librivox.org/), волонтерського проекту аудіокниг у суспільному надбанні; та колекції аудіокниг проекту Гутенберг. LibriVox і проект Гутенберг не потребують облікового запису. Багаточастинні твори автоматично відновлюються з місця, де ви зупинилися — див. [Аудіокниги (GETEM, LibriVox і проект Гутенберг)](#аудіокниги-getem-librivox-і-проект-гутенберг).
- **Локальна черга прослуховування** — Шукайте аудіофайли на будь-якому підключеному диску за назвою файлу або створіть особисту бібліотеку файлів і папок, і відтворюйте їх із тими самими засобами відновлення, пошуку, швидкості та тону, що й подкасти та аудіокниги — див. [Локальна черга прослуховування](#локальна-черга-прослуховування).
- **Закладки** — Ставте закладку в поточній позиції частини аудіокниги, епізоду подкасту або треку черги прослуховування, а потім повертайтеся до неї. Закладка може містити текстову нотатку або записану голосову нотатку, яка відтворюється, коли відтворення досягає закладки, а дві закладки можна використати для повтору ділянки між ними — див. [Закладки](#закладки).
- **Запис** — Записуйте поточний ефір миттєво, записуйте окремий трек від початку до кінця, записуйте кожен трек станції в окремий файл до зупинки або плануйте одноразові та повторювані записи — усе без переривання відтворення — див. [Запис](#запис).
- **Тайм-шифт (перемотування прямого радіо)** — Призупиняйте та перемотувайте пряму станцію, як відеореєстратор, а потім повертайтеся до прямого ефіру, коли забажаєте — див. [Тайм-шифт (перемотування прямого радіо)](#тайм-шифт-перемотування-прямого-радіо).
- **Розпізнавання треків і улюблені треки** — Ідентифікуйте треки без метаданих за допомогою Shazam, зберігайте улюблені треки у текстовий файл і шукайте їхні тексти — див. [Розпізнавання треків](#розпізнавання-треків) та [Улюблені треки](#улюблені-треки).
- **Аудіопрофілі та ефекти** — Зберігайте окремі налаштування гучності, ефектів, еквалайзера та швидкості відтворення для кожної станції, подкасту, аудіокниги чи треку, і застосовуйте ефекти в реальному часі (хор, реверберація, підсилення еквалайзера тощо) через бекенд BASS — див. [Аудіопрофіль станції](#аудіопрофіль-станції).
- **Транспонування (зміщення висоти тону)** — Зміщуйте висоту тону подкастів, аудіокниг і треків черги прослуховування вгору або вниз без зміни швидкості, використовуючи вбудований компонент `bass_fx` — див. [Транспонування (зміщення висоти тону)](#транспонування-зміщення-висоти-тону).
- **Дзеркало аудіо** — Надсилайте один і той самий потік на два пристрої виводу одночасно, наприклад на колонки та навушники — див. [Дзеркало аудіо](#дзеркало-аудіо).
- **Режим Obligato (фонова музика)** — Тихо відтворюйте вибрану улюблену станцію у фоні на окремому пристрої та з окремою гучністю, незалежно від того, що відтворюється (або не відтворюється) як основний медіапотік — див. [Режим Obligato](#режим-obligato).
- **Таймери** — Плануйте запуск улюбленої станції або зупинку відтворення у вказаний час — див. [Таймер](#таймер).
- **Глибокий доступ із клавіатури та шрифту Брайля** — Кожна функція доступна повністю з клавіатури, з глобальними комбінаціями, що працюють з будь-якого місця Windows (включно з `Ctrl+Win+F3` / `Ctrl+Win+F4` для переходу між станціями, епізодами, книгами та треками без відкриття вікна), прямими комбінаціями для окремих улюблених станцій, записів черги прослуховування та аудіокниг, а також необов'язковим виводом на брайлівський дисплей для всіх мовних сповіщень freeAudio.

## Каталог Браузер радіостанцій

freeAudio використовує відкриту базу даних [Браузер радіостанцій](https://www.radio-browser.info/) для свого каталогу станцій. Браузер радіостанцій — це безкоштовний каталог, яким керує спільнота і який містить понад 50 000 інтернет-радіостанцій з усього світу. Реєстрація чи обліковий запис не потрібні, а його API відкритий для всіх. Кожна станція містить інформацію про адресу, країну, жанр, мову та бітрейт; станції сортуються за вподобаннями користувачів. freeAudio підключається до цього API через дзеркальні сервери, розташовані в Німеччині, Нідерландах та Австрії; якщо один сервер недоступний, він автоматично перемикається на наступний.

Щоб браузер залишався швидким і не навантажував API під час кожного пошуку чи зміни країни, freeAudio зберігає на диску локальний кеш каталогу станцій. Цей кеш автоматично оновлюється у фоновому режимі за періодичним розкладом, тому список, який ви бачите, зазвичай уже актуальний без жодних дій з вашого боку. Ви також можете в будь-який момент примусово запустити негайну повторну синхронізацію кнопкою **Оновити список станцій** — див. [Браузер радіостанцій](#браузер-радіостанцій) нижче.

## Додавання станції до Браузера радіостанцій

Якщо станція, яку ви шукаєте, відсутня в каталозі Браузера радіостанцій, ви можете додати її самостійно за адресою [https://www.radio-browser.info/add](https://www.radio-browser.info/add). Обліковий запис чи реєстрація не потрібні.

Заповніть форму на цій сторінці:

- **URL потоку** *(обов'язково)* — прямий URL аудіопотоку, що закінчується на `.mp3`, `.aac`, `.ogg` або подібне. Це не адреса веб-сайту станції; це адреса самого потоку, яку ви вставляєте в медіаплеєр. Більшість станцій публікують URL свого потоку на своєму веб-сайті або в розділі «Слухати в прямому ефірі».
- **Назва станції** *(обов'язково)* — назва станції, як вона має з'являтися в каталозі.
- **Головна сторінка** — адреса веб-сайту станції.
- **Країна та мова** — виберіть країну та мову з комбінованих списків.
- **Теги** — ключові слова жанру або теми, розділені комами, наприклад `новини`, `джаз`, `класика`. Вони використовуються для пошуку та фільтрування.
- **URL логотипу** — пряме посилання на зображення логотипу станції, якщо воно є.

Після надсилання станція проходить перевірку та додається до публічного каталогу. Після затвердження вона автоматично з’явиться у пошуку freeAudio та списках країн, оскільки каталог оновлюється з API в режимі реального часу.

## Встановлення

Завантажте файл `.nvda-addon`, натисніть на ньому Enter і перезапустіть NVDA, коли буде запропоновано.

## Комбінації клавіш

Усі комбінації можна перепризначити в меню NVDA → Параметри → Жести вводу → freeAudio. Ці комбінації працюють будь-де, незалежно від того, який діалог сфокусований.

Деякі з цих комбінацій збігаються з тими, що використовує сама Windows. Якщо ви хочете залишити власну комбінацію Windows, не перепризначаючи freeAudio, натисніть `NVDA+F2` (Пропустити наступну клавішу) безпосередньо перед комбінацією — NVDA передасть цю комбінацію безпосередньо Windows, а не перехоплюватиме її для freeAudio.

| Комбінація | Функція | Опис |
|---|---|---|
| `Ctrl+Win+R` | Відкрити браузер радіостанцій | Відкриває діалог браузера радіостанцій, якщо він закритий, або виводить його на передній план, якщо він вже відкритий. |
| `Ctrl+Win+O` | Відкрити вкладку «Подкасти» | Відкриває браузер радіостанцій (якщо закритий) або виводить його на передній план і перемикається безпосередньо на вкладку **Подкасти**. |
| `Ctrl+Win+L` | Відкрити вкладку «Аудіокниги» | Відкриває браузер радіостанцій (якщо закритий) або виводить його на передній план і перемикається безпосередньо на вкладку **Аудіокниги**. |
| `Ctrl+Win+U` | Відкрити вкладку «Черга прослуховування» | Відкриває браузер радіостанцій (якщо закритий) або виводить його на передній план і перемикається безпосередньо на вкладку **Черга прослуховування**, з фокусом на полі пошуку на пристроях. |
| `Ctrl+Win+P` | Пауза / відновлення | Зупиняє поточну станцію, якщо вона відтворюється; відновлює, якщо була призупинена. Якщо нічого не відтворюється, запускає останню станцію або відкриває список улюблених залежно від ваших налаштувань. Подвійне натискання одразу переходить до вибраної вкладки. Триразове натискання виконує окрему дію залежно від вашого налаштування. |
| `Ctrl+Win+S` | Зупинити | Повністю зупиняє поточну станцію та скидає плеєр. |
| `Ctrl+Win+→` | Наступна улюблена | Переходить до наступної станції у списку улюблених. У кінці списку переходить на початок. |
| `Ctrl+Win+←` | Попередня улюблена | Переходить до попередньої станції у списку улюблених. На початку списку переходить у кінець. |
| `Ctrl+Win+F3` | Попередній елемент | Клавіша `F3` браузера радіостанцій, доступна й при закритому вікні. Що вона робить, залежить від того, що відтворюється: **радіо** — попередня станція; **подкаст** — попередній епізод; **аудіокнига** — попередня книга; **черга прослуховування** — попередній трек у папці. На початку списку оголошує «Уже на першому …». Якщо нічого не відтворюється, клавіша передається далі без змін. Див. [Перемикання елементів при закритому браузері радіостанцій](#перемикання-елементів-при-закритому-браузері-радіостанцій). |
| `Ctrl+Win+F4` | Наступний елемент | Клавіша `F4` браузера радіостанцій, доступна й при закритому вікні: залежно від того, що відтворюється, наступна станція, епізод подкасту, аудіокнига або трек черги прослуховування. |
| `Ctrl+Win+Shift+F3` | Попередній канал / частина / елемент | Клавіша `Shift+F3` браузера радіостанцій, доступна й при закритому вікні: **радіо** — попередня станція (як `Ctrl+Win+F3`); **подкаст** — попередній подкаст із підписок; **аудіокнига** — попередня частина книги; **черга прослуховування** — попередній запис (файл або папка). |
| `Ctrl+Win+Shift+F4` | Наступний канал / частина / елемент | Клавіша `Shift+F4` браузера радіостанцій, доступна й при закритому вікні: залежно від того, що відтворюється, наступна станція, подкаст із підписок, частина аудіокниги або запис черги прослуховування. |
| `Ctrl+Win+↑` | Збільшити гучність | Збільшує гучність на 5; максимум 200. |
| `Ctrl+Win+↓` | Зменшити гучність | Зменшує гучність на 5; мінімум 0. |
| `Ctrl+Win+V` | Додати до улюблених / Завантажити медіа | Додає станцію, що зараз відтворюється, до списку улюблених або завантажує епізод подкасту чи аудіокнигу, що зараз відтворюється. Повідомляє, якщо станція вже є у списку або якщо медіа вже завантажено. Не застосовується, коли відтворюється трек черги прослуховування: freeAudio повідомляє, що ця комбінація призначена лише для станцій, подкастів або аудіокниг. |
| `Ctrl+Win+Shift+K` | Збільшити швидкість відтворення | Збільшує швидкість відтворення епізоду подкасту, аудіокниги або треку черги прослуховування на 0,1x (зі збереженням висоти тону). Діапазон: від 0,5x до 2,0x. |
| `Ctrl+Win+Shift+J` | Зменшити швидкість відтворення | Зменшує швидкість відтворення на 0,1x. |
| `Shift+Win+K` | Транспонування вгору | Підвищує висоту тону епізоду подкасту, аудіокниги або треку черги прослуховування кроками по 1/8 цілого тону (0,25 півтону) без зміни швидкості. Діапазон: від −12,00 до +12,00 півтонів. Див. [Транспонування (зміщення висоти тону)](#транспонування-зміщення-висоти-тону). |
| `Shift+Win+J` | Транспонування вниз | Знижує висоту тону кроками по 1/8 цілого тону без зміни швидкості. |
| `Ctrl+Win+F12` | Додати закладку | Додає закладку в поточній позиції відтворення частини аудіокниги, епізоду подкасту або треку черги прослуховування. Недоступно для прямих радіостанцій. Див. [Закладки](#закладки). |
| `Ctrl+Win+I` | Інформація про станцію | Повідомляє назву станції, що зараз відтворюється. Натисніть двічі, щоб у діалозі показати деталі, такі як країна, жанр та бітрейт. Натисніть тричі, щоб скопіювати інформацію про поточний трек (метадані ICY) до буфера обміну, якщо вона доступна; якщо метадані відсутні, замість цього запускається розпізнавання музики Shazam. Натисніть чотири рази, щоб примусово запустити розпізнавання музики у разі неправильних метаданих ICY. Поки триває запис, його назва також оголошується; під час запису кожного треку це трек, який записується зараз. |
| `Ctrl+Win+M` | Дзеркало аудіо | Одночасно дзеркально показує потік на додатковий пристрій виведення аудіо. Натисніть ще раз, щоб зупинити дзеркальний показ. |
| `Ctrl+Win+Shift+M` | Режим Obligato (фонова музика) | Тихо відтворює вибрану улюблену станцію у фоні на окремому пристрої та з окремою гучністю. Перше натискання відкриває діалог вибору станції, пристрою та відносної гучності. Повторне натискання зупиняє режим. |
| `Ctrl+Win+E` | Запис (миттєвий / треку / кожного треку) | Натисніть один раз, щоб почати запис поточної станції; натисніть ще раз, щоб зупинити. Натисніть **двічі**, щоб почати **запис поточного треку** — файл отримає назву поточного треку, а запис автоматично зупиниться, коли трек зміниться. Натисніть **тричі**, щоб записувати **кожен трек** до зупинки: кожен трек зберігається в окремий файл. Натисніть двічі, поки запис треку або кожного треку активний, щоб зупинити його достроково. Відтворення продовжується без перерв у всіх режимах запису. ### Перемикання елементів при закритому браузері радіостанцій

У браузері радіостанцій клавіші `F3`, `F4`, `Shift+F3` і `Shift+F4` виконують різні дії залежно від активної вкладки. Їхні глобальні відповідники — `Ctrl+Win+F3`, `Ctrl+Win+F4`, `Ctrl+Win+Shift+F3` і `Ctrl+Win+Shift+F4` — працюють будь-де у Windows, незалежно від того, відкрите вікно чи ні. Оскільки вкладки, на яку можна зорієнтуватися, немає, freeAudio вирішує за тим, **що відтворюється зараз**:

| Відтворюється | `Ctrl+Win+F3` / `Ctrl+Win+F4` | `Ctrl+Win+Shift+F3` / `Ctrl+Win+Shift+F4` |
|---|---|---|
| Радіостанція | Попередня / наступна станція у списку, з якого її востаннє запущено (результати «Усі станції» або «Улюблене»), з переходом по колу на кінцях. Якщо станції в цьому списку немає, використовується список улюблених. | Те саме, що й без `Shift`. |
| Епізод подкасту | Попередній / наступний епізод того самого каналу. | Попередній / наступний подкаст із підписок. Оскільки немає списку, у якому можна виділити канал, відтворюється його перший епізод у списку. |
| Аудіокнига | Попередня / наступна книга у вашій бібліотеці з відновленням з останньої прослуханої частини. | Попередня / наступна частина поточної книги. |
| Трек черги прослуховування | Попередній / наступний трек папки, що відтворюється. | Попередній / наступний запис у списку; папка відновлюється з місця, де її було зупинено востаннє. |

Що варто знати:

- Якщо нічого не відтворюється, комбінація клавіш передається до Windows без змін, так само як `Ctrl+Win+→` / `Ctrl+Win+←`.
- На будь-якому кінці списку (крім радіо, де список замикається по колу) NVDA оголошує «Уже на першому …» або «Уже на останньому …», і нічого не змінюється. Трек, запущений не як частина папки, не має сусідів і повідомляє те саме.
- **Автоматичний перехід не переривається.** Після пропуску всередині папки або аудіокниги наступний трек чи частина, як і раніше, запускається сама, коли поточна закінчується, незалежно від того, відкритий браузер радіостанцій чи ні. Натискання «наступний» на останньому треку папки не скидає збережену позицію папки.
- Список епізодів подкасту зберігається в пам'яті лише протягом поточного сеансу NVDA. Якщо його ще не завантажено — наприклад, одразу після запуску NVDA — NVDA попросить відкрити браузер радіостанцій і один раз вибрати цей подкаст; після цього клавіші працюють і при закритому вікні.
- Якщо браузер радіостанцій відкритий, перехід до іншої аудіокниги з клавіатури також оновлює у вікні книгу й частину «зараз відтворюється», щоб його власний автоматичний перехід продовжився з правильного місця.

Як і будь-яку команду freeAudio, їх можна перепризначити в меню NVDA → Параметри → Жести вводу → freeAudio.

## Браузер радіостанцій

freeAudio також додає підменю **freeAudio** до меню «Інструменти» NVDA. Звідти ви можете безпосередньо відкрити браузер станцій та налаштування freeAudio.

Діалог, що відкривається за допомогою комбінації клавіш `Ctrl+Win+R`, містить вісім вкладок: «Усі станції», «Улюблене», «Запис», «Таймер», «Улюблені треки», «Подкасти», «Аудіокниги» та «Черга прослуховування». Переміщатися між вкладками можна за допомогою `Ctrl+Tab` або комбінацій `Alt+1`–`Alt+8`. Вкладки «Подкасти», «Аудіокниги» та «Черга прослуховування» можна вимкнути параметром **Модулі** (див. [Налаштування](#налаштування)); вимкнені вкладки не показуються.

Коли відкривається вкладка «Усі станції», 1000 станцій, що набрали найбільшу кількість вподобань, автоматично завантажуються з Браузера радіостанцій. Вибір країни зі списку оновлює список, показуючи станції цієї країни. Введення тексту в поле пошуку миттєво виконує повний пошук по всій базі даних Браузера радіостанцій одночасно за назвою, країною та жанром.

Під час пошуку результати з Браузера радіостанцій доповнюються станціями з TuneIn та iHeartRadio (коли доступні). Ці зовнішні джерела шукаються у фоні, а їхні результати автоматично додаються до списку, що дає доступ до ще більшої кількості станцій без жодних додаткових дій.

Комбінований список **Пристрій виводу** у нижній частині діалога браузера радіостанцій — поза вкладками — містить список усіх аудіопристроїв, розпізнаних BASS. Вибір пристрою негайно перенаправляє аудіовивід на нього та зберігає вибір назавжди; той самий пристрій автоматично використовується в наступній сесії. Якщо вибраний пристрій не підключено, додаток автоматично повертається до системного значення. Натисніть `F11`, щоб відкрити спрощений вибір пристрою з будь-якого місця браузера радіостанцій. Вибір не показується автоматично і відкривається лише тоді, коли BASS виявляє більше одного фізичного пристрою виводу. Коли доступний лише один, вибір не потрібен, і freeAudio використовує системний пристрій виводу за замовчуванням.

Елементи керування **Гучність** (0–200) та **Ефекти** у цій же області можна налаштовувати в будь-який час, поки діалог відкритий. У списку ефектів можна одночасно ввімкнути хор, компресор, спотворення, ехо, фленджер, булькання, реверберацію, еквалайзер: підсилення низьких частот, еквалайзер: підсилення високих частот та еквалайзер: підсилення вокалу; зміни миттєво застосовуються до активного потоку. Кожен ефект також можна миттєво вмикати чи вимикати комбінаціями від `Ctrl+1` до `Ctrl+0`, не відриваючи рук від клавіатури — див. [Комбінації клавіш для ефектів](#комбінації-клавіш-для-ефектів) нижче.

Коли ввімкнено один або кілька ефектів еквалайзера, для кожної активної смуги з’являється **регулятор підсилення**. Рівень посилення можна встановити в діапазоні від −15 дБ до +15 дБ; початкове значення — «Баси» +9 дБ, «Високі частоти» +9 дБ та «Вокал» +6 дБ. Регулятори посилення відображаються лише для тих смуг еквалайзера, які наразі позначені, і автоматично приховуються, коли ефекти еквалайзера знімаються. Значення посилення зберігаються глобально та відновлюються під час наступної сесії.

Кнопка **Відтворення/Пауза** також розташована внизу діалога. Якщо жодна станція не відтворюється, вона запускає вибрану станцію; якщо станція вже відтворюється, вона призупиняє відтворення.

Кнопка **Оновити список станцій** негайно повторно синхронізує локальний каталог станцій з API Браузера радіостанцій, замість того щоб чекати на періодичне фонове оновлення. Поки оновлення виконується, кнопка недоступна, а NVDA оголошує, що оновлення триває; якщо натиснути її ще раз до завершення поточного оновлення, NVDA повідомить, що оновлення вже виконується. Після завершення оновлення NVDA оголошує, що список станцій оновлено, а поточні результати пошуку чи список за країною автоматично оновлюються, відображаючи нові дані.

Коли станція вибрана у списку, кнопка **Інформація про станцію** показує таку інформацію, як країна, мова, жанр, формат, бітрейт, веб-сайт та URL потоку в окремому діалозі. Кожне поле показується у власному текстовому полі, доступному лише для читання; ви можете переходити між полями за допомогою клавіші Tab та скопіювати всю інформацію до буфера обміну одночасно за допомогою кнопки **Копіювати все до буфера обміну**. Ця кнопка доступна як на вкладці «Усі станції», так і на вкладці «Улюблене».

### Контекстне меню станції

Клацніть правою кнопкою миші на станції у списку «Усі станції» або «Улюблене», або виберіть її та натисніть клавішу контекстного меню чи `Shift+F10`, щоб відкрити контекстне меню зі швидкими діями:

- **Інформація про станцію** — те саме, що й описана вище кнопка «Інформація про станцію».
- **Додати до улюблених** *(вкладка «Усі станції»)* / **Видалити станцію** *(вкладка «Улюблене»)*.
- **Перейменувати станцію** *(вкладка «Улюблене»)* — те саме, що й `F9`.
- **Зберегти аудіопрофіль для цієї станції** / **Очистити аудіопрофіль** *(вкладка «Улюблене»)* — див. [Аудіопрофіль станції](#аудіопрофіль-станції).
- **Перевірити URL** — перевіряє, чи наразі доступний потік вибраної станції, не запускаючи відтворення, та оголошує результат (доступно, або причину збою, наприклад, помилку HTTP чи тайм-аут мережі).

Показуються лише пункти, що стосуються поточної вкладки та вибору.

### Комбінації клавіш у діалозі

Наступні клавіші працюють лише тоді, коли діалог Браузера радіостанцій активний.

#### Клавіші F

| Комбінація | Функція | Опис |
|---|---|---|
| `F1` | Довідка | Відкриває файл довідки додатка у браузері. Спочатку здійснюється пошук довідки для мови, яка використовується в NVDA; якщо її не знайдено, відкривається довідка початковою мовою. |
| `F2` | Що зараз відтворюється | Оголошує назву станції та треку, що зараз відтворюються. Натисніть двічі, щоб у діалозі показати детальну інформацію, таку як країна, жанр та бітрейт. ## Улюблене

Список улюблених — це особиста колекція радіостанцій, яка зберігається постійно. Щоб додати радіостанцію, виберіть її у списку та натисніть кнопку «Додати до улюблених» або скористайтеся комбінацією клавіш `Alt+V`. Ця ж комбінація клавіш видаляє радіостанцію, яка вже є у списку, після її вибору.

До улюбленого можна перейти за допомогою комбінацій клавіш `Ctrl+Win+→` та `Ctrl+Win+←`; ці комбінації працюють навіть тоді, коли діалог браузера радіостанцій закритий.

Щоб видалити станцію зі списку улюблених, виберіть її та натисніть кнопку **Видалити станцію** або клавішу `Delete`. Після видалення фокус та вибір автоматично переходять до наступної станції у списку. Якщо видалена станція була останньою, фокус переходить до попередньої станції. Якщо список стає порожнім, фокус переходить до кнопки «Відтворити».

### Позначення та видалення кількох елементів

Улюблене, Улюблені треки, бібліотека аудіокниг і список черги прослуховування підтримують позначення кількох елементів і видалення їх разом за один крок:

- Натисніть **`.`** (крапку) на виділеному елементі, щоб позначити або зняти позначку. NVDA оголошує зміну, а рядок позначеного елемента позначається як «(позначено)», щоб його стан залишався зрозумілим під час переміщення списком.
- Натисніть **`Shift+Home`**, щоб позначити або зняти позначку з усіх елементів від поточного до першого в списку, або **`Shift+End`** — до останнього. Позначається чи знімається діапазон залежно від поточного стану елемента. Після цього фокус переміщується на дальній кінець діапазону, а NVDA оголошує, скільки елементів змінено.
- Натисніть **`Delete`**, щоб видалити всі позначені елементи одразу. Якщо нічого не позначено, `Delete` видаляє лише поточний вибраний елемент, як і раніше.
- Контекстне меню кожного списку (клавіша «Контекстне меню» / `Shift+F10`) містить команду **Видалити вибране**, активну лише тоді, коли позначено принаймні один елемент.
- Перед видаленням з’являється діалог підтвердження із зазначенням кількості елементів.

Позначки діють окремо для кожного списку й очищаються після видалення (або зняття позначки); вони не зберігаються між сеансами.

Списки закладок на вкладках «Подкасти», «Аудіокниги» та «Черга прослуховування» використовують те саме позначення `.`, і саме позначені закладки використовують команди **Видалити вибране** та **Повторювати між позначеними закладками** — див. [Закладки](#закладки).

### Експорт та імпорт улюблених

Вкладка «Улюблене» містить дві кнопки для резервного копіювання та відновлення списку станцій:

**Експортувати улюблені…** — зберігає весь список улюблених у файл. У діалозі збереження можна вибрати один із двох форматів:

- **JSON** (`.json`) — повна резервна копія, що зберігає назви станцій, URL-адреси потоків і всі метадані. Рекомендується для подальшого відновлення списку або його перенесення на інший комп'ютер.
- **Плейлист M3U** (`.m3u`) — стандартний формат плейлиста, сумісний із більшістю медіаплеєрів і радіододатків. Зверніть увагу, що M3U не зберігає всі метадані станцій, тому відновлення з M3U може містити менше деталей, ніж резервна копія JSON.

**Імпортувати улюблені…** — завантажує станції з раніше експортованого файлу JSON або M3U. Після вибору файлу пропонується вибрати спосіб додавання станцій:

- **Так (Об'єднати)** — додає імпортовані станції до наявного списку, не видаляючи поточні улюблені. Дублікати не додаються повторно.
- **Ні (Замінити)** — повністю очищає поточний список улюблених і замінює його вмістом імпортованого файлу.
- **Скасувати** — повертається до браузера без внесення жодних змін.

Після успішного імпорту список улюблених, список станцій для запланованих записів і список станцій таймера оновлюються автоматично.

### Організація улюблених у групи

Улюблені станції можуть належати до папки/групи, що показується як суфікс «— Група» після назви станції у списку (наприклад, «NPR Newscast — NPR»).

- **Імпорт з M3U** — якщо файл використовує тег `group-title` (угода, прийнята у DVBViewer та більшості інших редакторів і плеєрів M3U) для організації станцій у папки, freeAudio зчитує його та зберігає групу кожної станції під час імпорту. Експорт улюблених назад у M3U записує той самий тег, тож структура папок зберігається під час циклу через freeAudio.
- **Призначення або видалення групи вручну** — позначте одну або кілька улюблених станцій знаком `.` (див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів) вище), потім виберіть **Призначити групі…** у контекстному меню (клавіша «Контекстне меню» / `Shift+F10`) і введіть назву групи. Залиште поле порожнім, щоб вилучити позначені станції з групи. Якщо нічого не позначено, команда застосовується до поточної вибраної станції.
- **Фільтрування за групою** — поле фільтра над списком улюблених також збігається з назвами груп і приймає кілька слів, кожне з яких може збігатися з різним полем. Наприклад, введення `Houston Classical` знаходить «Houston Public Media Classical», навіть якщо ця точна фраза ніде не зустрічається — «Houston» збігається з групою, а «Classical» — з назвою станції.

### Зміна порядку в списку улюблених

Вибравши станцію на вкладці «Улюблене», натисніть клавішу «кома», щоб увійти в режим переміщення — пролунає звуковий сигнал. Перейдіть до потрібної позиції за допомогою клавіш зі стрілками, а потім знову натисніть клавішу «кома». Станція буде розміщена у вибраній позиції, а нове розташування одразу збережеться. Повторне натискання клавіші «кома» у цій же позиції скасує переміщення.

### Прямі комбінації клавіш для улюблених станцій

Кожна станція у вашому списку улюблених зареєстрована як окремий скрипт у діалозі «Жести вводу» NVDA, у категорії **Станції freeAudio**. Ви можете призначити будь-яку комбінацію клавіш для будь-якої станції та натискати її з будь-якого місця — не потрібно спочатку відкривати діалог Браузер радіостанцій.

Щоб призначити комбінацію клавіш:

1. Відкрийте меню NVDA → Параметри → Жести вводу.
2. Розгорніть категорію **Станції freeAudio**.
3. Знайдіть станцію за назвою, виберіть її та натисніть **Додати**.
4. Натисніть потрібну комбінацію клавіш і підтвердіть вибір.

Комбінація клавіш негайно активує станцію. Якщо пізніше станцію буде видалено з ваших улюблених, її запис зникне з категорії, а будь-яка призначена їй комбінація клавіш автоматично буде скасована NVDA. Коли до улюблених додається нова станція, вона одразу з’являється в категорії — діалог «Жести вводу» не потрібно відкривати знову.

### Додавання користувацької станції

Щоб додати станцію, якої немає в Браузері радіостанцій, скористайтеся кнопкою «Додати користувацьку станцію». У діалозі, що з’явиться, введіть назву станції та URL потоку, щоб додати її безпосередньо до списку улюблених. Власні станції можна відтворювати та змінювати їхній порядок так само, як і будь-які інші улюблені станції.

У цьому діалозі доступні дві додаткові кнопки:

- **Перевірити URL** — перевіряє введений URL потоку перед додаванням станції та оголошує, чи він доступний. Корисно, щоб виявити помилку в написанні або неробочу URL-адресу до того, як вона потрапить до списку улюблених.
- **Додати до каталогу Браузера радіостанцій…** — відкриває [сторінку подання до Браузера радіостанцій](https://www.radio-browser.info/add) у браузері за замовчуванням, щоб ви могли поділитися станцією з ширшою спільнотою Браузера радіостанцій, щойно підтвердите, що вона працює. Про те, що очікується у формі подання, див. розділ [Додавання станції до Браузера радіостанцій](#додавання-станції-до-браузера-радіостанцій) вище.

### Аудіопрофіль станції

На вкладці «Улюблені» є дві кнопки для керування налаштуваннями звуку для кожної станції:

**Зберегти аудіопрофіль для цієї станції** — зберігає поточний рівень гучності, активні ефекти (хор, еквалайзер тощо) та значення підсилення еквалайзера як профіль, прив’язаний до цієї конкретної станції. Щоразу, коли починається відтворення цієї станції, її збережені налаштування гучності, ефектів та підсилення автоматично застосовуються, замінюючи загальні початкові налаштування.

**Очистити аудіопрофіль** — видаляє збережений аудіопрофіль з вибраної станції. Після очищення станція повертається до загальних налаштувань гучності, ефектів та підсилення еквалайзера. Ця кнопка активна лише тоді, коли вибрана станція вже має збережений профіль.

Обидві кнопки розташовані під списком улюблених і стають активними лише тоді, коли у списку вибрано станцію.

## Розпізнавання треків

Тричі натиснувши `Ctrl+Win+I`, запускається розпізнавання треків на основі Shazam для потоку, що відтворюється. Розпізнавання починається лише тоді, коли метадані ICY (інформація про трек, що транслюється станцією) недоступні; якщо метадані присутні, вони копіюються в буфер обміну. Чотириразове натискання `Ctrl+Win+I` примусово запускає розпізнавання навіть тоді, коли станція передає метадані, що допомагає, якщо ці метадані неправильні.

Розпізнавання працює наступним чином: за допомогою ffmpeg (який представляється так само, як медіаплеєр, тож станції, що відмовляють невідомим програмам, усе одно відповідають) із потоку витягується короткий аудіофрагмент, до нього застосовується алгоритм Shazam для визначення «відбитка», а результат надсилається на сервери Shazam. Якщо розпізнавання проходить успішно, назва треку, виконавець, альбом та рік випуску оголошуються NVDA та автоматично копіюються до буфера обміну. Якщо увімкнено опцію **Зберегти вподобані пісні у текстовий файл**, результат розпізнавання також додається до файлу `likedSongs.txt`.

Якщо ffmpeg не може прочитати потік безпосередньо — наприклад, тому що станція відмовляє в його підключенні, або тому що адреса потоку закінчується на `.nsv` (типово для серверів SHOUTcast), через що ffmpeg неправильно визначає аудіоформат — freeAudio сам записує короткий зразок із потоку й доручає ffmpeg декодувати цей файл. Це відбувається автоматично; окремого налаштування для цього немає.

**Аудіосигнали:** Два висхідних звукових сигнали лунають, коли розпізнавання починається, і два низхідних — коли воно закінчується. Короткий звуковий сигнал відтворюється кожні 2 секунди, доки процес триває.

**Вимога:** Потрібна наявність ffmpeg.exe. Якщо ffmpeg.exe знаходиться у папці додатка, він використовуватиметься автоматично; якщо в іншому місці — шлях можна вказати в Налаштуваннях. Завантажити ffmpeg можна з [ffmpeg.org](https://ffmpeg.org/download.html).

**Примітка щодо станцій, які вставляють рекламу:** деякі станції транслюють коротку рекламу під час кожного нового підключення до свого потоку, окремо від ефіру, який ви вже слухаєте. Розпізнавання уникає вибірки цієї реклами, повторно використовуючи наявне фонове з’єднання freeAudio з потоком (те саме, що використовується для [Тайм-шифту (перемотування прямого радіо)](#тайм-шифт-перемотування-прямого-радіо)), замість того щоб відкривати нове, тому воно розпізнає те, що насправді грає, а не рекламу. Це працює автоматично і не потребує налаштування.

## Дзеркало аудіо

Комбінація клавіш `Ctrl+Win+M` дозволяє одночасно відтворювати потокове аудіо на другому пристрої відтворення. Це зручно, коли потрібно слухати аудіо одночасно на двох різних пристроях, наприклад на колонках і навушниках.

Після першого натискання з’являється діалог з переліком доступних пристроїв виведення. Як тільки пристрій обрано, починається дзеркальне відтворення, при цьому основне відтворення не переривається. Повторне натискання зупиняє дзеркалювання.

**Приклади використання:**

- **Динаміки + навушники** — Гість може слухати той самий потік в навушниках, поки ви слухаєте його через динаміки комп’ютера.
- **Налаштування запису** — Направте сигнал головного виходу на колонки, а сигнал другого виходу — на зовнішній записний пристрій або аудіоінтерфейс для зовнішнього запису.
- **Multi-room** — Відтворюйте треки одночасно через Bluetooth-колонку та вбудований динамік; для передачі звуку в іншу кімнату не потрібно додаткового програмного забезпечення.
- **Дистанційний моніторинг** — під час сеансу спільного використання екрана або віддаленого доступу до робочого столу як локальний, так і віддалений користувач можуть одночасно слухати один і той самий аудіопотік.

## Режим Obligato

Комбінація `Ctrl+Win+Shift+M` тихо відтворює улюблену станцію у фоні на повністю окремому аудіодвижку від основного плеєра — як м’який музичний фон під час будь-якої вашої діяльності.

Під час першого натискання відкривається діалог із трьома елементами керування:

- **Фонова станція** — список улюблених станцій для вибору тієї, що циклічно відтворюватиметься у фоні. Потрібна принаймні одна улюблена станція; якщо список улюблених порожній, freeAudio просить спочатку додати станцію (`Ctrl+Win+V` під час відтворення станції).
- **Аудіовихід** — пристрій, через який відтворюється фонова станція: **Те саме, що й основний вихід** (за замовчуванням), **Системний за замовчуванням** або будь-який конкретний пристрій, який бачить freeAudio.
- **Гучність фону** — гучність фонової станції у відсотках від поточної гучності основного плеєра (25%, 50%, 75%, 100%, 125% або 150%). Ваш вибір запам’ятовується на наступний раз.

Після запуску фонова станція продовжує відтворюватися незалежно від основного плеєра — перемикання станцій, подкастів чи аудіокниг на основному плеєрі або його повна зупинка не переривають режим Obligato. Дві речі залишаються пов’язаними з основним плеєром автоматично:

- **Гучність** — гучність фону безперервно підтримується на вибраному відсотку від поточної гучності основного плеєра, тож підвищення чи зниження основної гучності (`Ctrl+Win+↑`/`↓`) так само масштабує фонову музику.
- **Пауза** — призупинення основного плеєра (`Ctrl+Win+P`) призупиняє й фонову станцію, а відновлення — відновлює. Повна зупинка основного плеєра не вважається паузою, тож фонова станція продовжує відтворюватися.

Натисніть `Ctrl+Win+Shift+M` знову, щоб зупинити режим Obligato.

## Запис

Записи початково зберігаються у папці `Documents\freeAudio Recordings\`. Назва файлу містить назву станції (або назву трека у режимі запису трека) та час початку запису. Папку для записів можна змінити у будь-який час: Меню NVDA → Параметри → Налаштування → freeAudio → **Папка записів**.

Параметр **Формат виводу запису** керує тим, як зберігаються завершені записи:

- **Оригінальний формат потоку** записує потік точно як отримано. Трансляція HLS може створити файл `.ts`.
- **Тільки аудіо, оригінальний кодек** видаляє відео/контейнер без повторного кодування аудіо. Наприклад, аудіо AAC із запису HLS `.ts` зазвичай зберігається як `.m4a` зі збереженням якості мовлення.
- **MP3** конвертує аудіо після запису з вибраним бітрейтом. Конвертація використовує `ffmpeg.exe`, що входить до складу freeAudio, і виконується у фоні, щоб NVDA залишалася чутливою. Якщо конвертація не вдається, оригінальний запис зберігається.

**Миттєвий запис:** під час відтворення станції натисніть `Ctrl+Win+E` один раз. Натисніть знову, щоб зупинити. Відтворення при цьому не переривається.

**Запис трека (поточного треку):** Натисніть комбінацію клавіш `Ctrl+Win+E` **двічі** під час відтворення станції, яка транслює метадані ICY. Запис розпочнеться за мить після другого натискання — freeAudio ненадовго чекає, чи не буде третього натискання — і отримає назву поточного треку. Коли станція оголосить наступний трек, запис зупиниться в цей момент, і NVDA оголосить назву збереженого файлу. Якщо ви хочете завершити запис достроково, знову натисніть `Ctrl+Win+E` двічі. Якщо поточна станція не транслює метадані ICY, запис трека недоступний, і NVDA повідомить вас про це.

**Запис кожного треку:** Натисніть `Ctrl+Win+E` **тричі** поспіль, щоб записувати кожен трек, який грає станція, доки ви не зупините запис. freeAudio тримає одне з’єднання відкритим і починає новий файл під час кожної зміни треку, тож між треками нічого не втрачається. Кожен трек зберігається в окремий файл, названий за треком і часом початку. Коли запис починається, NVDA оголошує, що записується кожен трек, і наводить поточну назву. Щоб зупинити, натисніть `Ctrl+Win+E` двічі; NVDA оголосить, скільки треків збережено.

Кілька подробиць про запис кожного треку:

- Перший трек (записаний з моменту натискання клавіш) і останній трек (обрізаний під час зупинки) є неповними, тому їхні назви містять **(partial)** — наприклад `Artist - Title (partial) - 2026-10-09 10-15.mp3`.
- Фрагменти коротші за 15 секунд — джингли, рекламні вставки або назва, що мерехтить між двома значеннями — відкидаються замість збереження.
- Для цього потрібно, щоб станція передавала назви треків усередині самого аудіопотоку (метадані ICY). Станції HLS (`.m3u8`) і сервери, що не передають назви в такий спосіб, не можуть бути розділені на треки; NVDA повідомляє про це, і нічого не записується.
- Поки запис триває, `Ctrl+Win+I` оголошує трек, що записується зараз, а не той, з якого запис почався.

**Запланований запис:** Відкрийте вкладку Запис у браузері радіостанцій. Виберіть станцію з улюблених, введіть час початку у форматі ГГ:ХХ і тривалість у хвилинах, виберіть один або кілька активних днів, потім оберіть режим повторення та режим запису:

Поле **Фільтр** над списком станцій дозволяє звужувати список улюблених у режимі реального часу, щоб швидко знайти потрібну станцію.

**Активні дні:** Позначте один або кілька днів тижня. У режимі одноразового запису для кожного вибраного дня створюється окремий запис, встановлений на найближче настання цього дня. У режимі повторення запис виконується лише у позначені дні. Якщо жодного дня не вибрано, запис не обмежується конкретними днями.

**Режим повторення:**

- **Записати один раз** — створює одноразовий запис для кожного вибраного дня. Кожен запис встановлюється на найближче настання цього дня; якщо сьогоднішній час вже минув, запис автоматично переноситься на наступний тиждень.
- **Повторювати щотижня** — повторюється щотижня у вибрані активні дні до видалення зі списку розкладу.

**Зберегти запис у:** Для кожного запланованого запису можна вибрати збереження в початкову папку записів або у власну папку. Скористайтеся кнопкою **Огляд...**, щоб вибрати папку інтерактивно. Якщо вибрана папка стає недоступною, запис повертається до початкової папки, і ви отримуєте повідомлення.

**Режим запису:**

- **Запис під час прослуховування** — одночасне відтворення та запис через бекенд BASS.
- **Тільки запис** — запис у фоновому режимі без відтворення звуку; механізм запису підключається безпосередньо до потоку.

Після додавання розклад з’являється у списку нижче. Використовуйте кнопку **Видалити вибране**, щоб видалити розклад, або **Редагувати вибране**, щоб змінити його час, тривалість, повторення, активні дні, режим запису або папку виводу.

NVDA сповіщає про початок і завершення запису. Якщо NVDA перезапускається під час активного запланованого запису, запис автоматично відновлюється під час запуску.

**Як з’єднуються записи:** Миттєвий запис, запис трека та запис кожного треку відкривають власне з’єднання зі станцією, а не копіюють те, що ви чуєте, тож миттєвий запис або запис кожного треку продовжується, коли ви призупиняєте відтворення чи перемикаєтеся на іншу станцію — він продовжується зі станцією, з якої почався. Зупинка відтворення за допомогою `Ctrl+Win+S` під час запису спершу просить підтвердження, оскільки це також завершує запис. Зворотний бік окремого з’єднання — станція, яка подає коротку рекламу під час кожного нового підключення, може вставити цю рекламу на початок файлу.

## Тайм-шифт (перемотування прямого радіо)

Тайм-шифт дає можливість перемотувати станцію, яку ви зараз слухаєте, як відеореєстратор або магнітофон – зупинити момент, повернутися на кілька хвилин назад і наздогнати прямий ефір, коли забажаєте. Відтворення ніколи не припиняється: перемотування вперед і назад відбувається миттєво на тому ж аудіопотоці.

Функція **початково вимкнена**. Увімкніть її в меню NVDA → Параметри → Налаштування → freeAudio → **Увімкнути буфер тайм-шифту (перемотування прямого радіо)**, або миттєво перемикайте будь-коли за допомогою `Ctrl+Win+T`.

> **Примітка:** freeAudio постійно записує невеликий фоновий фрагмент поточного радіо — не тільки коли ця функція увімкнена — оскільки [Розпізнавання треків](#розпізнавання-треків) покладається на це для уникнення реклами, описаного в цьому розділі. Коли ця функція **вимкнена**, цей фоновий запис обмежується приблизно до останніх 45 секунд, а `Ctrl+Win+J`/`Ctrl+Win+K` залишаються недоступними — змінюється лише розмір буфера, а не те, чи він працює. Увімкнення цієї функції збільшує цей же запис до повного буфера перемотування, описаного нижче.

### Як це працює

Після увімкнення freeAudio безперервно записує потокову станцію у локальний буфер, що оновлюється у фоновому режимі, незалежно від звичайного відтворення. Буфер вміщує найновіше аудіо, до довжини, встановленої параметром **Тривалість буфера тайм-шифту**; старіші дані автоматично видаляються з початку буфера у міру надходження нових, тому буфер завжди показує «недавнє минуле» відносно поточного моменту.

- **`Ctrl+Win+J`** — Перемотування назад на 15 секунд. При першому натисканні відбувається перехід із прямого ефіру в режим відтворення із затримкою, починаючи з моменту, що відстає від поточного ефіру на 15 секунд. Кожне наступне натискання переміщує вас ще на 15 секунд назад, аж до межі буфера.
- **`Ctrl+Win+K`** — Перемотування вперед на 15 секунд у режимі відтворення із затримкою. Як тільки ви досягнете межі прямої трансляції, відтворення автоматично переключиться назад на пряму трансляцію, а NVDA оголосить «Повернення до прямої трансляції» — вам не потрібно робити нічого додаткового, щоб відновити звичайне прослуховування.
- **`Ctrl+Win+Alt+J`** / **`Ctrl+Win+Alt+K`** — Те саме перемотування назад і вперед, але кроками по 1 секунді замість 15, для точного налаштування. Див. [Точний пошук (1 секунда)](#точний-пошук-1-секунда).
- **`Ctrl+Win+T`** — Увімкнення або вимкнення всієї функції. Вимкнення цієї функції під час відтворення із затримкою негайно поверне вас до прямого відтворення та зупинить фонове захоплення для поточної станції.

Фонове захоплення продовжується весь час, поки активний тайм-шифт, тому край прямого ефіру продовжує рухатися вперед, навіть коли ви слухаєте щось кількахвилинної давнини — точно як справжній DVR.

### Увімкнення та прогрів буфера

Буфер починає заповнюватися, щойно станція починає грати (при увімкненій функції) або в момент, коли ви вмикаєте функцію під час прослуховування станції. Тому перемотування можливе лише після того, як реально накопичено кілька секунд звуку — якщо натиснути `Ctrl+Win+J` одразу після переключення станцій, NVDA повідомить, що в буфері поки недостатньо звуку. Просто зачекайте кілька секунд і спробуйте знову.

Переключення на іншу станцію завжди перезапускає буфер для нової станції; буферизований звук попередньої станції видаляється.

### Підтримувані потоки

Тайм-шифт працює з тим самим діапазоном потоків, які вже підтримує freeAudio:

- Звичайні HTTP/HTTPS-потоки (MP3, AAC, OGG тощо), включаючи сервери у стилі Shoutcast/Icecast.
- **HLS-потоки (`.m3u8`)** — freeAudio вирішує основний плейлист станції, відстежує медіаплейлист і завантажує сегменти у фоні, щоб буфер залишався заповненим, так само як і для звичайних потоків.

У рідкісному випадку, коли плейлист станції взагалі неможливо прочитати (наприклад, пошкоджений або недоступний маніфест `.m3u8`), NVDA повідомить, що перемотування недоступне для цієї конкретної станції.

### Вимоги та обмеження

- **Потребує бекенду BASS**, який freeAudio завжди використовує для відтворення (див. [Відтворення](#відтворення)).
- Довжина буфера встановлюється параметром **Тривалість буфера тайм-шифту** — див. [Налаштування](#налаштування).
- Буфер прив'язаний до станції: зміна станції, зупинка відтворення або перезапуск NVDA очищають його й починають заново.
- Відтворення з тайм-шифтом використовує власний локальний файл буфера і не створює збереженого запису — якщо хочете зберегти звук назавжди, використовуйте також Миттєвий запис (`Ctrl+Win+E`).

## Таймер

Відкрийте вкладку «Таймер» у браузері радіостанцій (`Alt+4`). Можна додати два типи таймерів:

Під час вибору станції для таймера-сигналу поле **Фільтр** над списком станцій дозволяє звужувати список улюблених у режимі реального часу.

**Сигнал — увімкнути радіо:** Автоматично починає відтворення обраної станції з ваших улюблених у вказаний час. Оберіть станцію та введіть час у форматі ГГ:ХХ.

**Сон — зупинка радіо:** Зупиняє відтворення у вказаний час. Коли спрацьовує таймер, гучність поступово зменшується протягом 60 секунд, перш ніж відтворення зупиниться. Вибір станції не потрібен; просто введіть час.

Для обох типів, якщо вказаний час уже минув, дія планується на наступний день. Якщо на той самий час вже існує таймер (незалежно від типу), додавання нового заблоковано; користувач отримує повідомлення про конфлікт і пропозицію спочатку видалити наявний запис. Таймери, що очікують на виконання, перелічені у вкладці; виберіть один і натисніть кнопку «Видалити вибраний таймер», щоб скасувати його.

**Повторювані таймери:** У розділі **Періодичність** виберіть **Повторювати щотижня** замість одноразового варіанту за замовчуванням, щоб таймер спрацьовував щотижня. Список **Активні дні** дозволяє вибрати дні тижня; якщо жодного дня не позначено, повторюється щодня. Повторюваний таймер спрацьовує за розкладом, доки ви не видалите його зі списку таймерів, що очікують — це не одноразовий запис, який зникає після спрацьовування.

## Подкасти

freeAudio містить повнофункціональний плеєр подкастів. Ви можете підписатися на будь-який RSS- або Atom-канал подкастів, переглядати епізоди, відтворювати їх, завантажувати та продовжувати відтворення з того місця, де ви зупинилися — і все це повністю доступно.

### Перехід на вкладку «Подкасти»

Відкрийте браузер радіостанцій за допомогою комбінації клавіш `Ctrl+Win+R` і перейдіть на вкладку **«Подкасти»** за допомогою `Ctrl+Tab` або `Alt+6`. Вкладка поділена на три основні розділи:

1. **Пошук та додавання** — верхній розділ для пошуку нових подкастів, що містить список попереднього перегляду, який показує епізоди того результату пошуку, який наразі вибрано.
2. **Підписки** — список каналів, на які ви підписані.
3. **Епізоди** — список епізодів для вибраного каналу з елементами керування відтворенням. Список **Закладки** безпосередньо під ним показує закладки вибраного епізоду — див. [Закладки](#закладки).

### Додавання каналу подкасту

Ви можете додати канал подкасту двома способами:

**За URL:**

- У полі **Пошук** вставте повний URL RSS або Atom каналу (наприклад, `https://example.com/feed.xml`).
- Натисніть Enter.
- freeAudio завантажить канал, перевірить його та додасть до ваших підписок. Якщо канал є дійсним, ви почуєте підтвердження з назвою каналу. Якщо перевірка не вдалася, з’явиться повідомлення про помилку з поясненням причини.

**За допомогою пошуку:**

- У полі **Пошук** введіть ключове слово (назву подкасту, тему або ім’я ведучого) та натисніть Enter.
- freeAudio здійснить пошук у каталозі подкастів iTunes і відобразить відповідні подкасти у списку **Результати пошуку**.
- Вибір результату завантажує цей канал у фоновому режимі та показує його епізоди у списку **Епізоди у вибраному результаті** прямо під ним, тож ви можете переглянути, що насправді містить програма, перш ніж вирішити підписатися — див. [Попередній перегляд епізодів перед підпискою](#попередній-перегляд-епізодів-перед-підпискою) нижче.
- Якщо вас влаштовує те, що ви бачите, виберіть результат і натисніть `Enter` або відкрийте його контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) та виберіть **Підписатися**, щоб додати його до своїх підписок. Канал додається негайно і з’являється у вашому списку підписок. Окремої кнопки «Додати вибране з пошуку» немає — клавіша `Enter` або контекстне меню є єдиним способом підписатися на канал із результатів пошуку, що дозволяє зберегти інтерфейс лаконічним та зручним.

> **Порада:** Ви також можете ввести URL каналу безпосередньо в поле пошуку — якщо він виглядає як дійсний URL, додаток спробує додати його як канал без пошуку.

**Контекстне меню для результатів пошуку:** клацніть правою кнопкою миші на результаті пошуку або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з єдиною дією **Підписатися**, що еквівалентно натисканню клавіші `Enter` на результаті.

### Попередній перегляд епізодів перед підпискою

Перш ніж оформити підписку, ви можете прослухати епізоди подкасту безпосередньо з результатів пошуку. Щоразу, коли ви вибираєте подкаст у списку **Результати пошуку**, freeAudio завантажує цей канал і показує його епізоди — назви та дати публікації — у списку **Епізоди у вибраному результаті**, розташованому нижче.

- Виберіть епізод у цьому списку попереднього перегляду та натисніть `Enter`, або відкрийте його контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) і виберіть **«Попередній перегляд»**, щоб розпочати відтворення у звичайному програвачі. Усі звичні елементи керування відтворенням (пауза, гучність, тайм-шифт тощо) працюють так само, як і на будь-якій іншій станції чи в будь-якому іншому епізоді.
- Під час попереднього перегляду епізоду у тому самому контекстному меню замість пункту **Попередній перегляд** з’являється пункт **Зупинити попередній перегляд** — виберіть його або натисніть клавішу `Enter` ще раз на цьому епізоді, щоб зупинити відтворення.
- Попередній перегляд не означає підписку на що-небудь; він призначений виключно для прослуховування перед тим, як ви приймете рішення. Сам список попереднього перегляду є тимчасовим — він замінюється, щойно ви виберете інший результат пошуку, і не зберігається ніде, на відміну від ваших фактичних підписок.

### Керування підписками

Після додавання каналів вони з’являються у списку **Підписки**. У кожному записі вказано назву каналу та кількість доступних епізодів.

- **Виберіть канал**, щоб переглянути його епізоди у списку. У текстовому полі **Деталі каналу** (тільки для перегляду), розташованому під списком підписок, показуються назва каналу, автор, опис, кількість епізодів та URL.
- **Оновити канал** — виберіть його та натисніть кнопку **Оновити канал** (доступно через контекстне меню, див. нижче), щоб завантажити найновіші епізоди. Усі канали також автоматично оновлюються у фоновому режимі під час відкриття вкладки «Подкасти», тому зазвичай ви бачите найновіші епізоди без ручного втручання.
- **Видалити канал** — виберіть його та натисніть клавішу `Delete` або скористайтеся контекстним меню, щоб видалити його зі своїх підписок. Перед видаленням вам буде запропоновано підтвердити дію.

**Контекстне меню для каналів:** клацніть правою кнопкою миші на каналі або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з такими пунктами:

- **Оновити канал** — завантажити нові епізоди зараз.
- **Зберегти аудіопрофіль для цього подкасту** / **Очистити аудіопрофіль** — див. [Аудіопрофіль подкасту](#аудіопрофіль-подкасту).
- **Видалити канал** — видалити підписку.
- **Скопіювати URL каналу** — скопіювати URL каналу в буфер обміну.

### Перегляд та відтворення епізодів

Виберіть канал у списку підписок; його епізоди з’являться у списку **Епізоди** нижче. Для кожного епізоду показується:

- Номер епізоду (1 = найстаріший епізод у каналі, нумерація йде у порядку від найстарішого до найновішого).
- Дата публікації (якщо є).
- Назва.
- Префікс **«Прослухано»**, якщо епізод було повністю відтворено.
- Суфікс тривалості — загальна тривалість (якщо епізод ще не відтворювався) або відтворена/загальна тривалість (якщо епізод відтворювався частково).

**Відтворення:**

- Виберіть епізод і натисніть клавішу `Enter` або `Пробіл`, щоб розпочати його відтворення. Якщо епізод раніше відтворювався частково, відтворення продовжиться з того місця, де ви зупинилися.
- Рядок *не* оновлюється під час відтворення епізоду — це зроблено навмисно, щоб NVDA не повторювала оголошення рядка, поки ви перебуваєте на ньому. Позначка «Прослухано» та тривалість оновлюються одразу, щойно ви призупините епізод або він завершиться, тож інформація на екрані завжди точна саме тоді, коли це важливо; просто під час відтворення вона не оновлюється щосекунди.
- Використовуйте `F3` / `F4` на вкладці «Подкасти», щоб перейти до попереднього / наступного епізоду та негайно його відтворити. Ви також можете використовувати `←` / `→`, коли фокус знаходиться на списку епізодів, або `Ctrl+←` / `Ctrl+→` у будь-якому місці на вкладці «Подкасти» — обидва варіанти працюють однаково.
- Використовуйте `Shift+F3` / `Shift+F4`, щоб переходити між каналами без відтворення епізодів.
- Натисніть клавішу `Пробіл` під час відтворення епізоду, щоб призупинити або відновити відтворення.

**Відновлення відтворення:** freeAudio автоматично зберігає вашу позицію в кожному епізоді подкасту — одразу після паузи або завершення епізоду, а також кожні 15 секунд у фоновому режимі, поки ви продовжуєте слухати, тому збій або неочікуване перезавантаження не призведе до значної втрати перебігу виконання. Якщо ви зупините або призупините відтворення та повернетеся пізніше, епізод відновиться зі збереженої позиції. Якщо ви відтворите епізод до самого кінця (протягом останніх 3 секунд), він позначиться як «Прослухано» і не відновиться — наступного разу він почнеться з початку, а префікс «Прослухано» з’явиться у списку.

**Контекстне меню епізодів:** Клацніть правою кнопкою миші на епізоді або виберіть його та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з такими пунктами:

- **Відтворити епізод** — розпочати відтворення.
- **Завантажити епізод** — завантажити файл епізоду у папку із записами.
- **Зберегти аудіопрофіль для цього подкасту** / **Очистити аудіопрофіль** — ті самі команди, що й у контекстному меню каналу, включені сюди для зручності, щоб вам не доводилося повертатися до списку підписок. Вони все одно зберігають один профіль для всього подкасту, а не окремий для цього епізоду — див. [Аудіопрофіль подкасту](#аудіопрофіль-подкасту).
- **Скопіювати URL епізоду** — скопіювати прямий URL аудіо в буфер обміну.

### Завантаження епізодів

Виберіть епізод і натисніть кнопку **Завантажити епізод** (або скористайтеся контекстним меню). Епізод завантажиться у вашу папку із записами (Початково — `Documents\freeAudio Recordings\`). Назва файлу формується на основі назви епізоду та виявленого розширення файлу (`.mp3`, `.m4a`, `.ogg` тощо). NVDA повідомляє про початок і завершення завантаження. Якщо файл уже існує, ви отримаєте відповідне повідомлення, і завантаження пропуститься.

### Фільтрування епізодів

Над списком епізодів розташоване поле **Фільтр**. Під час введення тексту список епізодів фільтрується в режимі реального часу, щоб показати епізоди, назва яких містить введений текст або номер яких точно збігається з ним — отже, введення `47` переносить вас безпосередньо до епізоду 47, навіть якщо «47» ніде не з’являється в його назві. NVDA оголошує кількість епізодів, що відповідають критеріям, після кожної зміни. Натисніть стрілку `Вниз` поруч із полем фільтра, щоб перемістити фокус безпосередньо до відфільтрованого списку.

### Деталі відтворення подкастів

Епізоди подкастів відтворюються за допомогою **бекенду BASS** (того самого механізму, що використовується для радіопотоків, і єдиного бекенду відтворення, який використовує freeAudio). Оскільки епізоди завантажуються поступово і мають можливість пошуку, під час відтворення подкасту ви можете використовувати комбінації клавіш для перемотування назад/вперед (`Ctrl+Win+J`/`Ctrl+Win+K`), щоб переходити вперед або назад. Позиція зберігається автоматично, тож ви зможете продовжити прослуховування пізніше.

**Багаторівневе перемотування:** На відміну від фіксованого 15-секундного перемотування прямого радіо, пошук у подкасті, аудіокнизі чи треку черги прослуховування масштабується залежно від способу натискання:

- **Утримання клавіші** (автоповтор) крокує назад або вперед на **5 секунд** за повтор — той самий малий крок, який використовує комбінація на файлах.
- **Одне навмисне натискання** — пошук на **12 секунд**.
- **Два натискання** поспіль — пошук на **1 хвилину**.
- **Три або більше натискань** — пошук на **5 хвилин**; подальші натискання в тій самій серії не збільшують крок.

Навмисне натискання утримується на мить, перш ніж фактично виконати пошук, на випадок, якщо надійде ще одне натискання — за одну послідовність натискань виконується лише один пошук, розмір якого відповідає кількості натискань, а не сумі кожного натискання. Після пошуку NVDA оголошує отриману позицію минуло/залишилося в епізоді, а не просто «X секунд вперед/назад».

### Точний пошук (1 секунда)

Для невеликих корекцій, наприклад повторного відтворення слова, яке ви щойно пропустили, freeAudio має окрему пару команд, які завжди переміщують рівно на **1 секунду**, незалежно від способу натискання:

- **`Ctrl+Win+Alt+J`** — 1 секунда назад, з будь-якого місця Windows.
- **`Ctrl+Win+Alt+K`** — 1 секунда вперед, з будь-якого місця Windows.
- **`Alt+←`** / **`Alt+→`** — ті самі дві команди всередині браузера радіостанцій, на будь-якій вкладці.

На епізоді подкасту, частині аудіокниги або треку черги прослуховування вони працюють точно як звичайні команди пошуку, лише з кроком 1 секунда: NVDA оголошує отриману позицію минуло/залишилося, а на аудіокнизі чи папці черги прослуховування межі частини й треку поводяться так, як описано для `Ctrl+Win+J` / `Ctrl+Win+K` (пошук уперед за кінець переходить до наступної частини чи треку; перемотування назад за початок спершу зупиняється на 0:00, і лише друге перемотування назад протягом 10 секунд повертає до попередньої частини чи треку).

На прямій радіостанції вони переміщують на 1 секунду в буфері тайм-шифту. Як і з `Ctrl+Win+J`, буфер має бути увімкнений у налаштуваннях, і перше перемотування назад перемикає з прямого відтворення на відтворення з тайм-шифтом. Перемотування вперед, яке завершується в межах приблизно 2 секунд від краю прямого ефіру, повертається до прямого ефіру й оголошує «Повернення до прямої трансляції».

**Швидкість відтворення:** Ви можете змінювати швидкість відтворення епізодів подкастів, аудіокниг і треків черги прослуховування за допомогою `Ctrl+Win+Shift+K` (швидше) та `Ctrl+Win+Shift+J` (повільніше). Швидкість змінюється кроками по 0,1x у діапазоні від 0,5x до 2,0x зі збереженням висоти тону.

**Транспонування (зміщення висоти тону):** Незалежно від швидкості відтворення ви можете зміщувати висоту тону епізоду подкасту, аудіокниги чи треку черги прослуховування вгору або вниз за допомогою `Shift+Win+K` / `Shift+Win+J` — див. [Транспонування (зміщення висоти тону)](#транспонування-зміщення-висоти-тону).

**Звуковий ефект відновлення:** Щоразу, коли епізод відновлюється зі збереженої позиції, freeAudio ненадовго відтворює тихий звуковий ефект завантаження касети на окремому каналі, поки перемотує до збереженого місця, замість того щоб дозволити аудіо епізоду звучати чутно з 0:00. Це не залежить від налаштування **Перехід між станціями** — це налаштування впливає лише на перемикання між прямими радіостанціями, а не на відновлення подкастів чи аудіокниг.

### Аудіопрофіль подкасту

Клацніть правою кнопкою миші на подкасті у списку підписок або на будь-якому з його епізодів і виберіть **Зберегти аудіопрофіль для цього подкасту**, щоб зберегти поточну гучність, ефекти, підсилення еквалайзера та/або швидкість відтворення як профіль, прив’язаний до цього подкасту. Щоразу, коли відтворюється будь-який епізод цього подкасту, збережені налаштування застосовуються автоматично, замінюючи загальні початкові налаштування. Оскільки команда доступна як у контекстному меню каналу, так і в контекстному меню епізоду, ви можете дістатися до неї, не повертаючись до списку підписок — у будь-якому разі вона завжди зберігає один профіль для всього подкасту, а не окремий для кожного епізоду.

Діалог із 15 варіантами дозволяє вибрати, що саме зберегти:

- **Лише гучність**
- **Лише ефекти**
- **Гучність та ефекти**
- **Гучність та швидкість відтворення**
- **Ефекти та швидкість відтворення**
- **Тільки швидкість відтворення**
- **Гучність, ефекти та швидкість відтворення**
- **Тільки підвищення висоти звуку**
- **Гучність та підвищення висоти звуку**
- **Ефекти та підвищення висоти тону**
- **Швидкість відтворення та підвищення висоти тону**
- **Гучність, ефекти та підвищення висоти звуку**
- **Гучність, швидкість відтворення та підвищення висоти тону**
- **Ефекти, швидкість відтворення та підвищення висоти тону**
- **Гучність, ефекти, швидкість відтворення та підвищення висоти тону**

До профілю записуються лише вибрані частини; усе, що залишилося поза увагою, зберігає те, що вже було збережено для нього. Наприклад, вибір **Тільки швидкість відтворення** для подкасту, який уже має збережений профіль гучності/ефектів, оновлює лише швидкість і залишає решту без змін.

**Очистити аудіопрофіль** видаляє збережений профіль з подкасту з будь-якого контекстного меню. Вона активна лише тоді, коли подкаст наразі має збережений профіль.

### Зберігання даних подкастів

Ваші підписки зберігаються у файлі `freeAudio_podcasts.json` у папці конфігурації користувача NVDA. Позиції епізодів зберігаються окремо у файлі `podcast_positions.json` у тому ж місці. Обидва файли мають формат простого JSON, тому їх можна скопіювати для резервного копіювання або перенести на інший комп’ютер.
## Аудіокниги (GETEM, LibriVox і проект Гутенберг)

freeAudio містить плеєр аудіокниг, який шукає, відтворює та завантажує книги з трьох джерел:

- **[GETEM](https://getem.boun.edu.tr/)** — цифрова бібліотека Центру для людей з порушеннями зору Університету Боазічі. Для трансляції або завантаження аудіо книги потрібне безкоштовне членство (перегляд — ні) — див. [Вхід у систему](#вхід-у-систему) нижче.
- **[LibriVox](https://librivox.org/)** — волонтерський проект аудіокниг у суспільному надбанні. Обліковий запис не потрібен; весь каталог, включно з аудіофайлами, є суспільним надбанням і відкрито доступний.
- **Колекція аудіокниг проекту Гутенберг** — аудіокниги у суспільному надбанні, озвучені людьми та комп’ютерами, розміщені на [archive.org](https://archive.org/). Як і LibriVox, обліковий запис не потрібен.

Результати з усіх трьох джерел з’являються разом у єдиному об’єднаному списку **Результати пошуку** та єдиному об’єднаному списку **Бібліотека** — окремої вкладки чи випадаючого списку для перемикання між ними немає. Джерело кожної книги (GETEM, LibriVox або проект Гутенберг) показується як мітка поруч із назвою та в її деталях, тож ви завжди можете сказати, на що дивитеся. Ви можете шукати, переглядати, додавати, відтворювати та завантажувати книги з будь-якого джерела однаково; відтворювати багаточастинні твори з автоматичним відновленням між частинами; та завантажувати книги для прослуховування офлайн — і все це повністю доступно.

Будь-яке джерело можна вимкнути окремо в меню **NVDA → Параметри → Налаштування → freeAudio** за допомогою списку **Джерела аудіокниг**, якщо ви хочете шукати лише в деяких із них. Усі три увімкнено за замовчуванням.

> **Примітка:** Прослуховування книги GETEM потребує безкоштовного членства GETEM. Перегляд каталогу GETEM не потребує облікового запису, але розпізнавання та відтворення аудіо книги GETEM — потребує — див. [Вхід у систему](#вхід-у-систему) нижче. Книги LibriVox і проекту Гутенберг ніколи не потребують облікового запису.

### Перехід на вкладку «Аудіокниги»

Відкрийте браузер радіостанцій за допомогою `Ctrl+Win+R` і перейдіть на вкладку **Аудіокниги** за допомогою `Ctrl+Tab` або `Alt+7`. Вкладка має три основні області:

1. **Пошук** — текстове поле для пошуку в усіх увімкнених каталогах одночасно, зі списком результатів, що з’являється після запуску пошуку.
2. **Бібліотека** — список книг, доданих з будь-якого джерела, де ви їх відтворюєте, завантажуєте та керуєте ними. Список **Закладки** безпосередньо під ним показує закладки вибраної книги — див. [Закладки](#закладки).
3. **Деталі** — поле лише для читання, що показує джерело, назву, автора, оповідача, видавця, формат, кількість частин, опис і URL каталогу будь-якої вибраної книги, в обох списках.

### Вхід у систему

GETEM вимагає реєстрації для трансляції або завантаження аудіо книги, хоча каталог можна вільно переглядати. Введіть своє ім’я користувача та пароль GETEM один раз у меню **NVDA → Параметри → Налаштування → freeAudio**; вони зберігаються в зашифрованому вигляді на диску (через Windows Data Protection API, прив’язаний до вашого облікового запису Windows) і автоматично використовуються надалі. Якщо ви спробуєте відтворити або завантажити книгу GETEM до введення облікових даних, freeAudio просить спочатку додати їх у Налаштуваннях.

LibriVox і проект Гутенберг не потребують входу взагалі — їхні результати та аудіо можна шукати, переглядати, відтворювати та завантажувати негайно, без облікових даних.

### Пошук аудіокниг

Введіть пошуковий запит у поле пошуку та натисніть `Enter`. freeAudio шукає в увімкнених у Налаштуваннях джерелах і об’єднує результати в один список:

- **GETEM** шукається за назвою, автором, оповідачем, темою та видавцем одночасно, оскільки власна форма пошуку GETEM підтримує лише звуження за всіма ними разом, а не єдиний пошук за будь-яким із них. Показуються лише твори, фактично доступні як аудіо (людське або комп’ютерне озвучення, аудіоопис, радіодрама, розмовні книги DAISY тощо); шрифт Брайля, великий шрифт та інші неаудіоформати фільтруються автоматично.
- **LibriVox** шукається за назвою або автором/читачем у його каталозі суспільного надбання.
- **Проект Гутенберг** шукається за назвою або автором у колекції Open Audiobook Collection на archive.org.

Вставлення URL сторінки каталогу/деталей книги безпосередньо в поле пошуку (сторінка каталогу GETEM або сторінка «details» на archive.org для LibriVox чи проекту Гутенберг) безпосередньо розпізнає цю книгу замість виконання пошуку за ключовим словом.

NVDA оголошує, скільки аудіокниг знайдено всього. Вибір результату показує його деталі — автора, оповідача, видавця, формат і кількість частин — у полі деталей нижче.

**Попередній перегляд:** Виберіть результат і натисніть `Пробіл` або відкрийте його контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) і виберіть **Попередній перегляд**, щоб почати відтворення з першої частини без додавання до бібліотеки. Під час попереднього перегляду книги в тому самому контекстному меню замість нього з’являється **Зупинити попередній перегляд** — виберіть його або натисніть `Пробіл` знову, щоб зупинити. Попередній перегляд книги не зберігає позицію прослуховування, оскільки вона відстежується лише для книг, уже доданих до бібліотеки.

**Додавання до бібліотеки:** Виберіть результат і натисніть `Enter` або скористайтеся його контекстним меню та виберіть **Додати до бібліотеки**, щоб додати його. freeAudio повідомляє, якщо книга вже там.

### Ваша бібліотека

Додані книги з’являються у списку **Бібліотека**, показуючи назву, автора та формат. Вибір однієї показує її деталі нижче.

- Натисніть `Enter` або `Пробіл`, щоб відтворити вибрану книгу. Якщо нічого не завантажено, `Пробіл` запускає її; якщо щось уже відтворюється, `Пробіл` призупиняє його, як і в решті плеєра.
- Використовуйте `F3` / `F4` на вкладці «Аудіокниги» для переходу до попередньої / наступної **книги** у вашій бібліотеці та запуску відтворення. `Ctrl+←` / `Ctrl+→` роблять те саме, коли фокус на списку бібліотеки.
- Використовуйте `Shift+F3` / `Shift+F4` для переходу між **частинами** поточної книги натомість — це зворотне до вкладки «Подкасти», де F3/F4 переходять між епізодами, а Shift+F3/F4 — між каналами. Це тому, що книга є одним записом бібліотеки, навіть якщо має кілька частин, тож дрібніша навігація «частинами» тут розміщена на клавішах із Shift.
- Із закритим браузером радіостанцій `Ctrl+Win+F3` / `Ctrl+Win+F4` (попередня / наступна книга) і `Ctrl+Win+Shift+F3` / `Ctrl+Win+Shift+F4` (попередня / наступна частина) роблять те саме — див. [Перемикання елементів при закритому браузері радіостанцій](#перемикання-елементів-при-закритому-браузері-радіостанцій).

**Контекстне меню бібліотеки:** клацніть правою кнопкою миші на книзі або виберіть її та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити меню з такими пунктами:

- **Відтворити медіа** — почати відтворення, те саме, що й `Enter`.
- **Завантажити книгу** — завантажити кожну частину книги; див. [Завантаження аудіокниг](#завантаження-аудіокниг) нижче.
- **Скопіювати URL** — скопіювати URL сторінки каталогу книги в буфер обміну (сторінка каталогу GETEM для книги GETEM або сторінка деталей archive.org для книги LibriVox чи проекту Гутенберг).
- **Зберегти аудіопрофіль для цієї книги** / **Очистити аудіопрофіль** — див. [Аудіопрофіль аудіокниги](#аудіопрофіль-аудіокниги) нижче.
- **Видалити з бібліотеки** — видалити книгу з вашої бібліотеки.

Ви також можете позначити кілька книг одразу та видалити їх разом — див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів) у розділі «Улюблене».

### Відтворення та відновлення

Багаточастинний твір вважається одним елементом у плеєрі, а не рядком для кожної частини — так само, як епізод подкасту є одним елементом незалежно від способу доставки. freeAudio запам’ятовує, яку частину ви слухали останньою, і автоматично відновлює її наступного разу, коли ви відтворюєте цю книгу, навіть після перезапуску NVDA.

Коли одна частина завершується, freeAudio автоматично запускає наступну частину тієї самої книги — вам не потрібно вибирати її вручну. Це відбувається навіть тоді, коли вікно браузера радіостанцій закрите; частина «зараз відтворюється», показана у списку бібліотеки, автоматично синхронізується наступного разу, коли вікно відкривається.

Відтворення транслюється через невеликий локальний ретранслятор, а не завантажує всю частину спочатку, тож прослуховування починається, щойно надходять перші байти — та сама поведінка негайного запуску, що й у подкастів. Усі звичні елементи керування плеєра (пауза, гучність, тайм-шифт, швидкість відтворення, транспонування, пристрій виводу тощо) працюють на аудіокнизі так само, як і на станції чи епізоді подкасту.

Як і подкасти, відновлення книги зі збереженої позиції відтворює короткий звуковий ефект завантаження касети, поки freeAudio перемотує до збереженого місця — див. примітку **Звуковий ефект відновлення** в [Деталі відтворення подкастів](#деталі-відтворення-подкастів).

### Аудіопрофіль аудіокниги

Клацніть правою кнопкою миші на книзі в бібліотеці та виберіть **Зберегти аудіопрофіль для цієї книги**, щоб зберегти поточну гучність, ефекти, підсилення еквалайзера та/або швидкість відтворення як профіль, прив’язаний до книги. Щоразу, коли книга (або будь-яка з її частин) відтворюється, збережені налаштування застосовуються автоматично, замінюючи загальні початкові налаштування. Це працює точно так само, як [Аудіопрофіль подкасту](#аудіопрофіль-подкасту) вище, включно з тим самим набором варіантів збереження (гучність, ефекти та/або швидкість відтворення в будь-якій комбінації) і тією самою поведінкою часткового оновлення.

**Очистити аудіопрофіль** видаляє збережений профіль з книги; вона активна лише тоді, коли книга наразі має збережений профіль.

### Завантаження аудіокниг

Виберіть книгу в бібліотеці та виберіть **Завантажити книгу** в контекстному меню, щоб зберегти кожну частину в окрему папку (названу за книгою) у папці записів (`Documents\freeAudio Recordings\` за замовчуванням). Файли нумеруються, щоб частини завжди сортувалися у порядку прослуховування, незалежно від того, як їх називає сам GETEM. NVDA оголошує, скільки частин збережено після завершення завантаження; якщо якась частина не вдається, остання помилка повідомляється разом із кількістю.

### Прямі комбінації клавіш для аудіокниг

Кожна книга у вашій бібліотеці аудіокниг — чи то з GETEM, LibriVox або проекту Гутенберг — реєструється як окремий скрипт у діалозі «Жести вводу» NVDA, у категорії **Аудіокниги freeAudio**, точно як [Прямі комбінації клавіш для улюблених станцій](#прямі-комбінації-клавіш-для-улюблених-станцій) та [Прямі комбінації клавіш для записів черги прослуховування](#прямі-комбінації-клавіш-для-записів-черги-прослуховування). Ви можете призначити будь-яку комбінацію клавіш для будь-якої книги та натискати її з будь-якого місця — не потрібно спочатку відкривати вікно браузера. За замовчуванням комбінації не призначено.

Щоб призначити комбінацію клавіш:

1. Відкрийте меню NVDA → Параметри → Жести вводу.
2. Розгорніть категорію **Аудіокниги freeAudio**.
3. Знайдіть книгу за назвою (кожен запис називається «*назва* комбінація клавіш для відтворення»), виберіть її та натисніть **Додати**.
4. Натисніть потрібну комбінацію клавіш і підтвердіть вибір.

Комбінація клавіш негайно запускає книгу, відновлюючи з частини, яку ви слухали останньою; позиція всередині цієї частини відновлюється так само, як і під час відтворення книги зі списку бібліотеки. Якщо список частин книги ще не отримано, NVDA каже «Завантаження *назва*», і відтворення починається, щойно все готово (книзі GETEM потрібен ваш збережений вхід — див. [Вхід у систему](#вхід-у-систему)). Коли частина завершується, наступна запускається автоматично, з відкритим або закритим браузером радіостанцій.

Коли ви додаєте книгу до бібліотеки або видаляєте її, категорія **Аудіокниги freeAudio** оновлюється одразу — діалог «Жести вводу» не потрібно відкривати знову, щоб побачити зміну. Якщо книгу видалено, її запис зникає, а будь-яка призначена їй комбінація клавіш автоматично скасовується NVDA; якщо застаріла комбінація все ж спрацює, NVDA повідомить, що аудіокниги більше немає в бібліотеці.

### Зберігання даних аудіокниг

Кожне джерело веде власний файл бібліотеки, навіть якщо вони відображаються об’єднано на вкладці «Аудіокниги». Ваша бібліотека GETEM (додані книги та прогрес прослуховування) зберігається у файлі `freeAudio_getem_library.json`, бібліотека LibriVox — окремо у `freeAudio_librivox_library.json`, бібліотека проекту Гутенберг — окремо у `freeAudio_gutenberg_library.json` — усі три в папці конфігурації користувача NVDA. Ваші зашифровані облікові дані GETEM зберігаються окремо у `freeAudio_getem_credentials.bin` у тому ж місці й можуть бути розшифровані лише тим самим обліковим записом Windows, що їх зберіг. LibriVox і проект Гутенберг не мають файлу облікових даних, оскільки жоден не потребує облікового запису.

## Локальна черга прослуховування

Вкладка **Черга прослуховування** freeAudio дає два способи відтворення аудіофайлів, які вже є на вашому комп’ютері: пошук на кожному підключеному диску за назвою файлу або створення постійної особистої бібліотеки файлів і папок. Усе, що ви відтворюєте звідси, отримує ту саму обробку, що й подкаст чи аудіокнига — автоматичне відновлення, багаторівневе перемотування назад/вперед, швидкість відтворення, транспонування та аудіопрофілі для кожного елемента працюють точно так само.

### Перехід на вкладку «Черга прослуховування»

Відкрийте браузер радіостанцій за допомогою `Ctrl+Win+R` і перейдіть на вкладку **Черга прослуховування** за допомогою `Ctrl+Tab` або `Alt+8`, або відкрийте її безпосередньо глобальною комбінацією `Ctrl+Win+U`. Вкладка має три основні області:

1. **Пошук на пристроях** — текстове поле, що шукає на кожному локально підключеному готовому диску аудіофайли, назва яких містить введений текст. Натисніть `Enter`, щоб почати пошук.
2. **Результати пошуку** — список, що з’являється після запуску пошуку й показує відповідні файли. Прихований доти, тож вкладка залишається охайною, коли шукати нічого.
3. **Черга прослуховування та Треки** — постійний список доданих елементів, за яким іде список треків у вибраному елементі (для файлу — просто цей один файл; для папки — кожен аудіофайл усередині неї). Список **Закладки** йде за списком треків і показує закладки вибраного треку — див. [Закладки](#закладки).

Кнопки **Додати файл…**, **Додати папку…**, **Видалити**, **Експорт черги прослуховування…** та **Імпорт черги прослуховування…** розташовані внизу вкладки.

### Пошук файлів на пристроях

Введіть будь-яку частину назви файлу в поле **Пошук на пристроях** та натисніть `Enter`. freeAudio переглядає кожен локально підключений диск — жорсткі диски, USB-накопичувачі та карти пам’яті — шукаючи аудіофайли (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.m4b`, `.aac`, `.wma`, `.opus` та кілька інших), назва яких містить текст пошуку. Пошук виконується у фоні, тож NVDA залишається чутливою. Мережеві диски за замовчуванням пропускаються, оскільки пошук у мережевому ресурсі може перетворити односекундний пошук на той, що триває хвилинами, або зависнути, якщо ресурс недоступний. Щоб їх включити, увімкніть **Включити мережеві диски під час пошуку в черзі прослуховування** у налаштуваннях.

- **Пробіл** на результаті пошуку відтворює його попередній перегляд — запускає відтворення через звичайний плеєр. Натисніть **Пробіл** ще раз на тому самому файлі, щоб зупинити попередній перегляд.
- **Enter** на результаті пошуку додає його до черги прослуховування.
- Контекстне меню (клавіша «Контекстне меню» / `Shift+F10`, або клацніть правою кнопкою миші) пропонує ті самі дві дії: **Попередній перегляд** / **Зупинити попередній перегляд** та **Додати до черги прослуховування**.
- Початок нового пошуку скасовує будь-який пошук, що ще виконується, тож повільний пошук на великому диску ніколи не затримує новий.

### Створення черги прослуховування

Список черги прослуховування — це ваша постійна особиста бібліотека. Можна додати два види елементів:

- **Додати файл…** — відкриває вибір файлів, що дозволяє додати один або кілька окремих аудіофайлів. Усі вибрані файли додаються одразу.
- **Додати папку…** — відкриває вибір папок, що дозволяє вибрати кілька папок одразу. Кожен аудіофайл у кожній вибраній папці, включно з підпапками, вважається одним із **треків** цієї папки. Кожна папка додається як окремий елемент у списку черги прослуховування; файли в ній перелічуються у списку треків, коли папку вибрано. NVDA оголошує, скільки папок додано, коли вибір закривається.
- **Видалити** — видаляє поточний вибраний елемент зі списку черги прослуховування. Видалення папки не видаляє жодних файлів з диска чи пристрою; вона просто забуває папку. Ви також можете позначити кілька елементів одразу та видалити їх разом — див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів) у розділі «Улюблене».

Список черги прослуховування зберігається автоматично, тож переживає перезапуски NVDA. Вміст папок сканується на вимогу та кешується, тож додавання папки миттєве навіть для дуже великих колекцій — повне сканування відбувається першого разу, коли ви вибираєте цю папку. Якщо ви додаєте файли до папки поза freeAudio, скористайтеся пунктом **Пересканувати папку** в контекстному меню папки, щоб їх підхопити.

### Додавання елементів із Провідника Windows

Ще дві команди, доступні лише коли файл або папка у фокусі у списку файлів Провідника Windows (список «Подробиці/Значки» — не адресний рядок, не дерево папок, не стрічка, не поле пошуку), дозволяють повністю оминути діалоги «Додати файл…»/«Додати папку…» вище:

- **Відтворити файл, на якому стоїть фокус, за допомогою freeAudio** — відтворює виділений аудіофайл безпосередньо, без потреби, щоб він уже був у списку черги прослуховування. Працює лише з файлами; використання на папці просить додати папку до черги прослуховування натомість.
- **Додати елемент, на якому стоїть фокус, до черги прослуховування freeAudio** — додає виділений файл або папку до списку черги прослуховування, точно як якби ви скористалися **Додати файл…** або **Додати папку…** вище.

Жодна команда не має комбінації клавіш за замовчуванням. Призначте її в меню NVDA → Параметри → Жести вводу → freeAudio **перебуваючи у вікні Провідника файлів**.

### Відтворення з черги прослуховування

- **Enter** на елементі черги прослуховування відтворює його безпосередньо: для файлу — сам файл; для папки — папку по порядку, починаючи з треку, виділеного у списку треків, або, якщо жодного не виділено, з місця, де папку було зупинено востаннє (перший трек, якщо вона ніколи не відтворювалася). Коли трек завершується, наступний трек у папці запускається автоматично.
- **Пробіл** на елементі черги прослуховування призупиняє відтворення, якщо щось відтворюється; інакше відтворює елемент у фокусі.
- **Enter** або **Пробіл** у списку треків відтворює трек у фокусі. **Пробіл** спершу призупиняє, якщо щось уже відтворюється. Трек, запущений у такий спосіб, відтворюється самостійно й не переходить до наступного треку після завершення; використовуйте `F3` / `F4` або відтворіть сам елемент папки для безперервного відтворення.
- **F3 / F4** на вкладці «Черга прослуховування» переходять між треками в поточному вибраному елементі та відтворюють негайно. У папці трек відтворюється як частина папки, тож наступні треки запускаються автоматично після його завершення.
- **Shift+F3 / Shift+F4** переходять між елементами у списку черги прослуховування (файли та папки), повторюючи те, як ці клавіші переходять між каналами на вкладці «Подкасти».
- **Ctrl+← / Ctrl+→** у списку елементів або треків роблять те саме, що F3/F4 у списку треків — попередній / наступний трек, з автоматичним продовженням у папці.
- Із закритим браузером радіостанцій `Ctrl+Win+F3` / `Ctrl+Win+F4` (попередній / наступний трек) і `Ctrl+Win+Shift+F3` / `Ctrl+Win+Shift+F4` (попередній / наступний запис) роблять те саме — див. [Перемикання елементів при закритому браузері радіостанцій](#перемикання-елементів-при-закритому-браузері-радіостанцій).

### Деталі відтворення черги прослуховування

Кожен трек, відтворений із черги прослуховування, отримує повну обробку локальних медіа:

- **Відновлення:** freeAudio запам’ятовує вашу позицію в кожному треку, зберігає її під час паузи та періодично під час відтворення, і відновлює з цієї точки, коли ви відтворюєте його знову — навіть після перезапуску NVDA.
- **Автоматичний наступний трек:** коли трек, відтворений як частина папки, завершується, наступний трек у цій папці запускається сам, незалежно від того, відкритий браузер радіостанцій чи ні, і продовжує це робити після пропуску треків за допомогою `F3` / `F4` або `Ctrl+Win+F3` / `Ctrl+Win+F4`. Коли останній трек завершився, збережена позиція папки очищається, тож наступного разу вона починається з першого треку. Натискання «наступний» на останньому треку вручну не очищає її.
- **Багаторівневе перемотування:** `Ctrl+Win+J` / `Ctrl+Win+K` виконують пошук у треку з тим самим масштабуванням утримання/натискання, що й подкасти та аудіокниги — утримання = 5 секунд за повтор, одне натискання = 12 секунд, два натискання = 1 хвилина, три або більше = 5 хвилин. `Ctrl+Win+Alt+J` / `Ctrl+Win+Alt+K` виконують пошук рівно на 1 секунду — див. [Точний пошук (1 секунда)](#точний-пошук-1-секунда).
- **Швидкість відтворення:** `Ctrl+Win+Shift+J` / `Ctrl+Win+Shift+K` регулюють швидкість кроками по 0,1x від 0,5x до 2,0x зі збереженням висоти тону.
- **Транспонування:** `Shift+Win+J` / `Shift+Win+K` зміщують висоту тону без зміни швидкості — див. [Транспонування (зміщення висоти тону)](#транспонування-зміщення-висоти-тону).


> **Примітка:** Буфер тайм-шифту (що використовується для перемотування прямого радіо) навмисно **не** запускається для треків черги прослуховування — вони вже локальні файли з можливістю пошуку, тож фонове захоплення не має сенсу й лише споживало б дисковий простір. Перемотування назад і вперед усе одно працює, оскільки воно діє безпосередньо на файл, що відтворюється.

### Перейменування записів черги прослуховування

Виберіть **Перейменувати…** у контекстному меню запису черги прослуховування (клавіша «Контекстне меню» / `Shift+F10`), щоб дати йому власну відображувану назву. Власна назва замінює назву файлу чи папки у списку черги прослуховування й записується в рядок `#EXTINF`, коли запис експортується в M3U (див. [Експорт та імпорт бібліотеки черги прослуховування](#експорт-та-імпорт-бібліотеки-черги-прослуховування) нижче). Залиште поле порожнім, щоб очистити власну назву та повернутися до оригінальної назви файлу чи папки.

### Організація черги прослуховування в групи

Записи черги прослуховування можуть належати до групи, що показується як суфікс «— Група» після назви запису у списку, точно як [Організація улюблених у групи](#організація-улюблених-у-групи):

- Позначте один або кілька записів знаком `.` (див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів) вище), потім виберіть **Призначити групі…** у контекстному меню та введіть назву групи. Залиште поле порожнім, щоб вилучити позначені записи з їхньої групи. Якщо нічого не позначено, команда застосовується до поточного вибраного запису.
- Поле фільтра над списком черги прослуховування також збігається з назвами груп, так само як і для улюблених.

### Зміна порядку в черзі прослуховування

Виберіть елемент і натисніть `кома`, щоб увійти в режим переміщення — пролунає сигнал. Перейдіть до потрібної позиції за допомогою клавіш зі стрілками, а потім знову натисніть `кома`. Елемент буде розміщено у вибраній позиції, а нове розташування одразу збережеться. Повторне натискання `кома` у цій же позиції скасує переміщення.

### Експорт та імпорт бібліотеки черги прослуховування

Вкладка «Черга прослуховування» містить дві кнопки для резервного копіювання та відновлення бібліотеки, внизу вкладки:

**Експорт черги прослуховування…** — зберігає весь список черги прослуховування у файл. У діалозі збереження можна вибрати один із двох форматів:

- **JSON** (`.json`) — повна резервна копія, що зберігає шлях кожного запису, власну назву, групу та збережений аудіопрофіль. Рекомендується для подальшого відновлення бібліотеки або її перенесення на інший комп’ютер.
- **Плейлист M3U** (`.m3u`) — легший формат, сумісний із більшістю медіаплеєрів, що перелічує шлях кожного запису з його власною назвою (якщо є) у попередньому рядку `#EXTINF`. Групи та аудіопрофілі не включаються до M3U, тож відновлення з M3U втрачає цю деталь.

**Імпорт черги прослуховування…** — завантажує записи з раніше експортованого файлу JSON або M3U. Після вибору файлу пропонується вибрати спосіб додавання записів:

- **Так (Об’єднати)** — додає імпортовані записи до наявної бібліотеки, не видаляючи поточні записи. Записи, шлях яких збігається з тим, що вже є у вашій бібліотеці, не додаються повторно.
- **Ні (Замінити)** — повністю очищає поточний список черги прослуховування й замінює його вмістом імпортованого файлу.
- **Скасувати** — повертається до браузера без внесення жодних змін.

### Прямі комбінації клавіш для записів черги прослуховування

Кожен запис у вашому списку черги прослуховування реєструється як окремий скрипт у діалозі «Жести вводу» NVDA, у категорії **Черга прослуховування freeAudio**, точно як [Прямі комбінації клавіш для улюблених станцій](#прямі-комбінації-клавіш-для-улюблених-станцій). Ви можете призначити будь-яку комбінацію клавіш для будь-якого запису та натискати її з будь-якого місця — не потрібно спочатку відкривати вікно браузера.

Щоб призначити комбінацію клавіш:

1. Відкрийте меню NVDA → Параметри → Жести вводу.
2. Розгорніть категорію **Черга прослуховування freeAudio**.
3. Знайдіть запис за назвою, виберіть його та натисніть **Додати**.
4. Натисніть потрібну комбінацію клавіш і підтвердіть вибір.

Комбінація клавіш негайно відтворює запис — для файлу — сам файл; для папки — трек, на якому папку було зупинено востаннє (її перший трек, якщо вона ніколи не відтворювалася), після чого наступні треки відтворюються автоматично, навіть із закритим браузером радіостанцій. Якщо запис пізніше видалено з черги прослуховування, його запис зникає з категорії, а будь-яка призначена йому комбінація клавіш автоматично скасовується NVDA. Коли додається новий запис, він одразу з’являється в категорії — діалог «Жести вводу» не потрібно відкривати знову.

## Закладки

Закладки дозволяють позначити місце в **частині аудіокниги**, **епізоді подкасту** або **треку черги прослуховування** й повернутися до нього пізніше. Вони недоступні для прямих радіостанцій, які не мають фіксованих позицій для повернення.

### Додавання закладки

- Натисніть **`Ctrl+Win+F12`** з будь-якого місця Windows або **`F12`**, коли браузер радіостанцій активний, щоб додати закладку в поточній позиції відтворення.
- NVDA оголошує назву закладки та позицію, наприклад «Закладку додано: Закладка 2, 12:30».
- Якщо нічого не відтворюється або відтворюється пряма радіостанція, freeAudio повідомляє про це, і закладка не додається.

Назва закладки за замовчуванням — її **порядковий номер** серед закладок елемента, від найранішої: «Закладка 1», «Закладка 2» тощо. Оскільки номер відповідає позиції, додавання ранішої закладки перенумеровує пізніші, що мають назву за замовчуванням. Перейменовані закладки зберігають власну назву.

### Список закладок

Кожна з вкладок «Подкасти», «Аудіокниги» та «Черга прослуховування» має список **Закладки** поруч з елементом, до якого він належить:

- **Подкасти** — безпосередньо під списком епізодів, показує закладки вибраного епізоду.
- **Аудіокниги** — безпосередньо під списком бібліотеки, показує закладки кожної частини вибраної книги. Якщо книга має кілька частин, кожен рядок починається з назви частини.
- **Черга прослуховування** — безпосередньо під списком треків, показує закладки вибраного треку.

Кожен рядок показує назву закладки та позицію. Мітка **[текст]** або **[голосова нотатка]** додається, коли закладка має текстову або голосову нотатку, а **(позначено)** — коли ви позначили її знаком `.`. Список слідує за виділенням над ним і також оновлюється, коли ви додаєте закладку за допомогою `Ctrl+Win+F12` із відкритим вікном.

Поки список закладок у фокусі, клавіші відтворення вкладки над ним також працюють там: `←` / `→` — пошук, `Shift+←` / `Shift+→` — транспонування, `Page Up` / `Page Down` — зміна швидкості відтворення, `Ctrl+←` / `Ctrl+→` — перехід до попереднього або наступного епізоду, книги чи треку, а `Alt+←` / `Alt+→` — пошук на 1 секунду.

| Клавіша | Дія |
|---|---|
| `.` | Позначає або знімає позначку з закладки у фокусі. Див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів). |
| `Enter` | Відтворює з закладки у фокусі. |
| `Пробіл` | Призупиняє, якщо щось відтворюється; інакше відтворює з закладки у фокусі. |
| `Delete` | Видаляє всі позначені закладки або закладку у фокусі, якщо нічого не позначено. Спочатку з’являється діалог підтвердження. |
| Клавіша «Контекстне меню» / `Shift+F10` | Відкриває контекстне меню закладки. |

### Контекстне меню закладки

- **Відтворити із закладки** — якщо елемент уже завантажено, відтворення переходить до закладки; інакше елемент починає відтворюватися з цієї позиції.
- **Перейменувати…** — дає закладці власну назву. Залиште поле порожнім, щоб повернутися до назви за замовчуванням.
- **Видалити вибране** — видаляє позначені закладки або закладку у фокусі, якщо нічого не позначено.
- **Додати або змінити текст…** — відкриває багаторядкове поле для текстової нотатки. Залиште порожнім, щоб видалити текст.
- **Додати голосову нотатку…** — відкриває діалог, що починає запис із мікрофона за замовчуванням одразу після появи. Натисніть **Зупинити та зберегти**, щоб прикріпити запис до закладки, або **Скасувати**, щоб відхилити його. Додавання нової голосової нотатки замінює попередню.
- **Очистити нотатки** — видаляє і текстову, і голосову нотатку закладки у фокусі. Активна лише тоді, коли закладка має нотатку.
- **Повторювати між позначеними закладками** — див. нижче. Активна, коли позначено принаймні дві закладки.
- **Зупинити повтор** — вимикає режим повтору. Активна, поки повтор активний.

### Що відбувається, коли відтворення досягає закладки

Під час звичайного відтворення, коли позиція досягає закладки, freeAudio відтворює **два короткі сигнали**. Якщо закладка не має нотатки, відтворення просто продовжується.

Якщо закладка має текстову та/або голосову нотатку, відтворення **призупиняється**, текст зачитується поточним синтезатором NVDA, відтворюється голосова нотатка, після чого відтворення **продовжується з місця, де воно зупинилося**. Якщо ви зупините відтворення або запустите щось інше під час відтворення нотатки, відтворення не відновиться.

Закладки виявляються під час звичайного відтворення. Перемотування або стрибок повз закладку не запускає її.

### Повтор ділянки між закладками

Позначте дві або більше закладок **одного елемента** знаком `.`, потім виберіть **Повторювати між позначеними закладками**. Відтворення переходить до найранішої позначеної закладки та циклічно повторює ділянку між найранішою та найпізнішою позначеними закладками, а NVDA оголошує обидві позиції. Це корисно для повторення важкого для сприйняття уривка, фрази для вивчення мови або музичного фрагмента, який ви відпрацьовуєте. Виберіть **Зупинити повтор**, щоб повернутися до звичайного відтворення. Повтор не зберігається між сеансами, і якщо починає відтворюватися інший елемент, діапазон повтору ігнорується й відкидається приблизно через 20 секунд.

### Зберігання даних закладок

Закладки зберігаються у файлі `freeAudio_bookmarks.json` у папці конфігурації користувача NVDA, а голосові нотатки — як файли `.wav` у папці `freeAudio_bookmark_audio` поруч із ним. Обидва можна скопіювати для резервного копіювання або перенести на інший комп’ютер. Видалення закладки також видаляє її файл голосової нотатки. Усі закладки та голосові нотатки можна видалити одразу за допомогою пункту **Закладки** у діалозі очищення — див. [Очищення: скидання налаштувань і видалення збережених даних](#очищення-скидання-налаштувань-і-видалення-збережених-даних).

Кожна закладка належить ключу відновлення самого елемента — URL епізоду, стабільному URL каталогу частини аудіокниги або шляху файлу треку черги прослуховування. Файл черги прослуховування, переміщений або перейменований поза freeAudio, тому вважається іншим елементом і не показує свої старі закладки.

## Транспонування (зміщення висоти тону)

Транспонування зміщує **висоту тону** відтворюваного вгору або вниз без зміни **швидкості** — протилежність «ефекту бурундука», який ви отримали б, просто прискоривши трек. Це корисно для підлаштування під природний діапазон конкретного оповідача, транспонування музики в зручнішу тональність або просто налаштування запису, щоб він звучав комфортніше для вашого слуху.

Транспонування доступне для **подкастів**, **аудіокниг** і **треків черги прослуховування** — тих самих «локальних, з можливістю пошуку, з підтримкою темпу» медіа, до яких уже застосовуються комбінації швидкості відтворення. Воно недоступне для прямих радіостанцій, які не мають фіксованої висоти тону для зміщення.

- **`Shift+Win+K`** — підвищує висоту тону на один крок.
- **`Shift+Win+J`** — знижує висоту тону на один крок.

Кожен крок — **одна восьма цілого тону**, тобто **0,25 півтону** (цілий тон — 2 півтони, отже 8 кроків — цілий тон, 48 кроків — октава). Діапазон — **від −12,00 до +12,00 півтонів**, тобто одна повна октава вгору або вниз. NVDA оголошує нове значення після кожного кроку, наприклад «**+1,25 півтонів**»; повернення до 0,0 оголошує «**Нормальна висота тону**».

Транспонування запам’ятовується між треками так само, як швидкість відтворення: встановлення його один раз під час відтворення треку означає, що наступний трек із підтримкою темпу, який ви відтворите, почнеться з тим самим зміщенням, якщо тільки власний збережений аудіопрофіль цього треку його не перевизначить. Відтворення треку без збереженого значення транспонування скидає зміщення до 0,0 (Нормальна висота тону), так само як те саме правило вже застосовується до швидкості.

## Улюблені треки

Коли увімкнено функцію **«Зберегти вподобані пісні у текстовий файл»**, інформація про треки, скопійована до буфера обміну потрійним натисканням клавіш `Ctrl+Win+I`, також додається по рядках до файлу `Documents\freeAudio Recordings\likedSongs.txt`.

На станціях, що транслюють метадані ICY, назва треку та виконавець зберігаються безпосередньо. На станціях без метаданих ICY результат розпізнавання Shazam зберігається у тому самому файлі — обидва джерела використовують один і той самий список. Файл створюється автоматично, якщо його ще немає; кожен запис додається в кінець файлу, а попередні записи ніколи не видаляються.

## Вкладка «Улюблені треки»

Вкладка **«Улюблені треки»** у браузері радіостанцій відображає всі треки, збережені у файлі `likedSongs.txt`. Список автоматично оновлюється з цього файлу щоразу, коли відкривається ця вкладка. Клацніть правою кнопкою миші на пісні або виберіть її та натисніть клавішу «Контекстне меню» / `Shift+F10`, щоб відкрити контекстне меню з тими самими діями, що описані нижче.

Поле **«Фільтр»** над списком дозволяє звужувати перелік показуваних треків у режимі реального часу. Введіть будь-яку частину назви треку або імені виконавця, і список миттєво оновлюватиметься з кожним натисканням клавіші. NVDA оголошує кількість відповідних результатів після кожної зміни. Натисніть стрілку `Вниз` біля поля фільтра, щоб перемістити фокус безпосередньо у список.

Вибір треку зі списку дає змогу виконати такі дії:

- **Відтворити у Spotify:** Намагається безпосередньо відкрити настільну програму Spotify. Якщо програма не встановлена, використовується веб-сайт Spotify, і автоматично починається відтворення першого результату.
- **Відтворити на YouTube (`Alt+O`):** шукає вибраний трек на YouTube та відкриває результати у початковому браузері.
- **Показати текст треку:** завантажує та показує текст вибраного треку. Тексти треків отримуються з [lrclib.net](https://lrclib.net) (безкоштовно, обліковий запис не потрібен). Під час пошуку, що виконується у фоновому режимі, озвучується коротке повідомлення «Завантаження тексту…». Якщо текст пісні знайдено, він відкривається у діалозі, доступному лише для читання, де ви можете прочитати його за допомогою NVDA та скопіювати до буфера обміну. Якщо текст пісні не знайдено, NVDA повідомляє про це. Під час завантаження кнопка тимчасово вимкнена, щоб запобігти повторним запитам.
- **Видалити (`Alt+M`):** Видаляє вибраний трек із файлу `likedSongs.txt` та оновлює список. Клавіша `Delete` також активує цю кнопку, коли фокус знаходиться на списку. Ви також можете позначити кілька пісень одразу та видалити їх разом — див. [Позначення та видалення кількох елементів](#позначення-та-видалення-кількох-елементів).
- **Оновити (`Alt+E`):** Перезавантажує список із файлу.

Кнопки «Spotify», «YouTube», «Показати текст треку» та «Видалити» активні лише тоді, коли у списку вибрано реальний трек.

### Сервіс текстів треків

freeAudio використовує [lrclib.net](https://lrclib.net) для отримання текстів треків — це безкоштовна відкрита база даних, яка не вимагає API-ключа чи облікового запису. Процес пошуку аналізує рядок назви треку, збережений у файлі `likedSongs.txt`, і послідовно застосовує все більш вільні запити, доки не буде знайдено текст треку:

1. Точний збіг за повним ім’ям виконавця та очищеною назвою (перед пошуком видаляються зайві суфікси, такі як «Remastered», «Live», або позначення року).
2. Точний збіг за повним ім’ям виконавця та оригінальною назвою (якщо під час очищення вона змінилася).
3. Точний пошук за першим ім’ям виконавця та очищеною назвою (для рядків із кількома виконавцями, таких як «Виконавець А & Виконавець Б»).
4. Неточний пошук за першим ім’ям виконавця та очищеною назвою.
5. Неточний пошук за необробленим рядком назви треку як крайній захід.

Якщо доступні звичайні тексти треків, вони показуються без змін. Якщо доступні лише синхронізовані за часом тексти у форматі LRC, часові мітки видаляються, а звичайний текст показується. Інструментальні треки позначаються як «не знайдено».

### Очищення: скидання налаштувань і видалення збережених даних

Кнопка **Очищення: скинути налаштування та видалити збережені дані...** внизу сторінки налаштувань freeAudio відкриває діалог **Скидання налаштувань / видалення збережених даних**. Він перелічує у вигляді прапорців те, що freeAudio зберігає в папці конфігурації NVDA. **За замовчуванням нічого не позначено.** Кожен пункт показує, скільки місця він займає, або «нічого не збережено»:

- **Налаштування** — скидаються до значень за замовчуванням. Папка записів і параметр **Зберегти вподобані треки у текстовий файл** зберігаються.
- **Улюблені станції**
- **Кеш списку станцій** — завантажується знову за потреби.
- **Підписка на подкасти**
- **Бібліотеки аудіокниг** — GETEM, LibriVox і проект Гутенберг.
- **Збережені дані входу GETEM** — збережене ім’я користувача та пароль.
- **Список черги прослуховування** — ваші музичні файли не видаляються.
- **Збережені позиції відновлення** — подкасти, аудіокниги та папки черги прослуховування.
- **Закладки** — кожна закладка, включно з її текстовою та голосовою нотаткою.
- **Таймери сну та будильники**
- **Плани запланованих записів** — самі записи не видаляються.

**Вибрати все** позначає всі пункти. **Скинути / видалити вибране** виконує ваш вибір; якщо нічого не позначено, freeAudio повідомляє «Нічого не вибрано». **Скасувати** (або `Escape`) закриває діалог без жодних дій.

Перед будь-якою зміною freeAudio перелічує позначені пункти, попереджає, що цю дію неможливо скасувати, і просить підтвердити; відповідь за замовчуванням — **Ні**. Після цього повідомлення каже «Готово.» або перелічує пункти, які не вдалося видалити — зазвичай через те, що файл використовується. Якщо браузер радіостанцій відкритий під час видалення збережених даних, його закривають, і він відновлюється з решти даних наступного разу.

Записи, папка записів і текстовий файл улюблених треків **ніколи** не зачіпаються, а скидання налаштувань не змушує freeAudio знову імпортувати дані з попереднього додатка FreeRadio.

Після скидання налаштувань значення, які все ще показуються на сторінці налаштувань, не зберігаються, коли ви натискаєте OK, тож вони не можуть скасувати скидання. Рекомендується перезапустити NVDA, щоб усі налаштування набули чинності.

## Вимкнути сповіщення

Якщо в налаштуваннях увімкнено **Вимкнути сповіщення**, NVDA вимикає наведені нижче автоматичні повідомлення:

- Назва станції, коли починається відтворення нової станції
- Зміни стану відтворення: відтворення, пауза, зупинка
- Режим Obligato: запущено / зупинено
- Події запису: початок, зупинка, завершення (миттєвий запис, запис трека, запис кожного треку та запис за розкладом)
- Оголошення про зміну трека в ICY, навіть якщо також увімкнено функцію **Автоматичне оголошення про зміну трека**
- Повідомлення про те, що станція відтворюється в особливому режимі сумісності (див. [Відтворення](#відтворення))

Нижченаведені повідомлення навмисно **не** підпадають під ці зміни: повідомлення про помилки, відгуки щодо улюблених треків (додано / вже є у списку), результати розпізнавання треків та повідомлення про оновлення.

Цей параметр можна увімкнути або вимкнути в меню NVDA → Параметри → Налаштування → freeAudio, або миттєво в будь-який момент за допомогою жесту вводу, якому не призначено жодної комбінації (призначити такий жест можна в меню NVDA → Параметри → Жести вводу → freeAudio). Після увімкнення або вимкнення NVDA один раз озвучить повідомлення «Сповіщення вимкнено» або «Сповіщення увімкнено» для підтвердження зміни.

## Автоматичне повідомлення про відстеження змін

Якщо в налаштуваннях увімкнено параметр **«Автоматичне оголошення зміни треку»**, freeAudio приблизно кожні 5 секунд у фоновому режимі перевіряє потік метаданих ICY поточної станції. Коли трек змінюється, NVDA автоматично зачитує назву нового трека — натискання клавіш не потрібне.

Під час перемикання на нову станцію інформація про перший трек оголошується одразу після встановлення з'єднання. Якщо ви перемикаєтеся на станцію, яка не транслює метадані ICY, система не видає жодних звукових сигналів, а інформація про трек попередньої станції не повторюється.

Ця функція початково вимкнена, і її можна перемикати в меню NVDA → Параметри → Налаштування → freeAudio.

## Відтворення

freeAudio використовує **BASS** як єдиний механізм відтворення для всього — інтернет-радіо, подкастів, аудіокниг і треків черги прослуховування. Окремої інсталяції не потрібно; він входить до складу додатка. freeAudio не використовує VLC, PotPlayer чи Windows Media Player.

BASS надсилає аудіо безпосередньо до аудіостеку Windows і показується в мікшері гучності Windows як самостійне джерело звуку під назвою «pythonw.exe», окреме від NVDA. Це означає, що аудіо freeAudio передається по повністю окремому каналу від мовлення NVDA: радіо не обривається, не змішується та не зазнає впливу власних налаштувань аудіо NVDA під час мовлення NVDA. Користувач може регулювати гучність радіо незалежно від NVDA у мікшері гучності Windows. Підтримує HTTP, HTTPS та більшість вбудованих форматів потокового аудіо.

Епізоди подкастів, розділи аудіокниг і треки черги прослуховування відтворюються через BASS, оскільки він може відкривати потік як файл із можливістю пошуку (навіть під час завантаження), що дозволяє точне відстеження позиції, багаторівневе перемотування, швидкість відтворення, транспонування та відновлення. Дзеркало аудіо, тайм-шифт і пошук/відновлення подкастів, аудіокниг і черги прослуховування залежать від BASS і завжди доступні.

**Станції HLS, що потребують режиму сумісності:** кілька станцій HLS (`.m3u8`) пакують своє аудіо так, що BASS не може його плавно читати — він постійно перевідкриває потік, що звучить як постійне заїкання. Для цих станцій (наразі радіопотоки ABC Australia) freeAudio автоматично перепаковує те саме аудіо без повторного кодування у звичайний формат за допомогою невеликого сервера, що працює лише на вашому комп’ютері, і відтворює його натомість. Нічого налаштовувати не потрібно. Першого разу після запуску NVDA, коли ви відтворюєте таку станцію, NVDA оголошує: «Ця станція використовує особливий режим відтворення, щоб уникнути переривання звуку.» Це оголошення підпорядковується налаштуванню **Вимкнути сповіщення**.

## Перевірка оновлень

freeAudio автоматично перевіряє наявність нових версій через GitHub.

**Автоматична перевірка:** працює тихо у фоновому режимі через 15 секунд після запуску NVDA. Якщо знайдено нову версію, ви отримаєте сповіщення; якщо нічого не знайдено, повідомлення не показується.

**Ручна перевірка:** Можна запустити за бажанням у меню NVDA «Інструменти» → «freeAudio» → **«Перевірити наявність оновлень…»**. При запуску таким чином результат оголошується навіть у тому випадку, якщо версія є актуальною.

**Якщо оновлення знайдено:** Відкриється діалог з номером версії та встановленою версією.

- Якщо у випуску на GitHub доступний файл `.nvda-addon` для прямого завантаження, з’являється кнопка **Завантажити та встановити**. Після підтвердження файл завантажується у фоновому режимі, NVDA повідомляє про початок завантаження, а потім автоматично відкривається власний діалог встановлення NVDA.
- Якщо посилання для прямого завантаження відсутнє, з’являється кнопка **Відкрити сторінку**, і сторінка випуску на GitHub відкривається у браузері.

**Щоб вимкнути автоматичні перевірки:** Вимкніть параметр **Автоматично перевіряти наявність оновлень** у меню NVDA → Параметри → Налаштування → freeAudio.
